# 武器图鉴 HTML 原型（2026-11-17）

文件：`weapon-codex.html`（单文件，无外部依赖，双击即可在 Chrome/Safari 打开；需要 WebGL2）。
源：`template.html` + `build.py`（把 `art/weapon_gen/out/wingsword.json` 内联进去生成成品）。重新生成：`python3 prototype/weapon-codex/build.py`。
调试参数：`?cat=bow&sel=b3` 直达；`?reset` 清存档；`?do=equip@500,next@900` 定时动作。

## 风格与字体
扁平实色：无渐变框/模糊/光扫，切角实色板，2–4px 粗描边，粗体字。标题/页签/按钮/武器名用「站酷庆科黄油体」（OFL），正文用 Noto Sans SC（OFL，取 650 字重），均按页面实际用到的字符裁剪后以 woff2 内联（共约 170KB）。新增文字后重新 `build.py` 即可（首次会联网下载字体到 /tmp/fontdl）。只管横屏，竖屏仅保证不崩。

## 贴图（Mivo 生成，匹配游戏现有大理石 UI）
`art/codex_ui/tex_*.png` 为 Mivo(GPT Image) 生成的深蓝大理石 / 奶白金纹大理石 / 灰度回纹带，`baked/*.jpg` 为处理后的小图（面板压暗、金色按钮染金、纹带归一后用 multiply 叠色），由 `build.py` 以 CSS 变量内联。用途：面板/卡片底=深蓝大理石；选中卡、装备按钮、选中页签=奶白/金纹大理石；稀有度色带=回纹菱形纹叠稀有度色；标题下=金色回纹条。

## 交互与时序
- 分类页签：指示线 320ms ease-out 横移；网格卡片逐张入场 420ms，间隔 45ms。
- 切武器：旧模型 100ms 淡出+缩小，新模型 340ms 从下方 easeOutBack 弹入，同时展台扩散环、闪光 0.5–0.6。
- 选中卡：上抬 3px、四角金框呼吸、缩略图放大 1.07；NEW 停留 0.7s 后清除。
- 3D：拖动 yaw（0.011rad/px）+ 轻微 pitch(±0.35)；松手惯性衰减；1.5s 无操作后 12°/s 自转；双击或 ↺ 回正 0.4s；⏸ 暂停自转；减少动态效果时关闭自转/惯性/粒子。
- 键盘：←→ 切武器，Q/E 切类别，1–5 稀有度筛选，0 全部，Enter 装备，F 收藏，Esc 关闭，Home 回正。
- 触屏：右侧面板左右滑切类别；列表上下滑滚动；舞台拖动旋转。
