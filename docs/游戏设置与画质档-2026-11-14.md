# 游戏设置与画质档

2026-11-14。入口 scripts/ruins_main.lua。仅做离线检查，没有提交、构建或启动本地 Runtime；视觉与实际性能需 Web 验收。

## 入口与输入

触摸端右上既有 menu 图标打开设置；PC 使用 F10。Esc 在菜单打开时关闭菜单，否则沿用释放鼠标锁定行为。M.DEBUG_PANEL=true 时 F10 保留旧开发面板；正式场景默认 false。设置打开取消触摸所有权、蓄力与持续龙息，用独立菜单阻挡状态暂停玩家输入，不暂停物理、昼夜、谜题和虚空回溯。关闭后等待当前触点、鼠标键及移动/技能键释放，避免关闭点击穿透与继续跑动；PC 再点击画面激活锁定。

SettingsMenu 是现有 urhox-libs/UI.Panel 子类，复用 PixelDraw、ArkPixel 12/24、panel_paper、墨青/铜金/羊皮纸色；所有位图由现有 2× NEAREST 九宫格绘制。没有新增 raw NanoVG 帧或原生 UI。内容分为画质/高级/调试页，高级逐项循环覆盖并分页；按钮命中高度 44dp，安全区外再留 20dp。说明按中文宽度换行。未附着设置的 dragon_main 继续使用原操作说明。

## 设置项

| 键 | 值 | 默认 |
|---|---|---|
| quality | high / medium / low / auto | Android/iOS 或已检测触摸：medium；其他：high |
| debugLog | boolean | false |
| perfHud | boolean | false |
| clouds / lowClouds / cloudShadow / lightShafts / floatingMotes / volumetric | nil / true / false | nil（跟随档位） |
| grass | nil / full / half / off | nil |
| shadows | nil / high / low / off | nil |
| postFx | nil / full / lite / off | nil |

Web 的 GetPlatform 不区分桌面/手机，所以首个真实触摸会把尚未手选的 high 改为 medium；已手选/保存的明确档位不会被触摸覆盖。auto 以平台默认档起步，每 2 秒检查窗口均值，超过 1/28 秒累计慢窗口，低于 1/34 秒清零；至少 3 个慢窗口且距上次调档 >=10 秒才降一档，只降不升。失焦、最小化、非正 dt 和 >1 秒的恢复停顿不计入。离开 auto 即撤销其帧监测，只有尚未保存时保留 0.5 秒短暂定时器。

## 集中参数

GameSettings.PROFILES 是预算唯一源；单项覆盖在档位之后解析。

| 参数 | high | medium | low |
|---|---:|---:|---:|
| cloudCount / cloudsEnabled | 24 / true | 12 / true | 4 / true（仅地平线） |
| lightShafts | 8 | 3 | 0 |
| motes | 80 | 28 | 0 |
| volumetric | full | lite | off |
| grassDensity / grassDistance（m） | 1 / 55 | .5 / 38 | .25 / 24 |
| shadowCascades / shadowDistance（m） | 3 / 140 | 2 / 65 | 0 / 0 |
| shadowOn / shadowMapSize / PCF | true / 2048 / 4 | true / 1024 / 2 | false / 512 / 1 |
| bloom / postFx | true / full | false / lite | false / off |
| skyCaptureResolution / 最短间隔（秒） | 64 / .5 | 32 / 2 | 32 / 5 |

草覆盖 full/half/off 对应 1/.5/0；阴影 high/low/off 对应高档/中档/关闭。明确开启云、光柱、浮光时，低档预算为4/3/28；低档云只保留地平线，低空云及云影不启用（覆盖值保留到中高档），体积光 true 解析 full；能力限制仍由对应模块决定。

原生 GrassField 的草密度为 110×比例，花为 2.5×比例，并缩短可见距离；关闭时禁用组件并跳过压草调用。Web 草簇兜底不在设置时重建几何，而按稳定顺序保留全部/每2块/每4块的现有6m批次；这减少绘制而不释放启动时分配的网格，效果是空间稀疏，不是假装每簇变少。

阴影即时改变级联、贴图与 PCF，禁用自动级联属性以遵守手动距离。天空捕获只改分辨率和最短间隔，原有太阳逐帧移动、时刻差阈值、捕获中不排队保持。分辨率实际热切换仍需 Web 验证。

后效 full 使用 UE Bloom，lite/off 使用零泛光强度的 Legacy 合成。引擎把色调映射与曝光放在 Bloom 最后合成中，不能关闭 Bloom Enable，否则过曝；所以“关闭后效”仍保留基础合成与固定曝光。lite/off 当前都不额外开启屏幕特效；不宣称曝光直方图或所有后处理 pass 消失。未找到可靠的场景 renderScale API，不添加虚构分辨率缩放选项。

## API 与注册点

GameSettings.Load/Save/Get/Set/Apply/RegisterQuality/OnChange；附加 GetProfile/Resolve/TouchDetected/Stop。

- Load 在 ruins_main.Start、RuinsScene.Start 前执行，Save 写引擎相对路径 settings.json。
- Set 校验键值；画质/覆盖立即 Apply，日志/性能小字仅通知自身，不重复重建画质特性。最后一次编辑后 0.5 秒保存；Stop 刷新待保存内容。
- RegisterQuality(name,fn) 同名替换；加载后注册会立即收到当前解析 profile。Apply 按注册顺序调用回调，回调无需每帧轮询。OnChange 返回取消订阅函数。
- SceneQuality.Attach 在场景创建后注册 scene-shadows、scene-postfx、scene-grass、scene-skycapture；没有 Update 订阅。
- SkyAtmosphere 在 SetupLighting 中先注册 skyfx，SceneQuality 在场景完成后注册，因此天空回调先于捕获/阴影/后效/草。LightQuality.ConfigureScene 仅初始化一次；托管态热切只走 ApplyVolume，不调用 ApplyStandaloneScene，不再重写阴影/Bloom。
- 托管实例的 SetQuality(high/medium/low/auto) 转 GameSettings.Set；off 是 low 别名，尊重用户明确覆盖，不偷偷清除设置。SetFeature 七项全部转统一设置：clouds→clouds、lowClouds→lowClouds、cloudShadow→cloudShadow、shafts→lightShafts、motes→floatingMotes、volumetric→volumetric、bloom→postFx。clouds 在托管态是云总开关；lowClouds/地面云影另有可保存覆盖。每次 ApplyProfile 重置本地 feature 门控，不残留菜单之外的隐藏覆盖。停止后的两个旧调试入口均不再修改设置。
- 独立无 GameSettings 的旧调试语义保留：SetFeature(clouds,false) 仅关闭高云，SetQuality(off) 关闭所有大气；不存在托管态的保存/全局画质路由。
- 已现读并执行新版真实几何构造：SkyClouds/Shafts 已由固定18朵/3束改为按数量生成，当前高档实际24朵/8束/80粒子，中档12朵/3束/28粒子，均与集中参数及 fallback 一致。因此没有根据旧固定几何的18/3假设回退预算。高云/低云按2:1分布，高档16+8，中档8+4；关闭低空云后分别剩16/8朵（总预算上限不变）。最新三维密度云高/中档均为1个积分三角形、1批（近中景/地平线/岛下在同一视线积分），关闭低云后仍1批；实际GPU预算是96/48主步及2/1光线步，不能用三角数代替成本。光柱仍为32/12三角形；不含粒子、引擎额外pass。
- 云/光柱/浮光减量或关闭会 Dispose 独占节点与资源；不变的配置复用对象；低档仅4朵地平线密度云/20主步/1三角/1批并轻量漂移；云总开关关闭后无大气实例且宿主跳过Update。Stop 清 self.scene/ground 强引用并注销设置/探针。实际 GPU 驱动缓存释放时机仍由引擎决定。
- DayNight 仅改一处捕获门槛，读取 capture.minCaptureInterval。RuinsTerrain 仅给两处压草调用增加 enabled 门控。

DebugLog.enabled 默认 false；调用方必须先判 enabled 再组织参数，Log/Warn 内部仍二次判定。SetEnabled(true) 才创建独立 Node/LuaScriptObject、200条环形日志、1000桶帧时间直方图；关闭全部释放，不取消场景自身的 Update 监听。探针函数常驻注册，关闭不调用；开启每5秒调用一次。

每5秒输出平均 FPS、最低瞬时 FPS、按1ms桶估计的 P95 帧时间（>=1000ms合入末桶）、当前有效画质以及注册探针。Ruins 探针统计体积、碎块、既有特效粒子、龙苏醒状态。上述是预算/数量与帧时间，不是逐模块 CPU/GPU 耗时。GetRecent(n) 按时间顺序返回最多200条；设置页可打印最近40条，不访问剪贴板权限。

PerformanceHUD 独立开启：关闭时没有 UI 节点、事件节点或绘制；开启后每0.5秒缓存一次 FPS/ms 文本，渲染仅画缓存内容。

## 持久化与失败

引擎全局 cjson 编解码，File/FILE_READ/FILE_WRITE 沙箱操作；不用 io、绝对路径或自制 UUID。

格式示例：

    {"version":1,"explicitQuality":true,"values":{"quality":"medium","debugLog":false,"perfHud":false,"grass":"half"}}

nil 覆盖不写 JSON。未知键/非法值忽略；文件不存在、不开放、nil、抛错或 JSON 损坏均回退默认；写失败保留本次会话值，下次用户修改再尝试，不每帧重试。

**引擎 file-storage 文档明确：Web 的 savedata 是内存文件系统，刷新页面即丢失。** 此实现没有引入云存档/网络请求，因此 Web 仅本页会话有效；原生平台按引擎项目+用户沙箱持久化。不能将离线存取测试称为 Web 跨刷新持久化已实现。
