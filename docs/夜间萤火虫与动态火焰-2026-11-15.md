# 夜间萤火虫与动态火焰

2026-11-15。基于 efb8da9，未提交、构建或启动 Runtime。接线仅在 SkyAtmosphere；不改 RuinsScene、战斗、控制或 HUD。原 RuinsPillarFlame.shader / xml 原样保留为回退资源。

## 做法与参数

萤火虫使用 Fireflies.lua + RuinsFireflies.xml / shader：一个 CustomGeometry、一份克隆材质、一个透明无光照颜色批次，不增加点光源、不使用粒子池或贴图。6 顶点/只，另加两枚不可见退化三角形扩展 CPU 包围盒。真实 draw 数仍需 Web profiler 确认，不能把颜色批次数当成所有视口/pass 的总数。

每只世界锚点只在生成/换区时查询 RuinsTerrain.HasGround、GroundHeight、IsSafeGround。要求中心离岛边至少 1.5m，周围 ±0.8m 的 5×5 网格全部是安全永久岛面，地面起伏不超过 0.30m；排除虚空、台阶与龙庭的六米台缘，不跟随临时碎片。中心高度为地面上 1.2–1.6m；shader 水平各轴摆幅 0.45m、竖向摆幅 0.35m，含小光片与地面起伏留量仍处于约 0.48–2.32m 范围。稀疏/无可靠地面时宁可少生成或不生成。

shader 使用独立种子相位的李萨如轨迹、呼吸明灭和缓慢周期内短暂熄灭。暖黄绿色，光片直径 0.09–0.14m，透明度上限 0.68；亮芯 RGB 上限约 (2.0, 2.1, 0.65)，只借用现有 Bloom。玩家 0.65–2m 内淡出，23–28m 距离淡出；没有真实光源或推动玩家的物理。

夜间强度是 smoothstep(0.18, 0.90, DayNight.nightK)，黄昏/黎明平滑变化。普通帧 CPU 只维护统一时钟、玩家中心与整体可见强度，不逐只移动顶点、不采地形。玩家距上次换区中心超过 8m 后，批次用 0.45 秒淡出，在完全不可见时把旧 X/Z 锚点按 40m 周期环绕到新中心，再验证地面；无效锚点有限次重采样，之后 0.45 秒淡入。这个低频换区会重建一次全批顶点，是确保 GPU 不在未知岛面/虚空上盲目环绕的折中；并非永远零 CPU 重建。飞行/快速传送时可能看到整片微光呼吸式更替，需 Web 目测。

火盆使用新增 RuinsPillarFlameDynamic.xml / shader：保留原有两张交叉竖片和弱 halo，每盆增加 2–4 枚同网格上飘火星。火焰由向上行进的解析正弦噪声、尖顶宽底遮罩、第二火舌、侧向风摆与细抖组成，核心白黄向橙红边缘过渡。没有屏幕或深度采样，没有导数、循环或噪声纹理依赖。

不依赖引擎 TIME：SkyAtmosphere 的运行时 clock 每帧写 flame_time / flight_time，位于原 5Hz 天空色更新门槛之前；原来火焰虽然包含 TIME 表达式，Web 是否确实驱动它未得到证实，不能把此次改动称为已证实的根因修复。每盆相位用顶点色 R 的精确字节 i 编码，shader 与 Lua 均取 i×2.1。点光与火焰共享波形：0.94 + 0.04 sin(7t+phase) + 0.02 sin(13t+1.7phase)，范围 0.88–1.00；每盏亮度为夜间强度×7×波形，夜间满亮范围 6.16–7.0。光色轻微变化，G 范围 0.48–0.516、B 范围 0.16–0.184，R=1；Color 初始化缓存，循环不创建 Color/table/Vector。引擎 Variant 参数封送仍可能产生引擎侧分配，离线测试不冒充原生分配测量。

## 三档与接线

| 参数 | 高 | 中 | 低 |
|---|---:|---:|---:|
| fireflies 上限 | 48 | 20 | 0 |
| flameDetail | 1 | 0.5 | 0.25 |
| 火盆 / 点光上限（沿用） | 6 / 3 | 4 / 2 | 2 / 1 |
| 每盆火星 | 4 | 2 | 2 |
| 萤火虫颜色批次 | ≤1 | ≤1 | 0 |
| 火焰+盆体颜色批次 | 7 | 5 | 3 |

GameSettings.PROFILES 仅新增 fireflies、flameDetail；沿用 RegisterQuality("skyfx")，预算变化 Dispose 后重建。没有新增设置菜单项。已有 floatingMotes=false 同时关闭萤火虫；低档即使明确打开 floatingMotes，萤火虫仍为 0。nightBraziers=false 仍只关闭柱顶火盆；两个效果可独立关闭。没有 GameSettings 的独立兜底 profile 未增加萤火虫，保持安全关闭。

SkyAtmosphere 的 Probe 增加 fireflies、firefliesBudget、firefliesReady、fireFallback，汇总批次包含萤火虫。沿用 DebugLog 的按需 Probe，关闭日志没有新打印、格式化、统计遍历或独立事件监听。Stop 注销原有注册并释放新节点/克隆材质，晚到的异步回调受 disposed 保护。

## 回退与资源

所有材质保持 GetResourceAsync。动态火焰 XML/SurfaceShader 加载返回 nil 时加载原 RuinsPillarFlame.xml，恢复原几何（无新增火星）；原材质也失败则整个火盆保持不可见，避免默认白材质。萤火虫材质失败直接隐藏，不重试、不创建默认白片。

原火焰退路仍保留历史 TIME 写法，因此退回时可能和用户所见一样静态。这是保留已认可外观的安全退路。Web GPU 延迟编译失败可能不会反映为 Material 的 nil，Lua 无法承诺自动捕获这种驱动错误；需检查 Web 控制台。设置 nightBraziers=false 可直接止损，或由开发者把首选加载路径切回原 XML。

五个新资源及 .meta 均由官方 generate_resource_meta 生成：Fireflies.lua、两个 XML、两个 shader；没有自行编造 UUID。无需额外美术贴图。

- maker-lua-lsp 配套 EmmyLua 服务（stdio）对 Fireflies、NightBraziers、SkyAtmosphere、GameSettings：Error=0，完整日志 lsp.log。初次连接已停止的旧 HTTP 端口失败后，改用已安装服务独立会话；没有修用户配置或启动游戏。

**Web 必看（全部未验证）：**

1. 23:00，草地/龙庭/岛缘是否能看到微量暖黄绿色亮点，近身与远处淡出是否自然；绝不能扎眼、泛成大光斑或漂在裂隙下。
2. Bloom 开/关、高/中/低对照，检查曝白与低档完全无萤火虫。确认两个每帧 uniform 真正推动运动。
3. 连续走 30m、外环、骑龙、传送后的换区呼吸是否突兀；重建帧是否卡顿，夜间实际 draw/GPU/内存与长时间运行。
4. 柱顶近看与远看火舌摇曳、上飘火星和光色闪烁是否自然；夜间整体亮度保持，白天平滑熄灭，冷加载不出白块。
5. 高中低反复切换、关闭浮光/火盆、离开场景/返回无旧节点复活；控制台无 shader 编译错误。实际移动端与 Web 首次加载都需验收。
