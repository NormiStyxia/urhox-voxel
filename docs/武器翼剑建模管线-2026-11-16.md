### 几何与可复现检查

- `wingsword.py` 的 `SAPPHIRE_CUTS` 在长刃段定义六个站点，形成 **五段大切割区**。每个正/背面有左右两片脊面、两条窄肩面；每个四边刻面用两个三角形表示，非共面的两半会形成一道真实折线。不是 shader 贴上去的小格。
- 浅 Λ 形脊沿横向略偏移，增加 4–14mm 冠高，邻段斜度改变，避免整段只有一个反射法线。量化后长刃正面核心 nx 范围约 **-0.825 至 +0.737**；按 0.1 精度归并仍有 15 个法线方向。
- `SAPPHIRE_CUTS` 每行三个数：源图 y 像素、在原半厚度上增加的冠高（米）、脊横向偏移占核心半宽的比例。当前站点为 `(1150,.004,-.22), (1000,.013,.26), (800,.005,-.25), (575,.014,.24), (350,.005,-.18), (180,0,0)`。调冠高改变高光分叉，调第三项改变斜切方向；总高和白边外轮廓不受它们影响。
- 白边/外轮廓只在原分段线上插值加站点，不重估宽度。和 v3 前导出物逐项对比：metadata（含 bounds/sockets）完全一致，非刃体三角数据完全一致，所有原轮廓点保留，新轮廓点都在旧折线上。
- 阴面值仍是普通 `shade`：五段左右分别 `.84/.97, .96/.83, .82/.94, .98/.85, .86/.96`，用于硬面色阶及微弱流光相位差，不是新的材质编号。

### Shader 分段与调参

仅 `assets/model/forge-blades/WingSword.shader` 改动；A/B 的 `BladeStudy.shader` 未改。材质保持不透明、没有 alpha、读屏或纹理依赖。

1. **蓝色区域选择**：核心 `.35`、宝石 `1`，以及原 `r=.6/b=.4` 浅青带，全部进入同一宝石材质。`b=1/glow=0` 的细羽片镶边被排除。白刃自发光乘 `(1-cw)`，不再污染浅青带。
2. **色深**：点缀色先按最大通道归一化，再剔除中性色分量。深/中/亮三档全部从同一个 hue 派生，不写死蓝色。厚度取对象空间 `abs(z)`；穿透系数为 `1/(1+吸收系数*厚度/视角余弦)`。中心厚处更深，不再更白。
3. **内部反射**：两块低频、宽大的后侧平面产生深浅蓝交叠；第二层随观察角稍移位。真实网格法线和分面阴影使每段响应不同，没有噪声或重复碎格。
4. **表面**：低粗糙度的非金属 PBR 加少量有色天空反射。中性白只用于局部太阳高光和一条受观察方向限制的斜高光；菲涅尔只在斜视时增强。
5. **流光**：默认十秒一轮的窄斜扫，经过不同刻面时相位和强度不同，扫出刃尖后在刃根下方复位；宝石只有很小的慢脉动。

以下均为线性颜色/亮度系数，不是 sRGB 百分比。除 flow_speed 外都在 shader 内对危险范围做了保护；深度分母最小 0.001m、视角余弦最小 .28，颜色归一化分母最小 .001，零相机方向有显式 fallback。

| uniform | 默认 | 意义与调节方向 |
|---|---:|---|
| crystal_amt | 1.0 | 宝石材质覆盖比例，0 回普通材质，1 完整覆盖蓝色区 |
| crystal_glow | 0.08 | 很弱的有色底光；不再用旧版 1.15 整片自发光 |
| core_glow | 0.6 | 兼容原接口；核心乘 .035、宝石乘 .065 的中档色，只托暗部 |
| sapphire_saturation | 0.88 | 剔除最小 RGB 通道的比例；增大更饱和，限制 0–.98 |
| sapphire_absorption | 2.0 | 光程吸收，增大更深、更不透；减小更通亮 |
| sapphire_depth | .043m | 参考半厚度；增大时同一几何显得更薄、更透 |
| sapphire_deep | .18 | 最暗色阶幅度；深色由 hue² 得到 |
| sapphire_mid | .62 | 中间色阶幅度；颜色为 hue² 与 hue 的 .60 混合 |
| sapphire_bright | .95 | 内部亮反射色阶幅度，仍是饱和 hue，不加白 |
| sapphire_roughness | .09 | 表面粗糙度，保护范围 .04–.35 |
| sapphire_internal | .32 | 内部两层反射强度，限制 0–.70；太花时优先减它 |
| sapphire_reflection | .24 | 外部天空的有色镜面模拟强度 |
| sapphire_highlight | .50 | 局部白色点/斜线高光强度 |
| sapphire_fresnel | .18 | 边缘天空反射；色相与白色只混 .28，避免大面积发白 |
| flow_strength | .7 | 原控制接口；扫光额外乘 .16，仍能从展台关闭 |
| flow_speed | .10 | 每秒循环数，.10 为十秒一轮；正值从刃根扫向尖 |

关键内部常数（便于按反馈直接调）：

- 吸收后的颜色插值乘 **1.25**，控制可见蓝色底层；`cut_facing=.5+.7*obj_normal.x+.22*obj_normal.y` 控制两侧切面的反射差异。
- 内部平面：`x*6 + (UV.y-.64)*.80 + normal.x*.40` 是宽而斜的深度层；前层阈值 **.44–.49**、副本阈值 **.57–.63**，两层权重 **.65/.35**；观察方向偏移 **ndv*.16**。这些不是沿长度重复的格子。
- 真实 PBR `SPECULAR=.72`，原其它区域 `.45`。附加太阳高光为 **pow(rl,96)**，局部窗口中心 **y=1.08m**，宽度 **.025–.13m**，斜率 **x*1.8**；宝石不受这个长刃窗口限制。
- 斜条纹：`x+y*.08-.07-normal.x*.008`，半宽 **.002–.008m**，只在 **y=.60–1.35m** 内渐入/渐出，强度另乘 **.35**；还必须命中反射方向窗口 **.018–.055**，不常亮。
- 流光复位行程 **1.40**、起点 **-.20**；相位横斜 **x*.90**，分面偏移 `(shade-.90)*.07+normal.x*.012`，扫光半宽 **.008–.025 UV**。宝石脉动 **.025+.015*sin(TIME*1.2)**。
- 最终表面底色微调 **.78+.22*shade**；它是小幅切面明暗，不是整块发白。

以下既有参数和算法保持可用：`primary_color/secondary_color/accent_color/grip_color` 四色板；`gold_metal=.35`、`metal_dark=.7`、`metal_env=1` 的金属响应；`blade_rim=.5`、`blade_glint=.7`、`blade_emit=.2` 的白边响应。金色、白色、握柄不进入新宝石段。

## 材质通道（换色）
每个三角形存 r,g,b 权重 + 明度 + 发光遮罩，剩余权重 = 握柄：

| 通道 | 内容 | shader 参数 | 默认 |
|---|---|---|---|
| r 刃体 | 白蓝刃面（阴面混入 28% accent，换色后阴影随之偏色） | `primary_color` | 近白，保证任意主色不发脏 |
| g 金属 | 护手、翼羽、护刃环、握柄环、剑首 | `secondary_color`，`gold_metal`=0.55 | 时砂金 |
| b 发光芯 | 刃芯条、所有宝石 | `accent_color`，`core_glow`=0.7，`flow_strength` | 冰蓝 |
| 余量 握柄 | 握柄皮革 | `grip_color` | 深藏青 (.08,.15,.36)，可选 `colors.grip` 预设 |
