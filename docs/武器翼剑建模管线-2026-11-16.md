# 翼剑建模管线（二次元硬边路线）· 2026-11-16

方向：武器按近战 / 远程 / 法器分类，配件只改外观；造型走二次元大色块硬边，蓝/金/白/深藏青主视觉。本文只覆盖第一把「翼剑」（2D 图第三把，不对称翼护手）。

## 管线
1. `art/weapon_gen/wingsword.py`（纯 Python，`python3 -I` 即可）生成整把剑：刃体、护手底座、羽翼护手、握柄、剑首，按部位涂材质通道，写出
   - `scripts/combat/models/WingSword.lua`（游戏用紧凑数据，482 三角面，约 28KB）
   - `art/weapon_gen/out/wingsword.json`（预览用）
2. `art/weapon_gen/preview_blender.py`：Blender 5.2 无头渲染正/侧/背/斜视预览，`art/weapons_2d/wing_sword_v1/preview_*.png`。
   `Blender -b -P art/weapon_gen/preview_blender.py -- art/weapon_gen/out/wingsword.json art/weapons_2d/wing_sword_v1/preview`
3. 游戏里 `ForgeShowroomBlades.Data('W')` 展开数据，`CustomGeometry` 分帧上传，沿用 `BladeStudy.shader`。展示台路线 `W`（锻造库舞台左下「翼剑」，F6 也可循环）。

## 材质通道（换色）
每个三角形存 r,g,b 权重 + 明度 + 发光遮罩，剩余权重 = 握柄：

| 通道 | 内容 | shader 参数 | 默认 |
|---|---|---|---|
| r 刃体 | 白蓝刃面（阴面混入 28% accent，换色后阴影随之偏色） | `primary_color` | 近白，保证任意主色不发脏 |
| g 金属 | 护手、翼羽、护刃环、握柄环、剑首 | `secondary_color`，`gold_metal`=0.55 | 时砂金 |
| b 发光芯 | 刃芯条、所有宝石 | `accent_color`，`core_glow`=0.7，`flow_strength` | 冰蓝 |
| 余量 握柄 | 握柄皮革 | `grip_color` | 深藏青 (.08,.15,.36)，可选 `colors.grip` 预设 |

UV.x：0 普通面 / 0.35 刃芯 / 1 宝石；UV.y：沿全剑高度归一。刃芯与宝石有常亮自发光，流光扫刃芯，宝石脉动。shader 在原 `BladeStudy.shader` 上增加了 grip/gold_metal/core_glow，A/B 路线权重和为 1，行为不变。

## 尺寸与挂点（米）
总长 1.855，原点在握柄中心，刃尖 +Y 1.62，剑首底 -0.235，刃占约 70%。挂点：`grip`(0,0,0)、`tip`、`bladeBase`、`pommel`，数据里在 `sockets`。展示用尺寸，进战斗前要和现有武器长度/判定对齐（判定仍走数据驱动，不依赖网格）。

### 当前量化结果

`art/weapons_2d/wing_sword_v2/metrics.json` 是可重算结果。正视使用源图 alpha/颜色阈值分离可见金色与刃体，对量化后的网格进行独立软件 z-buffer 投影；不计概念图深蓝描边。侧视测的是**最大厚度包络**，不代表逐高度的轮廓都吻合。

| 项目 | 当前结果 |
|---|---:|
| 正面可见金色护手 IoU（含刃根金座） | 0.7457 |
| 正面可见刃体 IoU | 0.8781 |
| 侧视刃体厚度 | 概念 0.07009m / 模型 0.06743m，误差 3.79% |
| 侧视护手厚度包络 | 概念 0.12990m / 模型 0.13048m，误差 0.45% |

剩余差异：概念图有较粗深蓝描边与更多金色细碎折面；当前中央护手/宝石细节更简化，小菱形按接线要求保留蓝色，源图实际偏金；握柄/剑首沿用 v1，比例和配色仍未贴图式还原。源侧视上羽片比正面高约 90px，三视图并非完全正交一致，当前优先固定正面高度，侧面弧线仍需视觉验收。
