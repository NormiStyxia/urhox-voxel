# 武器造型细化 · 2026-11-14

本轮仅 W1 武器建模。基线 `96ffec970b1b3cee1897c9d8955f6661a7326ee9`。没有构建、提交或启动游戏 Runtime。全部图片由真实 Lua 稀疏体素数据离线投影生成，**不是引擎截图，也不表示 Web 视觉验收通过**。

## 造型与兼容性

- 直刃：短刃根、长段收束、单格尖端；阔刃：下肩—腰身—上叶肩，轮廓不同；细剑：窄肩强根、菱形截面针刃。保留各自高度 22/21/26 格。刃脊使用副色金属高光，取消贯穿全刃的点缀色亮条，仅刃根留小铆饰。
- 十字护手有下折末端；翼形护手上扬并留空口；窄护手为紧凑领环。全部改成薄刃边与正背倒角，不再整块挤出。缠革改为连续斜向缠线，长柄增加中部束环；圆首、晶首、配重分别为圆片、尖晶、平底重锤。
- 短弓紧弧、长弓长曲线、反曲弓有真实方向反转的末端曲线。弓臂从根部厚、宽到梢部细、窄；上、下弓臂和装饰簇仍对称。
- 两个握把增加右侧箭台：支撑格位于 `(2,1,3)`，原发射 socket 保持 `(2,2,3)`；只有握把的功能性箭台不作上下镜像。原点仍为握点。
- 铁簇为长三角、骨簇为短肩、晶簇为菱形；上弦箭使用相同部件几何，杆、双羽、侧向尾扣均可审查。原上弦箭中心线在 Y=0，低于发射 socket 6cm；现在对齐 Y=0.06m，尾扣连接该高度的实际弦格。`GetHit` 原点、方向未改，不改伤害射向。
- 保留 19 个 ID、存档版本、属性取舍、调色板、全部 sockets、组合 offsets、剑实际刃尖距离、弓发射 `(0.06,0.06,0.09)m / +Z`。72 组合逐一与基线比对。全局尺寸与体素边长不放大。原有剑视觉 X×1.3/Y×1.25 保留，**本轮没有再加比例**；已有视觉/判定缩放差异仍是原方案行为。
- 使用既有铜金/灰铁/深色派生色和三路玩家色板，不新增材质、发光灯、贴图或高面数资产。预览 token/异步回执、分帧创建不修改。两武器及三档弓形、残影、特效池仍在启动/换件时预建；切换只用现有池。

## 验证与性能边界

六套 `weapon_*` 回归覆盖 72 组合接点/六邻域连通、实际刃尖/剑轴、三档弦与握把不相交、箭台下托和发射走廊、箭尾贴弦、羽/簇避让、存档读写回退、预览 token/异步回执，以及切换/首次拔刃期间禁止 Build/CreateVolume/Color。LSP 检查四个 Weapon 模块、ForgePanel 与七个测试/mock 文件。

体素减少不等于面数减少：倒角/曲线/缠线使表面更细碎，预览合并面数有所增加。详细前后数量见 `metrics.md`，不能把离线 mock 耗时当作 Web 帧时间。世界 VoxelVolume 的原生面数、真实 GPU 提交数和耗时尚未测量。新增图片都只是 validation 审查产物，不是游戏资源，不需 `.meta`；没有新增运行 Lua 文件。

## Lead 构建后的 Web 待验清单

1. 正面：三剑单格尖端、直刃收束/阔刃腰身/细剑窄肩是否在常用战斗距离可区分；刃脊不形成全长霓虹条。
2. 左右侧面：薄刃、护手倒角、握柄缠线、配重层次；不能漏面/断格；既有手握比例不穿掌。
3. 背面与悬挂：护手翼端、剑首轮廓仍清楚；弓横挂弦靠人物、凸面朝外；漂浮/飞手/收回无重复武器。
4. 三种弓 0/中/满档：+Y向上、+Z目标、-Z射手，箭在握把右侧，箭台下托，箭尾贴弦；弦、箭羽、左掌/右拉弦手不穿插。离线只排除了武器自身几何相交，人物掌/手臂遮挡需实机。
5. 锻造遍历三预设/各部件/换色：3D 或有效 2D 降级均能辨形；仍看到 Forge preview 日志，退出无残留。背/手切换不触发重建，不因新面数产生尖峰。
6. 实测原生网格面数、提交数、启动池/换件分帧耗时及 30/60FPS 观感；尤其检查新增右侧箭台使弓池 AABB 增宽的内存影响。
