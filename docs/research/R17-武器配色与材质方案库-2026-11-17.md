# R17 · 武器配色与材质方案库

日期：2026-11-17｜对象：二次元体素探索战斗游戏的剑、弓｜性质：美术选型建议，未修改代码、材质或资源。

## 结论先行

| 决策 | 推荐做法 | 原因 |
|---|---|---|
| 稀有度与武器颜色解耦 | 普通/优秀/稀有/史诗/传说的灰/绿/蓝/紫/橙，仅用于 UI 框、标签和档位标记 | 传说可以是白银、黑红、粉晶、青铜；绿色武器也可以是普通 |
| 建立 32 套四色方案 | 8 个风格家族各 4 套，覆盖红、橙、黄、绿、青、蓝、紫、粉及黑白灰 | 避免所有家族收敛为蓝金 |
| 使用“一主二副＋握持区” | 刚体/刃面决定大轮廓；金属装饰说明工艺；芯/宝石说明能量；握把负责收束 | 四个通道不等于四种同等面积的抢眼颜色 |
| 高档提升材质和局部节奏 | 可提高宝石饱和度、打磨层次和少量发光，不强制提高整把武器的饱和度 | 黑曜暗金、白银月光也能成立为传说 |
| 白刃换色分两种模式 | 浅染模式保留高明度、适中饱和度；黑红/暗金等作为独立深色方案验收 | 将白刃直接乘成深红、深绿、深紫，容易丢失切面和轮廓 |
| 颜色不等于材质 | 本库 hex 是美术目标；珐琅、木纹、真透明水晶还需要对应材质支持 | 现有四个换色参数不能单独改变所有表面材质 |

### 1.1 可以立即采用的组织规则

| 手法 | 剑的落点 | 弓的落点 | 避免的问题 |
|---|---|---|---|
| 一主二副＋暗握把 | 主色贯穿刃身；金属沿护手/剑首；芯在中央或单侧 | 主色贯穿弓臂；金属在臂根/包角；芯在内侧导槽/节点 | 不将四区均分为四条等宽彩带 |
| 冷暖配对 | 冷白刃＋暖银金属＋红/青宝石 | 暖木弓臂＋冷银包角＋薄荷芯 | 冷色不必永远配黄金 |
| 近似色＋一个反差点 | 灰紫刃＋银＋紫芯＋酒红握把 | 苔绿弓臂＋古铜＋黄绿芯＋深褐握把 | 同色系仍保留明度、粗糙度差 |
| 元素色局部化 | 火色用在芯与裂缝；冰色用在晶面；自然色落在枝形纹样 | 在弓臂内缘与能量节点体现元素 | 不把整把武器等同于“火=橙、冰=蓝” |
| 阵营色位置固定 | 家族固定护手/铭牌位置，不要求固定全部颜色 | 家族固定包角/徽章位置 | 同阵营可有白、黑、粉等变体 |
| 大块静色＋小块高纯色 | 让宝石/芯成为视线终点 | 让弓中央与两端节点形成节奏 | 不同时给四个色区高饱和/强发光 |

**面积起点（按主要视角投影面积估算）：**刚体/刃面 55–70%，金属装饰 15–25%，芯/宝石 3–10%，握把 8–15%。四项应按具体造型归一到 100%，区间端点不能直接相加。透明度和发光会增加视觉权重，芯通常应比几何面积更克制。

## 2. 四色区与材质的使用约定

| 库中名称 | 当前翼剑参数 | 推荐内容 | 限制 |
|---|---|---|---|
| 刚体/刃面 | `primary_color` | 剑刃大面、弓臂主体/外壳 | 弓可表现木或漆，剑需按设计区分钢、陶瓷、涂层；hex 不自动改变材质 |
| 金属装饰 | `secondary_color` | 护手、剑首、包角、箍环、机匣边件 | 银金铜是视觉目标；现有金属响应仍带暖色高光，银色方案需 Web 看是否偏金 |
| 发光芯/宝石 | `accent_color` | 宝石、导能槽、晶体刃芯、弓臂能量节点 | 本库写“水晶”不代表现有实现真透明；低档可保留不发光的石头/嵌件 |
| 握把 | `grip_color` | 皮革、缠绳、木握、橡胶 | 暗而有色比纯黑更能保留体积；弓弦不默认归入这一色区 |

以下全部 hex 为 **sRGB 目标色**，不是线性 RGB 或发光强度，也不是竞品取色。若未来接入颜色管理，遵循当前 `source_color` 路径，只进行一次 sRGB→线性转换。

材质说明按 **刚体 / 金属 / 芯 / 握把** 顺序。它们是建议，不是“当前 shader 已支持”的承诺。水晶建议优先保留不透明刻面与透感模拟；真半透明、木纹、珐琅需要另行制作/验收。发光方式是该套允许的表现，实际强度和覆盖面积由稀有度裁切。

## 4. 五档稀有度如何与颜色共存

以下面积/节奏是本项目初始美术预算，不是引擎性能结论。发光面积指主要视角中真正自发光的投影面积；宝石总面积可以更大。高档允许保持无光/低饱和，以更精细的工艺与轮廓体现价值。

| 稀有度 | UI 代表色 | 刚体与金属建议 | 芯/宝石与发光面积起点 | 发光节奏 |
|---|---|---|---|---|
| 普通 | 灰 | 素钢、木、皮；主色低到中饱和度；基本金属反射 | 0%；彩色芯可解释为普通嵌石 | 关闭自发光/流光 |
| 优秀 | 绿 | 多一处干净包角或涂层；保留朴素大块 | 0–2%；一个局部亮点可选 | 稳定弱光 |
| 稀有 | 蓝 | 拉开哑光与抛光；允许鲜明宝石色 | 2–4% | 稳定光，或一处很弱慢脉动 |
| 史诗 | 紫 | 两种金属明暗或刻面层次；更有辨识的芯色 | 3–6% | 2–4 秒一轮的低幅脉动，或 8–12 秒一轮流光 |
| 传说 | 橙 | 局部工艺最清楚，轮廓和材质分层最完整；可黑、白、暗金 | 4–8%，少数造型短暂峰值最多约 12%，需 Web 复核 | 一个主节奏；宝石呼吸与刃线流光避免同时抢眼 |

**规则不是“普通必须灰、传说必须橙”，也不是“传说必然最亮”。**同一方案可横跨五档；例如 P25 普通为无光铜/松石，传说可通过包角精修、宝石切面和少量细线光升级。玩家自定义换色后，UI 稀有度标识仍保持不变。

### 4.1 卡框色的避让表

“低冲突”仅指大面积武器色与对应卡框较易区分；不是色觉障碍认证。芯、装饰和背景也要一起看。下列编号只给起始候选，不能替代实际缩略图验收。

| 框色 | 优先搭配的方案示例 | 容易贴框的方案 | 避让动作 |
|---|---|---|---|
| 灰：普通 | P05、P07、P11、P15、P17、P26、P32 | P02、P18、P21、P30 的中性主体 | 灰框外加明确“普通”字；白银武器放中暗底，灰钢用更亮边/轮廓 |
| 绿：优秀 | P01、P04、P07、P13、P15、P18、P21、P29 | P05、P17，P06/P23 的大绿光 | 植物绿不要沿卡框边缘形成同色轮廓；给内缘中性隔离线 |
| 蓝：稀有 | P01、P07、P11、P15、P18、P23、P26、P31 | P13，及 P10/P28 的青蓝边光 | 主体改暗/亮级差，芯收小；避免蓝色光晕接触蓝框 |
| 紫：史诗 | P01、P05、P09、P18、P25、P29、P32 | P08、P14、P20、P24，P22 的洋红光 | 紫晶集中在内部，以银或中性刃边断开；使用文字/档位符号 |
| 橙：传说 | P02、P10、P14、P15、P18、P19、P21、P28 | P07/P26/P32 的暖主体、P29 的橙芯、P31 的暗金大面 | 不采用大面积纯橙主体；暖金/红铜可用，但不能再附整圈橙光，边缘必须有中性色与明度间隔 |

| 通用规则 | 可操作的起点 |
|---|---|
| 色相避让 | 当主体和框都明显有彩色时，HSV 色相最短角距离优先 ≥35°，理想 ≥45°；中性色不强行比较色相 |
| 明度避让 | 色相接近时，缩略图里主体轮廓与紧邻底色的相对亮度差优先 ≥0.20；这是美术起点，不能当 UI 文字对比标准 |
| 面积避让 | 与框同色系的高饱和武器区域，先压到武器投影面积 10% 以内，并放内部；不让同色光晕碰框 |
| 橙框特别规则 | 传说主色不取纯橙。暗金/赤铜属于材料色，可保留；小橙芯需被白铁/深灰包围。P29 是可保留橙芯的例子 |
| 空间隔离 | 框与武器之间保留中性留白；可用 2–4 个逻辑像素的中性内线，按最终卡片缩放检查 |
| 冗余编码 | 同时显示“普通/优秀/稀有/史诗/传说”文字与可数档位标记；不要仅靠颜色，也不要只靠模型发光猜档位 |
| 保留主题 | 不为迁就卡框强行把所有绿色自然武器改白；优先调整卡内底色、光晕范围、间距与中性轮廓 |

## 5. 换色的安全范围

### 5.1 白刃换红/绿/紫会不会发脏？

**会，但不是这些色相天然发脏。**风险来自三处：深色把固有明暗一起压低；原有蓝/青烘焙色或混合权重与红绿相混；冷暖环境光、暖金反射、强白色自发光让面色失去原本层次。浅白基底有利于换色，但不能保证“任何颜色一键都干净”。

| 机制 | 项目核对结果 | 美术决策 |
|---|---|---|
| 四色权重混合 | 当前翼剑 `base` 按 `COLOR.r/g/b` 和剩余握把权重相加 | 先检查该面是否纯主区；边界混色不能仅靠主色解决 |
| 主色与芯色相互影响 | 当前 shader 将部分 `0.6r/0.4b` 肩面纳入水晶分支；刃边反射还引用 accent | 白刃转红后若仍配青芯，边缘可能出现双色；作为有意设计验收，不假定自动变成红钢 |
| 宝石亮度与饱和度 | 当前水晶分支先按最大通道归一化，再削中性分量并重建深/中/亮色阶 | 调暗 accent 的 hex 不等于调暗宝石；低饱和粉晶/乳白石也可能被增强饱和度，需材质单独调参 |
| 金属暖色倾向 | 当前装饰分支含暖白高光常量与原有金属环境模拟 | 冷银/玫瑰银方案必须在 Web 灯光下复核；不可凭 hex 保证材质中性 |
| 水晶透明 | 当前翼剑为不透明的光学透感模拟 | 选型阶段可用；不能将其写成真半透明已完成 |

本地旧管线文档出现过“阴面混入 28% accent”的说明；当前 `WingSword.shader` 的结构已有变化，本节以当前代码为准，**不把旧百分比当作全部刃面的现行规则**。

### 5.2 给调色面板的简单门槛

这里 HSL 是对 **sRGB 颜色**计算的工具值；L 不是场景照度，也不是严格感知亮度。规则针对保留“白刃浅染”观感；方案库里的黑、暗金、苔绿等有意深色不受此模式限制。

| 色区/模式 | 建议范围 | 允许放宽的条件 |
|---|---|---|
| 刚体：白刃浅染默认 | HSL **L 78–90%，S 15–45%**；色相自由；近中性 S 可低于 15% | 已在中性光、暖日光、冷月光通过四视角观察，可降至 L 72%；不作为默认滑杆下限 |
| 刚体：浅染硬防线 | **L 不低于 72%，S 不高于 55%**；另用线性相对亮度 Y≥0.40 筛掉看似高 V 实际很暗的颜色 | 这只是过滤危险输入，不能代替渲染验收；要更深色则切深色专案 |
| 金属装饰 | 不用统一浅染下限；依银/金/铜材质定标，避免纯白/纯黑作为常规金属基色 | 色板允许暗金，但要保留反射与亮边，不能只降色值 |
| 芯/宝石 | 可用高饱和色；优先局部而非扩大面积；不以 hex 明度控制所有发光 | 乳白、粉晶等低饱和方案须校准水晶去中性/饱和增强参数 |
| 握把 | HSL L 16–35%、S 10–45% 为起点；保留可读暗面 | 深色主体时可将握把提高到 L 35–45%，避免两者合成一块 |
| 深色专案 | 允许突破主区亮度下限；保留中亮度棱边/装饰和受光面 | 先用 P03/P19/P22/P24/P31 定制验收，不由浅染滑杆直接一路压黑 |

相对亮度计算：先将各个 sRGB 通道归一到 0–1；若 c≤0.04045，线性值为 c/12.92，否则为 `((c+0.055)/1.055)^2.4`；再算 `Y=0.2126R+0.7152G+0.0722B`。不要用 HSV 的 V 代替 Y：纯红和纯蓝即使 V=100%，也可能显著偏暗。

| 换色方向 | 浅染安全起点 | 视觉意图 | 不宜直接当浅染输入的例子 |
|---|---|---|---|
| 红 | `#E0B9BD` | 灰玫瑰钢/浅红漆；红度集中在宝石 | `#AA1F32` 深猩红；会把白刃的大面压暗 |
| 绿 | `#BFD6BD` | 玉白/薄苔绿钢，保留中性高光 | `#1F6B3C` 深森林绿；需深色专案 |
| 紫 | `#CFC1E0` | 藤白/淡紫银，切面仍清楚 | `#5A2688` 深紫；冷阴影下易并成暗块 |
| 中性白 | `#E2E4E2` | 保留原始形体检查基线 | `#FFFFFF` 不一定错误，但与强白高光叠加时易失层次 |

“发脏”出现时，按 **关闭发光看底色 → 看色区权重/原有烘焙色 → 恢复中性光 → 调主区明度/饱和度 → 最后恢复芯光** 的顺序排查。不要先把整把武器加亮来掩盖问题。

### 5.3 材质参数只作制作方向

| 材质 | 粗糙度建议起点 | 金属度方向 | 颜色/发光注意 |
|---|---|---|---|
| 哑光钢、枪灰钢 | 0.40–0.65 | 金属基底为主；涂层需按层区分 | 大面不自发光，亮边负责辨形 |
| 高光银、抛光金铜 | 0.15–0.30 | 裸金属通常接近 1 | 反射光不等于自发光；避免全表面白片 |
| 珐琅、漆、陶瓷感涂层 | 0.25–0.50 | 涂层表面通常接近 0 | 以清楚的表面高光区别金属 |
| 水晶、玉石 | 晶面 0.08–0.25；蜡质玉可更粗 | 非金属 | 真透明另验；底色和内部色阶分开控制 |
| 木、麻绳、皮革 | 0.55–0.85 | 非金属 | 握把不发光；纹理细节不能盖过四色大关系 |

这些是通用 PBR 起点，并非当前翼剑能逐区自由设置的现成接口。当前装饰金属度、粗糙度和模拟反射另有耦合，不应直接用上表数值覆盖现有全局参数。
