# R4：闪避滑步与攻击衔接

2026-11-14。目标：短促、贴地、保持进攻朝向、能接剑与弓的滑步。只提出调参方案，不修改现行契约或代码。以下来源访问日期均为 **2026-11-14**；秒为实现单位，f60表示60Hz换算帧。官方说明、社区资料、我的推断分别标识；没有独立逐帧复测，缺失参数写“未确认”。

## 10 条可执行结论

1. 用低姿态短滑步替换360°翻滚；不能仅换动作外观，还要打开滑步接攻击的入口。
2. 初值为 **2.2m / 0.32s**；0.30s完成位移，0.22s即可接攻击。
3. 无敌窗口先设 **[0,0.20s)**，CD **0.50s**，均从动作接受时计时。
4. 根位移用12→9→5→2m/s的四段速度，起步即有冲量、末端迅速刹停。
5. 滑向按下瞬间的摇杆方向；身体保持原进攻朝向，准星不因侧滑旋转。
6. 通用缓冲保留160ms；滑步早按攻击可锁存至衔接点，单条消费，不自动攻击。
7. 滑步可衔接原连段下一击，短暂保留连段；普通回避不免费增伤。
8. 精准闪避沿用下一剑失衡×1.5，保护结束后再开放进攻，不携带额外无敌。
9. 手机以独立闪避键单击为主，无方向向后；方向拖滑可选，双击不作为必需手势。
10. 路径逐段检查地面、坡度与墙体；遇边缘截断位移，不能跳到安全终点穿过虚空。

## 分专题详述

### 1. 怪猎：要借的是回避与武器循环结合

**社区资料：World。**弓的 Charging Sidestep 同时回避并升一档蓄力，可维持高档位进入“射击—刚射—滑步”循环；之后可接突进近战，页面列动作值35。滑步不是所有武器通用替代翻滚的同一动作。**我的推断：**“躲完还在攻击位置、武器仍朝目标”比加长无敌更接近用户要的手感；剑应保留连段进度，弓要保持准星。

来源：https://monsterhunterworld.wiki.fextralife.com/Bow 。访问：2026-11-14。

**社区资料：Rise。**Charging Sidestep 与 Dodgebolt 是不同替换技；后者回避兼攻击，擦过来招可显著提升蓄力，可向四方移动。不能把Dodgebolt的反击判定当作普通滑步无敌。所读Wiki没有可靠帧表，网上“4帧”未统一计帧口径，**未确认**。**我的推断：**本项目v1先做纯位移＋按键续攻，不让每次滑步自带伤害，否则玩家会用闪避替代普攻。

来源：https://monsterhunterrise.wiki.fextralife.com/Dodgebolt 。访问：2026-11-14。

**社区资料：Wilds。**弓的 Discerning Dodge 成功可获得无敌及大量耐力、技巧箭槽；Flying Swallow Shot可由侧滑跳跃衔接射击。回报进入武器资源循环，而非只播一次慢镜。该页未给稳定版本的窗口/恢复量，**未确认**，不采用试玩版“100耐力”等网络数字。**我的推断：**精准闪避增加失衡收益已足够，不必增加新能量条。

来源：https://monsterhunterwilds.wiki.fextralife.com/Bow 。访问：2026-11-14。

**官方：Now。**弓可“蓄力中划动”滑步并保留蓄力；精准闪避使蓄力等级 **+2**，随后长按可维持、继续蓄力。陀螺仪FULL自由瞄准、SEMI自动追踪，说明位移与瞄准可分别处理。**我的推断：**触屏最值得借的是少一个重置操作；但本项目现契约要求闪避弃箭，不应擅自改成保蓄力。先做准星不跳、闪避后重新按弓即可开始拉弓；保蓄力列为后续单独平衡项。

来源：https://scopelyexplore.helpshift.com/hc/en/15-monster-hunter-now/faq/2277-bow/ 。访问：2026-11-14。

**官方/社区：回避距离与性能分开。**Now官方回避距离有3级，描述位移增强，未公布百分比；World/Rise社区同样把回避距离与延长无敌的回避性能分列。World回避性能页面列13/15/17/19/22/25，但FPS和“extra”含义不清，不换算成秒。**我的推断：**必须独立调距离、无敌、收招；更远不等于更好，贴身武器滑出剑距反而破坏进攻。

来源：https://monsterhunternow.com/en/skills/evade-extender （官方）；https://monsterhunterrise.wiki.fextralife.com/Evade_Extender 、https://monsterhunterworld.wiki.fextralife.com/Evade_Window （社区）。访问：2026-11-14。

### 2. 短步、连闪与取消：其他产品的取舍

**官方：《只狼》。**发行商支持页区分锁定、弹反反斩、倒地后的Safety Roll；Step Dodge与起身翻滚不是同一职责，不能把所有防御统一成翻滚。该页未给Step Dodge时长与无敌帧，**未确认**。**社区：《仁王2》**低架势战斗中始终短步、中架势短步后接滚、高架势始终滚，消耗依次增加；动作形态服务不同策略，而非换皮。**我的推断：**本项目可统一低姿态短步，死亡/起身才保留翻滚类动作。

来源：https://support.activision.com/sekiro/articles/sekiro-shadows-die-twice-game-mechanics （官方）；https://nioh2.wiki.fextralife.com/Stances （社区）。访问：2026-11-14。

**社区：《匹诺曹的谎言》。**Link Dodge允许在闪避中再闪一次；Rising Dodge现已补丁改为默认能力，不能照搬首发时“必须解锁才能起身”的评测。**官方平台攻略：《哈迪斯》**Greater Reflex增加 **1次**连续Dash；**社区：《死亡细胞》**翻滚长0.4s，重启前冷却列0.37s，并可翻滚后续连段。其0.37s从哪一刻起算，所读文字不足以证明，不能直接相加成0.77s。三者都没有本项目可直接套用的米制距离。**我的推断：**v1保留单CD，不新增耐力；不做按住自动连闪和滑步接滑步，避免手机连点把自己送出攻击范围。

来源：https://liesofp.wiki.fextralife.com/Link_Dodge 、https://liesofp.wiki.fextralife.com/Rising_Dodge ；https://www.playstation.com/en-us/games/hades/tips-and-tricks-to-survive-your-first-hades-encounters/ ；https://deadcells.wiki.gg/wiki/Mechanics 。访问：2026-11-14。

**官方刊载的攻略作者访谈：《猎天使魔女》。**PlatinumGames访问官方攻略作者Saurian Dash，讨论Dodge Offset如何把回避混入攻击；也举《合金装备崛起》刃狼裁掉回避结束延迟以延长输出的例子。这是受访者经验，不是公开引擎帧表。**社区：《鬼泣5》**BK Brent说明Trickster负责追击、无敌位移，连续Dash间隔受能力影响；骑摩托长攻击接触敌人后可跳跃、Trick或防御取消。并非一切招式任意时间取消。**我的推断：**只开放明确的“攻击→闪避”与“闪避→攻击”窗口，比全程可取消更适合本项目。

来源：https://www.platinumgames.com/official-blog/article/6421 （官方访谈）；https://bkbrent.com/dmc5/dante/ （社区）。访问：2026-11-14。

**社区实测：《原神》KQM**普攻常可闪避取消，普通Dash动作约20f60，不能当作无敌20帧；连段能缓冲。**社区攻略：《鸣潮》**成功闪避可反击、回耐力并重置Dash限制，通常允许两次Dash；攻略称约半秒触发窗，未独立实测。**我的推断：**借鉴即时响应与奖励反击，不照搬高覆盖无敌或无限精准闪避；本项目没有耐力消耗，必须有稳定的非无敌空隙。

来源：https://library.keqingmains.com/combat-mechanics/frames ；https://guildjen.com/wuthering-waves-combat-guide/ 。访问：2026-11-14。

### 3. 对当前实现的诊断与触屏选择

**本地只读证据：**§14已经把距离修订为2.6m，但`dodge_roll`仍0.45s，body pitch走到366°、root下沉0.28m；位移前0.315s完成85%，没有接攻击的取消事件。`CombatMoves`中普通攻击遇到活动片段直接拒绝，提前释放片段的分支只识别`sword_light_*`；因此仅添加`cancel_open`或替换翻滚姿态，仍不能保证0.22s接攻击。`blocked`还要求原来按住的攻击先抬起，弓闪避后误射保护应保留。改为`dodge_step`时须同步检查启动、移动倍率、精准闪避三处旧id关联，由动作与战斗模块一起接线。

来源：项目`AnimClips.lua`、`CombatAnim.lua`、`CombatMoves.lua`及策划§13–§15；读取：2026-11-14。此处为代码观察，不是竞品数据。

**我的推断：**把世界空间位移方向与人物面向分离。剑滑步期间固定起始朝向，攻击衔接时才恢复现有辅助朝向；弓继续接收玩家主动瞄准，不自动甩镜追敌。摇杆模长≥0.18时取方向，低于阈值默认向身体后方；不用“上次移动方向”，避免松杆后意外冲向敌人。按下即接受，不等待松手或双击识别。按钮拖滑若做可选方案，必须同样按下即执行，不能先等拖动判方向而延迟闪避；v1采用左摇杆定向即可。触点所有权保持到抬起，菜单/失焦/取消清空缓冲。依据：上述Now的瞄准分离、KQM的输入取消与本项目触屏契约。

以下全部为**我的推断/首轮Web调参初值**，不是怪猎原值。优先验证“0.22s接攻击”是否成立，再微调特效。

| 终点硬直 | 位移结束后仅0.02s；0.22s开放攻击、0.26s开放普通走动；按攻击/走动可提前截断剩余滑步 |
| 攻击→滑步 | 沿用§14：前两普攻判定结束后；第三判定后再等0.08s；重击收招先保留0.16s；拉弓随时可取消且弃箭 |

| 普通回避首击 | 伤害×1、失衡×1，不送重击；收益为最多提前0.10s出手与保留连段；贴身时首击额外前冲上限0.35m，避免再穿过敌人 |
| 精准回避首击 | 保留§14：开始后0.10s内真实拦到来招，0.8s内下一剑失衡×1.5，仅一次；不加伤害/无敌/CD返还 |
| 弓衔接 | 0.22s后新按攻击开始拉弓；维持原瞄准方向；旧蓄力清零、不补箭，不自动恢复原先按住态 |
| 面向与方向 | 位移方向按键接受时快照，不随随后甩杆转弯；侧滑时yaw不追随滑向；攻击时才重新选攻击朝向 |
| 动画时钟 | 无敌/取消使用真实秒数；片段events与keys转为归一化，motion仍用秒；滑步不受武器speed缩放 |

### 冲量曲线：兼容现有分段运动数据

现有`motion`按重叠时长积分每段距离，并不支持任意速度曲线。先用四段常速表达先快后慢，无须新建动画系统；各段距离之和精确为2.20m：

| 实际时间 | 速度 | 该段距离 |
|---|---:|---:|
| 0–0.06s | 12m/s | 0.72m |
| 0.06–0.16s | 9m/s | 0.90m |
| 0.16–0.26s | 5m/s | 0.50m |
| 0.26–0.30s | 2m/s | 0.08m |
| 0.30–0.32s | 0 | 0 |

0.22s取消时实际已走1.92m；取消后丢弃剩余0.28m，不瞬间补齐，不继承12m/s冲量进攻击。判定积分跨过多个阶段时须计算所有重叠，不能取当前帧速度直接乘dt。依据：本地`CombatAnim:GetMotion`语义；数值为我的推断。

### 六关键姿态语义：供动画制作

位移节点负责贴地，视觉root只负责蹲低；刚性块腿没有独立膝关节，使用左右腿反向摆与root降高表达屈膝，不能要求不存在的膝骨。角度按语义校准，不直接套欧拉正负号。

| 时刻 | 重心/躯干 | 手臂/腿/头 |
|---|---|---|
| 0s | 从战斗站姿root -0.04m进入 | 保持持剑/持弓，不收武器 |
| 0.04s | root -0.14m；向移动方向倾约12° | 蹬地腿后摆20°，另一腿前伸25°；剑臂靠身、左臂配平 |
| 0.10s | 最低root -0.18m；前倾约18°，侧滑可侧倾8° | 前后腿错开约40°；头反向补偿，继续看目标 |
| 0.18s | root -0.15m；倾斜减至12° | 后腿追上，武器回到可出手预备位 |
| 0.26s | root -0.08m；倾斜4°，前脚踩实刹车 | 腿差缩至12°；手臂准备接当前连段下一姿态 |
| 0.32s | root -0.04m、回战斗姿势 | 无额外站直弹跳；若已取消，由攻击姿态直接接管 |

### 特效、镜头与安全截断

验收：前/后/左/右各做“攻击→滑步→攻击”，另测拉弓弃箭、贴Boss侧滑、摇杆松开、边缘和墙角；30/60FPS下完整位移差应≤0.03m，取消时不能补位移。没有Web操作证据前，短滑步是否比原翻滚好用仍是待验假设。
