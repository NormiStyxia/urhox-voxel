# R14｜稀有度分级命名与产品对照

日期：2026-11-17｜用途：剑、弓的外观分级与出图参考。

## 先看结论

- **首选：普通 / 优秀 / 稀有 / 史诗 / 传说**，对应灰 / 绿 / 蓝 / 紫 / 橙；补入「优秀」即可保留用户已有的四个名字。
- 备选：**普通 / 优秀 / 精良 / 史诗 / 传说**；蓝档更像工艺评价，但失去用户已选的「稀有」。两套不要混用。
- 五色属于**稀有度 UI、掉落标记和展示光**；武器本体继续自由配色，不要求绿档做绿剑、橙档做橙弓。
- 本项目分级只影响外观：递增的是轮廓辨识度、装饰层次、局部发光与展示仪式感，**不改变伤害、攻速、射程、攻击判定和技能能力**。
- **资料状态：本稿为知识参考稿，未联网核实、不附链接。产品表全部标「凭记忆·未联网核实」；中文译名和版本差异须在正式对外引用前复核。**

## 4. 本项目的外观规则（可直接给出图与制作）

| 档位 | 剑 / 弓的轮廓与装饰 | 发光、粒子与获取反馈 | UI 固定识别 |
|---|---|---|---|
| I 普通 | 基础完整轮廓；一眼认出剑刃、护手或弓臂；结构简洁但保持二次元风格 | 无常驻发光、无常驻粒子；简短普通获取音 | 灰框 +「普通」+ I |
| II 优秀 | 增加一处明显设计：护手、弓梢、镶件或纹样 | 主要靠材质高光；获取时少量短闪 | 绿框 +「优秀」+ II |
| III 稀有 | 增加一个远看能记住的主题轮廓；如月牙护手、偏心弓臂或悬挂小件 | 单一局部发光点；稀疏、短时展示光；不占据攻击轨迹 | 蓝框 +「稀有」+ III |
| IV 史诗 | 主题轮廓更鲜明，有分层装饰或局部悬浮视觉；仍保留清楚握持和出箭结构 | 局部发光线；展示时慢脉冲或少量粒子；获取音更有层次 | 紫框 +「史诗」+ IV |
| V 传说 | 一个独特视觉母题：时间环、断裂重组刃、星轨弓等；靠设计辨识而非堆体积 | 一个标志性动态效果；获取 / 展示时完整表现，战斗时收敛 | 橙框 +「传说」+ V |

- **三通道分工：主色 / 辅色 / 点缀或发光色。** 三者服务武器主题，均不锁定品质色；例如蓝白传说弓仍配橙色品质 UI。通道如何接入材质须按项目现有实现，不在此假设已支持额外蒙版。
- **同一造型换色只能作为配色变体。** 五档若要在手持状态也能辨认，至少给每档一个可见的结构或装饰差异；禁止仅用整体染绿 / 染紫代替设计。
- **轮廓递增不等于尺寸、面数、材质数递增。** 剑刃有效长度、弓的握点与箭的出射点保持一致；装饰不遮挡人物脸、右手或瞄准方向，所有档位共用攻击判定与能力规则。
- **分清品质光与技能光。** 橙色品质不表示火属性；时间冻结等能力保留自己的统一视觉语言，不能让传说专属装饰看起来提供额外技能。
- **距离分工：** 背包靠框色 + 名称 + I～V；地面掉落靠带档位的标识与短光柱；手持近景靠轮廓 / 装饰；远距离不强求从模型判断，选中后显示品质。展示间可以强化，实战降低粒子密度。
- **性能与公平：** 高档也不常驻铺满粒子；给装饰特效统一预算与降级开关。获取音只表达获得的仪式，不改变攻击命中反馈，不暗示伤害提升。
- **玩家文案：** 在外观详情明确标注「品质影响外观，不影响属性」。先做同一剑 / 同一弓的五档并排稿，同时检查灰阶缩略图轮廓和正常配色下的 UI 辨识。

**出图指令要点：** 同视角、同尺寸、同剑刃长度 / 弓握点；五把并排；各自大胆二次元配色；品质只用下方灰绿蓝紫橙标签；装饰层次逐档增加；背景与光照一致；先确定轮廓，再决定局部发光。
