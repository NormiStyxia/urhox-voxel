# R8：近战命中反馈与武器重量感

日期：2026-11-15。范围：只读代码、公开资料调研及本文件；未修改代码/资源，未启动 Runtime、测试、构建或提交。本文供实现 worker 拆任务使用。

## 0. 最关键的五条

1. **不能诊断成“完全没写 hitstop/特效”。** 成功结算确实设置玩家/目标顿帧、部位反冲、定向池化粒子、材质音、镜头包络；先核对 Web 运行版本与 `Isolated error`。本次没有 Web 画面/日志，最终观感为 **UNDETERMINED**。
2. **白闪目前没有可靠保证。** `EnemyVisual.Init` 检查 `MatDiffColor` 非空，再乘 RGB×1.6；参数存在不代表 shader 消费它，乘亮也不等于混白。`NomiVoxel.xml` 的 shader 不读取该参数；而当前敌人实际上由 `CreateVolume` 创建、继承世界调色板材质，并未显式加载 `NomiVoxel.xml`。这两种颜色来源必须分开处理。
3. **顿帧有值，但冻结与接触不完整。** 玩家动作时钟确实暂停；敌人 `stateTime` 暂停，`age` 和反冲却继续走，死亡分支绕过 `hitStop`。近战从 `hit_on` 即检测整个扇区，刀刃此刻才开始扫，可能出现“剑在身侧停住、火花在敌人身上”的错位。
4. **先将反馈集中到接触的 0–120ms，保留40/80/100ms批准基线。** 成功命中同帧出现接触白核、部位白闪、材质撞击音、姿态停势；停势解除后再回弹、击退、随势回收。普通轻击不需要更大的全屏震动。
5. **共享32/64粒池够做第一轮，先修优先级。** 当前轻软命中无白核，重击核排第11槽，池紧时先丢；击杀又跳过即时粒子，250ms后才碎散。应先保证一次接触的可见锚点，再发装饰碎屑。

主方案 §14/§18/§19/§20 与2026-11-15背挂合同仍有效。下文：**A=已有裁定；B=本次建议，待Lead采纳；C=可选调参实验，未经Web对比不得默认启用。** 本文没有自动修改伤害、取消窗口、poise、挂点或敌人玩法。

## 1. 命中现状核对

### 1.1 真实调用链

场景顺序：`UpdateCombatActions → CombatMoves.Update → CombatAnim.GetMotion(stepDt,realDt) → 敌人Update → 箭Update → Nomi基础Animate → CombatAnim.Apply → UpdateCombatRig → CombatMoves.AfterPose`；镜头在PostUpdate消费。

剑：`AfterPose → StrikeZones → Hit.QueryZone → 遮挡/每段去重 → Hit.Apply → enemy.ApplyHit → PrepareImpact/伤害/甲/poise/受击/粒子 → CombatMoves.Feedback → 玩家/目标stop、镜头、音效、HUD → CombatFeedback`。

箭：`Projectile.Step → Hit.Apply → enemy.ApplyHit → Feedback(...,arrow=true)`，成功后穿透或附着部位。普通箭只顿目标，满蓄弱点箭也顿射手。相机、音频、粒子按真实时间运行。

**事件所在位置：** `Hit.lua`是几何/校验/结算适配器；8槽借用`HitEvent`在`CombatMoves.Feedback`组装，并非`Hit.Apply`自行广播。`EnemyBase.OnHitEvent`已存在，但剑/箭info未传`deferPresentation=true`，场景也未调用该consumer，所以目前走**立即表现兼容路径**。不能因为没调用OnHitEvent就声称敌人粒子完全没发。

### 1.3 确定缺口与待验证假设

**代码能确定：** 无专用命中武器Flash；轻soft无白核；击杀无即时粒子；重击击退字段不消费；敌人age/反冲不停、死亡不消费stop；低画质关Rig整套特效；大dt可只结算hitPending而不画活动刀光。shader未声明/未读取的uniform不会因为Lua写入同名参数就自动生效。

**高概率但未看画面：** 扇区提前命中、射点埋面、正前方镜头投影弱、乘亮不显白、2.5cm微移太小。不能写成实测结论。

量级检查（纯投影估算，非Web实测）：以390逻辑像素高、55°垂直FOV、目标约5m，.01m纯横向相机位移约`390*.01/(2*5*tan(27.5°))=.75px`；.025m约1.87px。前向位移投影更弱。不能只看“已经写.01m”就断言玩家必能看到，也不应直接把幅度放大十倍；优先屏幕投影方向与接触锚点。

**只能Web日志确认：** shader编译失败、材质nil、Safe断路、音频解码/自动播放锁、池满、运行旧版本。`CombatState.Isolated`失败后该key暂停3000ms，日志最少5000ms才重记；查`Animation.Apply`、`Rig.Update/Rig.Visuals`、`Combat.AfterPose`、`Enemies.Update`、`Audio.Play`。没有日志不能断言pcall已经吞掉了某效果。

## 2. 设计依据与来源

### 2.1 时间组织

Swink《Game Feel》的实时控制、模拟空间、修饰反馈框架强调控制与表现共同形成触感：**按键有即时可见响应，预备慢、经过接触点快、接触受阻、随后有惯性回收**。修饰不应掩盖判定和模型错位。[S1]

`Juice it or lose it`与`The art of screenshake`展示动画、粒子、声音、震动的组合价值；它们不是“所有招式100ms stop”的依据，也不能把2D像素数直接当3D米数。[S2][S3] GDC镜头数学资料见[S10]，只借鉴有界、可控、按时间计算的包络思想，不挪用未知的商业参数。

本项目调参范围：轻接触2–3帧（33–50ms），重/连段终结4–5帧（67–83ms），关键破甲/击杀约6帧（100ms），特殊满蓄弱点约7帧（117–120ms）。这是**本项目建议范围，不是竞品统一实测标准**。按真实秒计，30fps不翻倍，120fps不缩短。

## 3. 逐档规格

### 3.1 共用定义

- 60fps一帧16.667ms，只用于对照；实现用秒积算。先取帧初剩余值：`held=min(realDt,stopRemaining)`，再令`poseDt=realDt-held`、`stopRemaining=stopRemaining-held`；不能用已经扣减的剩余值再次扣动作时间。无敌/输入/冷却/HUD/音频/粒子/白闪/相机走realDt。
- 近战冻攻击者动作/root motion与受击者动作/root motion，不冻无关敌人/环境/已发箭弹；目标不能在stop中推进新的出手。镜头和输入继续。普通箭只冻目标，满蓄弱点例外沿现有合同。
- 攻击者同swing以首接触取max，目标各有独立stop；同击破甲/击杀/弱点按维度升档，不加总时长/粒子。每段每敌一次，死亡不重复升档。
- **W(T,I)**：部位白闪T毫秒、峰值白混合I（0原色、1白）。接触立即峰值，保持`min(16.7ms,T/3)`，余段按`(1-u)^2`归零；走realDt，发光见§4。
- **K(A,D,T)**：镜头峰A米、方向D、总T毫秒。D为斩向投影到屏幕right/up；0→峰12ms→25%反向小峰→0，二次衰减。最终总offset≤.03m，不改yaw/pitch/roll，不累计进跟随位置。
- **N(D,T)**：小怪击退D米、目标停势后T毫秒，以`x=D*(1-(1-u)^3)`完成；每步Base.Move，墙/柱/边缘截断即停。Boss普通D=0、失衡既定.6m另算。
- 粒子：c方屑、s扁火星、x交叉白核、p甲片；速度m/s，寿命s。白核.06s、.12–.18m，先抢槽。仅FX位置沿normal外偏.02m避免埋面，不改结算点。颜色soft苔黄绿/米白、armor赭金/暖白、stone石灰/暖白、core浅青/白；靠形状+声音区分。
- 音效复用现有cue：主体0dB，whoosh−8/−7/−5dB、heavy低中频−3dB、core强调+2dB，总线留6dB余量；同击≤3声部、预警优先。以下所有新增强度/组成/曲线属B；A的时长/位移明确保留。

## 4. 体素白闪：可靠实现路线

### 4.1 先分网格颜色来源

`assets/Materials/NomiVoxel.xml → Shaders/BLGL/VoxelCharacter.shader`把`COLOR.rgb`当真实RGB，经sRGB转换写ALBEDO；只声明`color_is_srgb/roughness_value`。当前敌人`EnemyVisual.Init`没有加载它，而是`VoxelPhysicsWorld.CreateVolume`自动继承`world:GetPaletteMaterial(bank,domain)`；依据`.emmylua/VoxelPhysicsWorld.d.lua:831–844`和`voxel-physics.md`，这种网格`COLOR.r`是索引/255、`COLOR.g`是断面标记。

所以**不能直接把NomiVoxel挂给敌人，再往MatDiffColor写白色**：可能不白且破坏调色板色彩。初始化记录一次实际material name、GetSurfaceShader、bank/domain和效果uniform契约；不要每击反射探测。

### 4.2 首选：颜色路径保持不变，专用受击SurfaceShader混白

**B建议**新增敌人专用`EnemyVoxelHit.shader`与材质模板，保留palette/PBR/断面处理，仅加`hit_flash`（0..1）。不要修改共享NomiVoxel缓存材质，不每击改world调色板。以下只是待实现的shader契约，本轮未写入资源：

```glsl
uniform float hit_flash = 0.0;
// base_albedo/base_emission 由当前网格正确的颜色路径产生。
float f = clamp(hit_flash, 0.0, 1.0);
ALBEDO = mix(base_albedo, vec3(1.0), f);
EMISSION = base_emission * (1.0 - f) + vec3(1.0) * (0.65 * f);
```

0.65发光只是初值，不能依赖Bloom才能读到；Web检查曝光/色调映射后不泛成大光团。roughness/metallic/specular、剔除/深度策略保持原来语义；不加透明叠层、点灯或改阴影形状。

**Palette路径：** 按`voxel-physics.md`相关章节及VoxelHologram示例，使用`#include "res://Shaders/BLGL/Voxel/VoxelPalette.shaderinc"`；`voxel_palette_index(COLOR)`和`voxel_palette_uv(index, VOXEL_PALETTE_*)`寻址；颜色层解码sRGB，PBR层不解码，emissive alpha强度按文档恢复。初始化一次`mat:SetSurfaceTexture("palette_tex", world:GetPaletteTexture(volume:GetPaletteDomain()))`。bank/slot由引擎写入，禁止猜纹理槽号或自己设置旧palette_bank坐标。

**真实RGB路径：** 若将来敌人改CustomGeometry/StaticModel的NomiVoxel网格，则沿原`COLOR.rgb→颜色转换`再mix；另建相应模板，不能把palette shader给RGB网格。人物/剑/预览各自材料不受影响，默认flash=0原样。

### 4.3 核实的接口、归属与缓存

- `.emmylua/Material.d.lua`已声明`Clone(cloneName)`、`GetSurfaceShader()`、`SetSurfaceShader(resourceName)->boolean`、`SetSurfaceTexture(name,texture)->boolean`、`SetShaderParameter(name,Variant)`。
- `.emmylua/VoxelVolume.d.lua:136/140`已有`SetMaterial(Material)/GetMaterial()`；world的palette texture/domain接口也已声明。不存在自动的`Enemy:SetFlashWhite`或任意`SetVertexColor`捷径；不能为受击改grid/rebuild。
- 材质按**敌人实例×受击组×palette bank/domain**预建。Boss头/前腿/背甲/核心，虫壳/腹/腿可分组；同敌人同组同bank可共享，不同敌人或独立闪组不能共享可变Material，否则一起闪。不同bank的palette定位也不能混用。
- 预存9档Variant（0、1/8…1）；命中只复位flashAge和目标峰值，曲线跨档时才SetShaderParameter，不每帧new Variant/Color。失活/重置/死亡/退出恢复0。
- clone/替换材料由EnemyVisual持有并释放；不Dispose world/cache共享原材质。若模板/纹理失败，保留原材质、记录一次错误，白核/姿态/声音照常；`flashSupported=true`必须代表已建立明确效果契约，不能靠MatDiffColor存在猜测。

### 4.4 替代路线比较

| 方式 | 问题/效果 | 选择 |
|---|---|---|
| MatDiffColor×1.6 | shader可能不读，乘色不去饱和、暗处仍暗 | 不作为白闪验收方案 |
| 仅emissive | 仍需声明/读取uniform，可能保留原色或Bloom过强 | 辅助，不独自承担白闪 |
| shader混白+小emission | 单pass、无需重建，保原色又有瞬态确认 | **首选**；两种网格分别保留颜色来源 |
| 改palette entry | 同world/bank同色槽的别的实体会串色，上传纹理/并发恢复难 | 拒绝 |

### 5.1 事件/方向合同

profile表初始化预建，id包括`light_1/light_2/third/heavy/full/critical/kill/arrow_weak/arrow_mid/arrow_full/arrow_full_weak/break/stagger`，不每击new配置。Event保留现有weapon/tier/part/material/pos/dir/normal/swingId/broke/staggered/killed/weak/damage，补combo/full/critical/impactDir/profileId。

`dir`继续表示玩法前向/弹道，`impactDir`表示视觉斩向，`normal`表示表面法线；不能为了换火星方向改变击退。优先从命中子采样刀尖速度取impactDir；退化时light1/2分别±角色right、third向下+forward、heavy弧切向、箭弹道。

借用Event同步消费，延迟保存只拷标量/预建快照，不保留8槽会覆盖的table。死亡用已有deathImpact快照。新增字段每次包括false/nil都覆盖，防前一次critical/full泄漏。

## 6. 性能与安全预算

### 6.1 硬预算

| 项 | 低档 | 中档 | 规则 |
|---|---:|---:|---|
| 活跃共享粒子 | 32 | 64 | cube+flat合计；16关键预留沿用，不建第二命中池 |
| 常态cube/flat | 20/12 | 40/24 | 白核占flat；关键可淘汰旧装饰，预警独立不淘汰 |
| 每次soft/armor/heavy/break | 6/8/11/12 | 同左 | 多目标可各降1核+2屑，不全部漏核 |
| 小怪/Boss解体 | 8–12/16 | 12/24 | 总池约束，替代普通burst |
| 刀带/残影 | 4段/0 | 8段/2 | 距离补段，active+60ms尾 |
| 装饰地环 | 0 | ≤2 | 预建8边轮廓、有地面才显，非危险预警 |
| 新动态灯/刚体 | 0/0 | 0/0 | 单pass白闪；碎片仅视觉，不进TimeObject |
| 音频全场声部 | 8 | 12 | 每击≤3，预警>玩家受击>破甲>普通 |
| 命中Event/镜头group | 8/32 | 8/32 | 固定容量，group当前new/淘汰改原位池化 |

### 6.2 热路径/帧时

- 新增反馈稳态**不新增Lua table/闭包/Material/Node/Component/mesh/volume构造**，不写grid、不Rebuild、不加灯，不每击GetPaletteMaterial。Vector3原生值类型必须整体写回，不能依赖table mock引用语义。
- 当前链路仍有分配：Hit.QueryZone结果/排序、info/result、数字记录、Envelope group、音频handle/pcall闭包。不能声称全系统零GC；新增profile/scratch走预建，后续池化这些已有项时保持嵌套爆炸与多目标结果不互相覆盖。
- 每粒两个预建mesh仅一个可见；64槽可能接近64次提交，**池化不是一次drawcall**。普通粒子三角约≤768（64×12），刀带另计，先测提交与CPU。
- 目标增量CPU≤1ms、GPU≤2ms（待设备测）；60fps总16.67ms、弱机30fps33.3ms。记录P95/P99、提交数/材质变体，不只看平均FPS。
- 参数只在9档跨档时提交，每次flash每组约≤9写；低档5档即可。不能对全敌每帧重复Set同值。
- 后续Web预热后10秒空挥/10秒命中对比Lua堆趋势/分配/P95/P99，100击+死亡/重置后新材质/节点/几何计数不增。本轮没有执行这些测试。

### 6.3 边界

- 群攻5目标只取一次攻击者stop/相机，各目标闪/核独立；不叠成400ms。
- stop内输入/无敌/冷却继续，恢复不补发hit_on/旧音效，仍每段每敌一次。
- 失焦/菜单/隐藏/切换/骑龙/死亡清武器impulse/刀光/Flash，敌人flash归零；遵守背挂消隐合同，不启动停止的预览、不复活hidden。
- 池满优先核，回收旧低优先装饰，记录evicted/dropped；不分配第65粒，不删危险预警。
- 位移逐步HasGround/墙柱截断，尘/环不悬空；视觉不推hurtShape下岛缘。
- shader失败保原材质+白核+姿态+声音，记录一次原因与flashSupported=false，不猜API/改服务环境。

## 合同：R8 玩家/敌人同步 HitEvent（2026-11-15 W1）

- Hit.Apply 仍只结算一次，成功结果附 resolved=true（无效/拒绝为 false）。近战 info.deferPresentation=有 OnHitEvent consumer；Feedback 完成字段和 stop 后同步调用 enemy:OnHitEvent(e)。无 consumer 木桩交场景共享粒池。箭维持当前 legacy 表现，直到其 owner 成对接入 defer；不得重复表现。
- 8 槽借用事件，每次完整覆盖：kind='hit', enemy, swingId, weapon, tier, part, material, pos, dir, normal, damage, poise, broke, staggered, killed, weak, combo, full, critical, profileId, impactDir, flash, flashPeak, stop, attackerStop, resolved, presentationConsumed。combo=0/1/2/3；full/critical/weak 等始终 boolean。critical 只映射弱点或显式标记，不新增概率/倍率。
- dir 保留玩法朝向；impactDir 是视觉斩向单位向量，不改变击退。flash 单位秒、flashPeak=0..1；stop 为目标顿帧秒数，attackerStop 为玩家顿帧秒数。敌人复制到自己的预建 impact/deathImpact，不保存事件表。
- profileId：light_1/light_2/third/heavy/full/critical/kill/break/stagger/arrow_weak/arrow_mid/arrow_full/arrow_full_weak。优先 break > stagger > kill > critical > 来源，各维度取最大、不累加。轻/第三 stop=.04，重/满=.08，破甲=.10；kill/critical 不擅自提高来源 stop。闪白：轻 .06/.85，第三 .08/.95，重 .08/1，满 .10/1，弱点 .09/1，kill/break/stagger .10/1。
- OnHitEvent 消耗一次 pending token 后返回 true；legacy/重复/不匹配返回 false。成功击杀当帧仍有白核，不被场景 killed 过滤。白闪/FX 走 realDt；pose/recoil/knockback 走扣停顿后的 poseDt（敌人 worker 负责）。

### 本轮玩家侧落地边界

- P0 采用 Lead 允许的保守路径：`AfterPose` 在 hitPending 同帧调用 `rig:ShowContactArc(zone)`，复用 8 段（低档 4 段）刀带展示原判定扇区的样本。跨 hit_on/off 的大 dt 也给一帧样本。原 QueryZone/reach/伤害/去重不变。**尚未实现刀根/刀尖子采样窄相位；实体剑刃与接触点错位仍未解决。** 因此本轮不增加 CombatAnim/AnimClips 采样 API，impactDir 用已定义的横斩/反斩/下劈退化方向。
- `rig:HitImpulse(event)` 只旋转剑网格子节点：轻 .8°，第三/重 1.5°，stop 结束后 50ms 回零；刃白轻 40ms、第三/重/弱点/击杀 60ms，复用既有 blade flash。pivot、SetSwing、GetHit、GetAfterimagePose 不变。SetTrail(false) 只关闭装饰残影/蓄力粒子，保留 essentialHit/arrival 与最多 4 段刀带；Cancel 使用既有 StopCombatVisual 清理，hidden 拒绝迟到事件。
- 镜头按命中组局部时间从零开始单次 punch，投影 camera right/up，命中与落地偏移合成后 clamp .03m；独立角色跟随位移不被这个 clamp 截断。低档仅关近战动作 pulse，弓 FOV 不变。
- profile 的 flash/flashPeak 是统一事件元数据；敌人本轮实现保留批准的实际 60/80ms 白闪曲线，不能把 HUD 的 profile 值称作已实测的敌人可见闪白时间。
- 新反馈层的 8 个事件、32 个镜头组、12 个数字记录、音效 opts 与方向 scratch 均预建。离线 mock 的 Feedback+Shake 1000 次热态毛分配为 0 B/次，100 次武器命中不新建体积/材质/几何。**不是全链路零分配**：现有 Hit.Apply 的独立 info/result 快照、音频 handle 及原生 userdata 分配不在这项测量里；为保持并行 owner 的快照所有权合同未替换它们。复用白刃仍可能增加一个短时活跃 draw，不能把“零新几何”写成“零提交增量”。
- 手感、真实刀刃对齐、暗处可见度、移动端毛分配/批次和音画峰值 ≤30ms 均需 Web/真机验收；未启动本地 Runtime。
