# R13：开放世界里，解谜能力怎样同时进入战斗

调研日期：2026-11-16。范围：只研究公开资料，不运行项目、不修改游戏代码。版本限定为《旷野之息》2017 年 Nintendo Switch 本篇、《王国之泪》2023 年 Nintendo Switch 本篇、《渡神纪：芬尼斯崛起》2020 年本篇；不混入《灾厄启示录》《封印战记》、DLC 或 Switch 2 特有功能。未实测具体补丁版本。

## 先给独立判断

**“探索能力能用于战斗”很有先例；“因此把它做成第三把互斥主武器”不是这些案例的共同答案。** 两部 Zelda 把近战、弓、特殊能力放在不同输入通道；《渡神纪》甚至把剑和斧分别直接放在轻、重攻击键上。它们证明的是工具与战斗可以共存，不是证明统一轮盘或高频换武器一定合适。

本项目的“剑／弓／时间法器统一轮盘、冻结绑定法器”可以成立，但有一个比切换 CD 更早的问题：**玩家选法器后，能不能把眼前这场普通战斗打完？** 如果法器只有低伤害和强冻结，冻结又能为剑提供稳定安全输出，那么合理操作自然会变成“法器冻住→切剑输出→等冻结恢复→再切法器”。降低法器伤害反而可能加强切换动机。这里是设计推论，不是玩家行为统计。

切换 CD 只会提高这一循环的成本，并不会自动让三种玩法各自完整；严重时会变成“解谜装备被敌人撞见，想换剑却被锁住”。建议先讨论法器的独立应敌能力与敌人是否强制克制，再讨论是否需要切换 CD。

## 1.《塞尔达传说：旷野之息》：Stasis 和 Stasis+ 必须分开说

### 已核实的输入与装备结构

Nintendo 官方《Explorer’s Guide》写明：按 **L** 进入已选符文，按 **A** 对兼容对象使用；静止器教程紧接着要求装备铁锤、敲击被锁住的巨石来积蓄动能。[B1，书页 53–54、61–64]

GameWith 的操作表补全了三条输入通道：[B2]

| 操作 | Switch 默认输入 | 选择入口 |
| --- | --- | --- |
| 近战攻击／蓄力 | Y／长按 Y | 方向键右选择近战武器 |
| 拉弓／射箭 | ZR | 拉弓状态下，方向键右选择弓，左选择箭 |
| 使用符文 | L，目标确认 A | 方向键上选择符文 |

这是**战斗中可操作的独立装备类别与工具选择**，不是“剑、弓、静止器三选一占同一个主手槽”，也不是角色切换、营地换装或只能从两把预装武器之间切。其符文选择是横向快捷列表，不能称为本项目设想的统一武器轮盘。[B2][B4]

### 对物件与敌人的规则不同

- **基础 Stasis（静止器）**：停止兼容物件的时间，受到的击打可以储存动能；不能把基础版描述成开局就能冻住怪物。官方教程用的是齿轮、滚石、挡路巨石。[B1]
- **Stasis+（静止器+）**：Hateno Ancient Tech Lab 升级后，才增加对敌人的时间锁定。Zelda Dungeon 记录强敌会更快挣脱；被锁定的敌人也不能再叠加燃烧、冰冻、触电等这些元素状态。这里的时间锁定与冰元素冻结是两回事。[B3]
- 符文用后有回充。Zelda Dungeon 对物件给出最长锁定与之后冷却的说明，并记录提前解除会缩短回充；本报告不把物件数值移植到敌人，也不把符文回充说成“切武器 CD”。[B3]

### 实际一段游玩怎样发生

官方教程情境：遇到旋转平台→L、A 锁住齿轮→赶在效果消失前穿过；随后遇到挡路巨石→对巨石使用 Stasis→用铁锤敲几下→时间恢复时石头飞走。[B1]

战斗情境：已取得 Stasis+，遇到难追或逼近的敌人→用 L、A 锁住目标→用已有近战或弓制造输出窗口→效果结束，回到正常移动、盾防与攻击；回充限制的是下一次锁定机会。[B2][B3] **这段描述是基于已记载规则组合的可行操作例，不是“每场战斗都必须这么打”的主张。**

官方还教玩家引敌人追赶后丢遥控炸弹、继续跑、在敌人接近炸弹时引爆，以免消耗武器耐久。探索工具直接进入战斗，且没有要求先清掉仇恨。[B1，书页 27–28]

### 限制、切换与证据边界

1. 使用武器击打不会立即清掉物件的 Stasis：官方巨石教程直接证明这一点。它证明“能力生效后可接武器动作”，**不等于证明所有主动换符文、换装备的组合都保留所有效果**；后者本轮未逐项核实。[B1]
2. 快捷列表降低找装备的操作成本；本轮已读正文没有明确给出打开各类快捷列表时的世界暂停规则，也没有可靠的通用换装秒数，因此不写“零耗时切换”。[B2][B4]
3. 不能把本作当成“完全不鼓励切换”的样板：官方明确介绍武器会损坏，须备库存，耐久会迫使玩家更换；弓、环境工具又提供不同解法。它只是没有通过同一主手槽强制执行“近战→法器→近战”流程。[B1，书页 17–20]
4. 因此最值得借鉴的是**同一工具对物件和强敌采用不同控制规则**，而不是照搬耐久或断言玩家低频切换。

## 2.《塞尔达传说：王国之泪》：回溯主要控制物件，选目标时给思考空间

### 已核实的输入与选择结构

StrategyWiki 的操作表（按钮以图片呈现，本轮另读取了图片 alt）记录：[T3]

- **Y**：近战攻击。**ZR**：使用弓。
- **轻按 L**：使用当前右手能力；**长按 L**：更换能力。
- 方向键右更换近战武器，左更换盾，上更换素材。

因此，右手能力选择与近战武器选择分开，弓也有独立输入。长按 L 的能力选择不能说成剑／弓／回溯统一占位。该页是社区操作表且标为待补全；这里只使用已列出的上述按钮，不从空缺部分推断额外操作。

### 回溯不是 Stasis+ 的换皮

官方将 **Recall（倒转乾坤）**定义为倒放一个物件的运动，并明确给出三种情境：[T1]

- 将敌人投来的物件按原路退回去。
- 让漂走的船或平台回到原先位置。
- 对自己脚下的飞行器回溯，以修正走偏的路线。

Zelda Wiki 补充：只倒转目标物件的轨迹，不倒转整个世界；效果可提前结束，也会随时间结束。[T4] **已读来源足以证明“回溯物件可造成战斗后果”，不足以支持“像 Stasis+ 那样直接锁住普通敌人本体”。不要将二者合并成同一种敌人控制技。** 本轮未取得逐类目标白名单，故不对所有特殊敌人／组合物件作绝对排除结论。

最有用的一条官方操作说明是：**选择倒转对象时，时间停止**，玩家可以从容选择；不是要求玩家在敌人挥击过程中高速切菜单。该暂停来自 Recall 的目标选择阶段，不能推导成所有能力瞄准或所有菜单都有同样规则。[T2]

### 实际一段游玩怎样发生

玩家在岸边探索→船漂远，选择 Recall 把船带回→乘船经过敌人据点，被投掷物攻击→再次选 Recall，在停止的时间里选中来物→把投掷物送回攻击者→后续可以选择近战、射箭、绕开据点。这里让探索与战斗共享的是**可解释的物理规则**，不是把遇敌自动变成另一套禁止工具的状态。[T1][T2]

官方同时建议 Ascend（通天术）在战斗中寻找高处、突袭或逃开攻击；Fuse（余料建造）为装备增加属性，并让不同组合产生点火、破墙等效果。探索与战斗共用的不止一个特殊按钮。[T1][T2]

### 限制、切换与证据边界

1. 冷却：已读官方页面没有给 Recall 通用回充秒数；社区论坛有“无冷却”的说法，但本报告不据此落精确结论，也不把贤者能力的冷却混入右手能力。
2. 切换是否解除：已读来源说明可主动结束和自然结束，但未明确列出切到另一右手能力／更换武器的所有结果，**未核实**。[T4]
3. 选中能力与选中物件是两步。官方确认的是第二步时间停止；本轮没有把能力轮盘自身的暂停行为单独核实。
4. 来源展示能力提供额外机会，没有提供“每场必须用 Recall”的规定或切换次数统计。因此只能判断它支持环境解法，不能声称本作玩家普遍只切一次。

对本项目最直接的启发：**时间能力未必要对敌人本体施加同等强度的控制。** 同一个法器可以对机关执行稳定、长窗口的解谜操作，对敌人投射物执行反制，对强敌只提供较小的应敌机会。这样能保留探索身份，减少必须“先冻结再换剑”的单一解。此段是设计建议，不是 Zelda 的完整目标规则复刻。

## 3.《渡神纪：芬尼斯崛起》：剑、斧、弓和神力靠输入分层共存

### 已核实的输入，不是武器轮盘换三套主手

Shacknews 在发售前一日发布的默认操作表记录 PS4／PS5 输入：[F2]

| 操作 | 默认输入 |
| --- | --- |
| 轻攻击 | R1 |
| 重攻击／持物时投掷／瞄准时射箭 | R2，按上下文变化 |
| 近战神力界面 | L1 |
| 自由瞄弓／远程能力界面 | L2 |
| 格挡 | L1 + R1 |

Ubisoft 的官方介绍明确轻攻击是剑、重攻击是斧，弓负责射击；因此玩家按 R1、R2 就能交替出剑、出斧，不能把这里的招式衔接误写成每次要开轮盘更换主武器。[F1][F2]

神力属于另一层输入。例如 Herakles’s Strength（赫拉克勒斯之力）隔空搬举、投掷重物，是物理解谜的重要手段；Apollo’s Arrows（阿波罗之箭）可操控飞行中的箭，还可调整速度；Athena’s Dash、Ares’s Wrath、Hephaistos’s Hammer 则提供冲击和大范围伤害。官方也直接记载，Herakles’s Strength 的战斗运用可把玩家拉向敌人。[F1]

### 约束来自资源和动作，而不只是换装次数

Ubisoft 介绍这些能力消耗体力，耗空后仍可以战斗，但回充需等待；同时普通剑斧攻击、闪避、格挡构成战斗主体。[F1] 这份资料是 **2020-09-10 的官方试玩介绍**，与发售操作表共同使用：可据此确认输入与设计方向，但不拿它作最终补丁精确伤害、体力消耗或技能冷却表。

具体神力是否另带个别冷却、打开神力界面是否减速、神力施放中能否被所有其他输入打断：本轮已读来源没有逐项证明，**不写成“全部无 CD、菜单暂停、任意取消”**。

### 实际一段游玩怎样发生

按官方介绍可组合的例子：探索路上隔空搬石头放到压力板→发现需要引导箭穿过多个目标的奥德修斯挑战，改用可操控箭→附近怪物逼近，直接按轻攻击用剑应敌，遇盾敌改用重斧攻击→若被围住，额外用神力打出空间→结束后回到原解谜目标。[F1][F2]

这段流程不需要先进入独立的战斗装备模式再离开；但不能据此说它“没有鼓励混用”：官方恰恰用快速、灵活、空中攻击、完美闪避减速、连续组合招式来介绍战斗，并说明重斧可以破盾。[F1]

**它是输入结构的好参考，战斗节奏却未必适合本项目。** 把它拿来证明“剑／弓／法器可以各自打完整场、无需频繁混用”会超出证据。

## 三例真正能比较的内容

| 维度 | 旷野之息 | 王国之泪 | 渡神纪本篇 |
| --- | --- | --- | --- |
| 战斗中能否使用探索能力 | 可以；升级 Stasis+ 可直接锁敌 | 可以；回溯敌人来物等 | 可以；神力参与战斗与物理解谜 |
| 近战／弓／能力是否同一互斥槽 | 否，独立输入与选择类别 | 否，右手能力与武器分开 | 否，剑斧直接输入，弓／神力另有层 |
| 是否属于战斗完全不可切 | 否 | 否 | 否；很多操作甚至不需要换装 |
| 是否只能营地更换这些工具 | 否 | 否 | 否；不要混同升级地点与使用地点 |
| 时间／资源成本的已读证据 | Stasis 自身回充，武器耐久 | Recall 选目标暂停；其精确回充未核实 | 神力消耗体力；最终数值未核实 |
| 能否据此证明每场低频切换 | 不能；耐久会迫使更换 | 不能；无频次统计 | 不能；官方反而强调快速组合 |

**本专题没有找到“战斗完全禁用探索能力，同时靠收武器才能恢复解谜”的正面样板。** 这里只是上述三例的结论，不代表市场上没有此结构，也不代替其他专题对锁装、营地换装作品的调查。

## 给本项目的两种不同结构：从一段游玩判断代价

以下均为本项目建议，不是对上述作品规则的转述。暂不提出秒数，也不代替用户决定切换 CD。

### 结构 A：法器确实是第三把可独立应敌的主武器

三把装备占同一当前武器位置，用同一个轮盘切换；冻结、碎时、回溯都明确属于时间法器，持剑不会额外长出一个冻结热键。法器有自己的可重复普通攻击／蓄力攻击，伤害可以低一些，但普通路敌不能逼玩家非切剑不可。剑、弓同样要有不依赖冻结的基础应敌空间。

一段游玩：玩家拿着法器回溯空岛机关→守卫过来，玩家保留法器，用中距攻击、移动和一次冻结应付→怪物离得太近时可以后退继续用法器，也可以选择打开轮盘改拿剑→用剑结束，或者直接甩开敌人继续探索→若需要下一处时间机关，主动切回法器。

这里**没有必选的“冻住→剑→法器”循环**，因为用法器打完或离开都成立；“偶尔换剑”是玩家对距离和手感的偏好。这个成立条件需要战斗原型验证，不能只靠一段设定文字宣称实现。

代价与检查点：

- 法器若低到只适合开冻结，就会变成辅助起手器，三主武器的承诺落空；降低伤害要与射程、命中便利和控制价值一起调。
- 每种主武器至少能处理常见路敌，不宜给普通怪铺满“必须先冻／必须射箭／必须切近战”的硬门槛；特殊谜题或少量特别遭遇可以例外并清晰提示。
- 冻结收益若无条件适配剑弓，追求效率的人仍会自行循环。不要先加全局切换 CD 掩盖这一收益结构；也不要为了防连招而让切出法器立刻清除机关效果，破坏解谜操作的可理解性。
- 敌人仇恨只描述敌人追不追，不应同时决定玩家能不能收刃、开轮盘或使用当前法器。攻击动作中的短暂切换窗口与整场仇恨锁装是两回事。

若坚持用户当前“三把主武器”的定义，优先讨论这条结构。它要承担的是**把法器做完整**的成本，而不是再添加一项菜单限制。

### 结构 B：主武器选择与时间工具选择分层，法器是随身工具

这是对“三把互斥主武器”前提的真正替代，不应包装成结构 A 的小调整：剑／弓是普通攻击装备，法器通过专门工具输入临时举起，冻结仍由角色实际拿起法器施放。界面可以统一展示在同一个环弧里，但必须明确“选武器”和“选当前时间工具”各自改变什么，不能靠外形统一掩盖两种状态。接近 Zelda 的，是这种输入和状态分层。

一段游玩：玩家选择剑作为普通攻击装备，正用法器举起状态回溯机关→怪物出现，取消当前目标操作，按普通攻击出剑→需要喘息时按工具输入举起法器并冻结→回到剑继续打，或利用冻结穿过门离开→之后按工具输入继续解谜，不必先等仇恨结束。整个过程可以不开武器轮盘，但**实际仍在交替武器动作与工具动作**。

代价与检查点：

- 它解决的是访问成本，不保证减少技能混用次数。若冻结对所有敌人都很划算，玩家可能每次回充就用一次，仍可能违背“不做频繁操作”的目标。
- 需要一个工具输入／手机按钮或清晰的上下文层，UI 负担比单一当前武器更大。
- 法器身份会偏向“工具＋控制技能”，独立主武器手感与未来同槽武器扩展不如结构 A 清楚。
- 如果用户说“冻结绑定法器”的真实意思是“只有把法器选为当前主武器才能冻结”，这条结构不满足该要求，应放弃，而不是偷偷自动切回剑。

两条结构都允许探索与战斗共存，但承诺不同：**A 让选法器本身成为一种能持续玩的战斗方式；B 让时间工具随时可访问。** 在这件事决定前，不宜先拍板切武器 CD。

## 自审结果

- 未把角色切换、同输入的剑斧招式、右手能力选择统称为武器切换。
- 未把物件 Stasis、Stasis+ 对敌时间锁定、元素冰冻、Recall 倒放轨迹混为一谈。
- 未给项目设定切换 CD 秒数；没有用未核实的作品 CD 为其背书。
- 现成作品情境与本项目建议分章标记；可行操作例没有写成每场必做流程。
- 当前证据空缺明确保留：快捷列表暂停、各作完整切换取消规则、Recall 的精确回充、最终补丁神力数值、实际玩家切换频次。
