# R16｜弓稀有度造型阶梯与风格家族

日期：2026-11-17。用途：二次元体素探索战斗游戏的弓外观设计、生图与后续建模交接。本文为调研与设计建议，不修改玩法、数值或代码。

## 先给结论

| 决策 | 建议 | 原因 |
|---|---|---|
| 五档如何区分 | 普通＝好看的基础轮廓；优秀＝成对端帽与分材质；稀有＝明确家族符号；史诗＝结构变体；传说＝独有的大轮廓 | 不能只靠加金边、加宝石、加光效升级；缩小后仍应看得出差别 |
| 每档是否只有一种风格 | 八个家族均覆盖五档，共 40 个外观方向；家族决定配色与形状，稀有度决定结构层级 | 普通也可以是和风、哥特、机巧；传说也可以是木质、铁黑、珊瑚红 |
| 与已有传说剑的关系 | 继承第 3 把剑的深色粗轮廓、清晰切面、大色块、少花纹、一个主焦点；蓝金只留给适合的家族 | 统一的是画法和形状尺度，不是把所有武器涂成蓝金 |
| 弓弦 | 默认实体纤维弦；能量弦是少数家族的可选表达 | “二次元弓几乎都是发光弦”没有可支持的总体样本统计；亮色线也不能直接等同自发光 |
| 适配拉弓 | 所有外观共用左手握点、箭台、弦中扣点、弓梢锚点和拉弓行程；装饰避开手、箭、弦的运动空间 | 外形不能造成实际射速、射程、命中、蓄力或弦震差异 |
| 图鉴“正视图” | 明确写成“竖直摆放、完整展示弓臂与弦的正交侧立面”；弓臂在左、单根弦在右、无箭、未拉开 | 英文 front view 易被理解成沿射击轴看去，只剩一条窄边；side elevation 才能说明目标图 |

**建议先试画 8 家族的普通＋传说，共 16 张缩略图，选定跨度后补中间三档。** 不建议一开始画 40 张细节稿；这是一份设计矩阵，不代表已批准生产 40 把资产。

## 3. 弓的造型语言：把复杂度花在能看见的地方（D）

### 3.1 弓型与轮廓

短弓／长弓描述尺度，反曲描述弓臂末端曲率，复合描述滑轮／缆索机构；它们并非互斥的同一层分类。“机巧”是本项目美术家族，可做层压反曲弓，不必全做现代复合弓。

| 设计轴 | 可选形式 | 识别点 | 在本项目的用法 |
|---|---|---|---|
| 短弓 | 紧凑圆弧、短反曲 | 矮而宽、弦与握把距离清楚 | 森林、珊瑚；只改变视觉，不改变射速 |
| 长弓 | 窄长单弧、浅反曲 | 一条有节奏的长线、少转折 | 圣庭、和风；避免为了高档无限拉长 |
| 反曲弓 | 中段舒展、两梢反折 | 末端 S 曲线、腹部大负形 | 默认适配度最高，可覆盖全部档位 |
| 复合弓 | 上下偏心轮、硬质弓把、控制缆 | 两个轮端和架式结构 | 仅机巧家族的高档候选；额外缆索必须能解释，不随意穿过握把 |
| 机括／弩 | 横置弓臂、弩身、扳机、轨道 | T 形而不是竖直 D 形 | 作为研究对照；本项目弓拉弦玩法不选弩形主方案 |
| 非对称和弓 | 上臂长、下臂短，握点偏下 | 明显不等长 | 先做“视觉偏心”版本；真偏心需重做姿态兼容评估，不能直接挪共用握点 |

### 3.2 结构要素与可读性

| 要素 | 应解决什么 | 普通／优秀怎样就有设计感 | 史诗／传说允许增加什么 |
|---|---|---|---|
| 弓臂曲线 | 第一眼轮廓、受力方向感 | 一条主曲线＋一次明确反折，粗细变化集中在根部与弓梢 | 双层外壳或分叉冠，但保留一条能读出的连续主承力弓臂 |
| 握把／弓把 | 左手抓握与视觉重心 | 一段干净包皮／织带，清楚箭台；家族差异可先落在握把截面 | 主徽记和主宝石放在握把上下，中央留空 |
| 弓梢／弦槽 | 告诉人弦从哪里固定 | 两枚大而简洁的端帽就足够，不靠满臂雕花 | 大角、翼、晶簇从弦槽外侧展开；弦槽位置仍清楚 |
| 负形 | 缩小时仍分得清弓臂与弦 | 宽而连续的弦内空间 | 外壳可以形成一个大孔洞；不增加一串碎小孔 |
| 宝石 | 提供焦点 | 普通／优秀可以 0 颗；用金属切面或嵌木代替 | 主石优先于小石堆积；森林与锻造传说也允许 0 颗 |
| 羽饰／挂件 | 传达地域、职业 | 至多一根短系带或一片宽叶，贴弓臂外背 | 一簇大羽或一条短穗，避免落入箭台和拉弦轨迹 |
| 花纹 | 表达工艺而不破坏大色块 | 不画细密符文；只用一个大接缝、包带或材料边界 | 局部两三段大纹，优先放可见宽面；不能均匀铺满 |
| 弓程 | 拉弦中部的运动距离 | 所有家族继承相同动画约束 | 外壳变大也不挤占弦中点后拉空间；外观不能改变蓄力时间 |

### 3.3 “弦几乎都是发光线？”核查结论

**不能成立为事实。** 本轮没有完成原图逐件查验，也没有产品全量样本分母；搜索到“发光弓／魔法弓”不能推出“几乎所有弦发光”。将材质分三层记录，才不会把白色线条、后期 bloom 和技能演出混为一谈。

| 检查项 | 怎么判 | 当前证据状态／本项目建议 |
|---|---|---|
| 实体纤维弦 | 弦槽处连续连接，线本身受光，可能有缠线／中段护弦 | 常规弓结构参考；本项目默认米白、灰麻或深棕，0 自发光 |
| 高亮但实体的弦 | 白色／浅色线在暗背景突出，但不必照亮周围 | 单凭图标亮线无法判发光；原神各弓的弦材质逐件 U |
| 能量弦 | 官方说明或实机展示支持能量／发光，或有明确持续光效 | 光之弓、三月七的弓可作待核对候选，具体材质 U；不要当本轮已证实反例或正例 |
| 释放／蓄力时增亮 | 平时实体弦，技能状态加光 | 与常态材质分开；本项目若采用，也应同一玩法档统一反馈 |

本项目建议：八家族中六家族常态用实体弦；水晶星象高档允许细弱能量弦，圣庭或暗影传说可二选一尝试。能量弦仍须有清楚的中段扣点与可见震动，不能用整片辉光盖住拉弦反馈。这个比例是设计选择，不是市场统计。

### 3.4 低档的“少而好”与全局五档预算

| 本项目档位 | 主形与结构预算 | 宝石预算 | 表面细节预算 | 轮廓验收 |
|---|---|---|---|---|
| 普通 | 1 条连续主弓臂＋1 段握把；家族形状从第一档就存在 | 0 | 两种主材质区最多，一个特色切口／弧度 | 纯黑剪影仍能分森林短弓、圣庭盾肩弓、和风细弓 |
| 优秀 | 保留母形，加成对端帽或一层包覆 | 0 | 一个明确对比色块或宽色带，不刻花 | 不靠提亮就能看出比普通更完整 |
| 稀有 | 增加家族徽记＋一组弓梢饰物 | 0—1 | 1 个局部大纹或徽章 | 特色母题能在约 96px 图鉴高度读到 |
| 史诗 | 主弓臂＋一层外背饰；大孔或分叉选一种 | 0—3 | 每臂最多一组大饰件，不覆盖全长 | 关掉特效仍有明显结构差别 |
| 传说 | 一个专属主意象，如圣翼、鹿角、开炉、日蚀 | 0—3，数量不必高于史诗 | 强主次：大轮廓＞主焦点＞少量边饰 | 与已有第 3 把剑并排，细节密度相近而非翻倍 |

以上数量为本项目初稿预算，非已测引擎限制。低档可以**精工、完整、好看**；不要用脏污、断弦、破皮、随机缺口表示普通，也不要把全部普通档强制涂灰。稀有度灰／绿／蓝／紫／橙只用在名称、卡框或标签。

## 6. 持弓、拉弦与建模交接约束（D）

| 项目 | 必须保留 | 允许外观变化 |
|---|---|---|
| 左手握把 | 中央抓握段、手指包覆空间、共用握持轴 | 包带色、截面装饰、握把上方徽记 |

建议每把弓最终交接三态：上弦未拉开、满弦、放弦回弹关键帧。**概念主图只出第一态**，三态是后续动作验收，不是本次生成任务。弓弦不能被“模型里画了一条线”替代，后续需要真实随动作变化的独立表现。

### 7.2 视图：正交侧立面才是这里要的“正视图”

```text
Orthographic side elevation of ONE complete bow, displayed upright and fully inside the frame.
Look perpendicular to the plane containing the limbs and the bowstring,
so the entire limb curve and the entire string are visible together.
The solid bow stave is on the LEFT; the single straight main bowstring is on the RIGHT.
The string joins the upper and lower string nocks on the same side of the grip,
leaving a broad clear D-shaped open space between the string and the grip.
Show the braced, undrawn state: the string is already fitted, but is not pulled back.
The main string stays clear of the grip and does not run through decorative gems.
No arrow, no quiver, no hands, no character. Neutral plain background.
No perspective foreshortening, no diagonal placement, no horizontal bow,
no end-on view looking along the shooting direction.
```

“一条主弦”针对本手册默认的反曲弓；若以后批准复合弓方案，应另写轮组、控制缆数量和走线，不能直接复用这段。

| 容易歧义的写法 | 建议替代 |
|---|---|
| front view of a bow | orthographic side elevation, entire limbs and string visible in the same plane |
| unstrung / relaxed bow | braced and undrawn，强调弦已挂好；unstrung 会变成无弦 |
| bow facing forward | stave on the left, string on the right，明确平面构图 |
| glowing bow | one thin low-intensity energy string only，或 no emissive materials |
| highly detailed legendary weapon | one unique dominant crown silhouette, sparse broad details |

```text
The archer holds the grip with the LEFT hand and draws the string with the RIGHT hand.
In this side view, the target is to the LEFT and the drawing hand moves to the RIGHT.
Show one arrow pointing LEFT, its shaft aligned with the arrow rest;
the arrow nock meets the middle serving between the drawing fingers.
Only the drawn state has two straight string segments forming a V toward the drawing hand.

```
