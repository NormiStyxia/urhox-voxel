# 手边武器弧环：参考核对与实现记录

调研日期：2026-11-15。用户用语是“明日方舟众生行迹背景结构图”。本轮先联网检索，再实现；没有把搜索摘要当成图片验收。

## 已核对的来源

- [PRTS：SideStory「众生行记」](https://prts.wiki/w/众生行记)：直接打开页面并核对标题 `THE MASSES' TRAVELS SideStory「众生行记」`。页面含[明日方舟官网公告](https://ak.hypergryph.com/news/3062.html)链接。可确认活动常见名称为“众生行记”，与用户口述“众生行迹”有字面差异；不能据此认定用户一定指该活动的某张图。
- [一颗豆游戏UI：从线稿到完成｜临摹《明日方舟》众生行记｜背景加UI全流程](https://www.bilibili.com/video/BV1k6jJ6vEwA/)：直接打开并核对标题、作者，查看浏览器截图。所见视频前段为 Affinity 中的人物线稿、横纵定位轴与周边占位框。这是二次临摹教学来源，不能冒充官方原图。尚未逐帧核对成品背景，也未得到用户指定截图，所以“用户所称的那张背景结构图”仍未确认。

本次实现只采用用户明确提出的“结构图式刻度、定位点、引线”，不宣称还原某张尚未确认的图片，不下载或复用该活动资产。原神 Tab 轮盘只作为用户指定的交互方向；项目 Tab 继续用于远眺，入口保留 Q。

## 实际实现

`scripts/ui/WeaponWheel.lua` 使用现有 `urhox-libs/UI` 自定义 Panel 绘制；文字使用 `UI.Label`，单独注册 MiSans 字体族，避免沿用 HUD 像素字体。沿现有 root 加子层并 PushOverlay，退出 PopOverlay/RemoveChild/Destroy；不 SetRoot、不 Shutdown、不创建 raw NanoVG frame。

- 圆心对应右手屏幕投影；越界时只平移环带，并保留手部定位标记和连接引线。
- CSS/dp 基准：内半径 88、外半径 164、起始角 -96°、跨度 122°；两项分别位于 -65.5°/-4.5°，保留中空，四个端角圆润。
- 墨蓝轻透环带、米白内外细弧、外圈细刻度、内沿定位点；选中只用小段琥珀色短弧和轻亮区域。没有整屏遮黑或实心圆盘。
- 呼出用 0.12 秒淡入并径向外推 6 CSS 像素，三次缓出；文字与命中沿相同的实时布局移动，不出现动画期间的点击错位。
- UI 基准坐标与 CSS 坐标转换只用 `DPR/UI.GetScale()`；UI 框架负责最后一次物理像素缩放，避免双乘 DPR。安全区纳入布局，小屏缩小结构。
- PC：按住 Q 打开，鼠标方向与 hover 选项；Q release 由场景调用 Confirm，escape/右键取消。移动端：swap 打开，另一次完整按下/抬起同一扇区确认，空白完整点击取消；开启的那次抬起不会误选。
- 拒绝切换：onSelect 返回 false 保持打开；外部成功/默认接受后淡出 0.10 秒。IsOpen 覆盖淡出，IsBlocked 另覆盖释放保护。ForceClose 用于场景安全清理。
- 扩展：Open 可传 items 数组（id/name/tag），槽位按数量均分弧段；非剑/弓物品有占位线稿，不限制底层武器系统。

## 公开接口与离线构图

`Open({weapon,anchorX,anchorY,touch,onSelect,onClose,items?})->boolean`；`Close(reason)`；`ForceClose(reason)`；`IsOpen()`；`IsBlocked()`；`Update(dt,{anchorX,anchorY}?)`；`Confirm()`；`Cancel()`；`SetAnchor(x,y)`。均为 dot-call。anchor 为 [0,1] 屏幕坐标。场景应持续调用 Update（包括关闭后释放保护阶段），并在停止时 ForceClose。

`Layout(widthCSS,heightCSS,anchorX,anchorY,touch,count,safeCSS)` 返回纯布局；`HitTest(layout,xCSS,yCSS,strict)` 与绘制共用几何；`Draw(vg,layout,selectedIndex,items?,alpha?)` 可记录实际 NanoVG 绘图命令，不开始/结束 frame。`DebugLayout()` 返回当前 CSS 布局，`DebugState()` 返回打开/淡出/阻断/选择状态。离线绘图只能验构图，不能称为引擎截图或 Web 验收。
