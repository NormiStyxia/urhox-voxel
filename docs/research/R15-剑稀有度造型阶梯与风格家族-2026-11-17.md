# R15｜剑稀有度造型阶梯与风格家族

日期：2026-11-17。用途：二次元体素探索战斗游戏的剑外观设计与生图。

## 先给结论

1. **用两条轴设计：风格家族负责身份，稀有度负责视觉复杂度。** 普通剑也有完整审美，不能只是传说剑删掉装饰后的灰模；圣庭、森林、机巧、星象、和风、哥特、海洋、锻造八个家族，从普通档就应能凭剪影和三色认出来。
2. **只借鉴产品的造型阶梯，不借用数值成长。** 本项目五档不改变攻击力、范围、攻速、技能、命中体积或切换规则。灰／绿／蓝／紫／橙只出现在 UI 标签、边框和底板上，不进入剑的配色约束。
3. **四档升级顺序：好看的基础器形 → 有目的的结构转折 → 一个清楚的主题焦点 → 有主次的标志性轮廓。** 不是锈铁→银→金，也不是不断加宝石、花纹和光。
4. **传说剑已定稿，作为上限而非全部家族的模板。** 参考图从左数第 3 把：不对称大金色羽翼护手、蓝色宝石质长刃、深蓝握柄；前四档不用整片金羽翼＋通体蓝宝石刃的组合，保留它的独占辨识度。
5. **必须纠正对标口径。** 《原神》1★／2★单手剑各只有一个常见基础条目，不能各凑两个；《星穹铁道》角色持剑不等于剑装备稀有度；《旷野之息》和《Minecraft》材料／获得阶段不等于五档稀有度；“塔维亚的传说剑”暂未识别到可靠产品条目。下文分别注明，不编造空缺。

## 3. 从产品中提炼的造型规律

以下为跨产品的设计归纳，不是“所有游戏都这样”的统计规律。材质写的是视觉表现，不改变本项目属性。

| 维度 | 普通 | 优秀 | 稀有 | 史诗 | 传说：既定上限 |
|---|---|---|---|---|---|
| 剑身形状 | 完整直刃、单曲线或利落宽刃；可有一个独特剑尖／肩线 | 基础器形加一个明确转折：肩部台阶、浅槽、折线刀背 | 一条主题性结构贯穿局部，如叶脊、月牙凹面、嵌芯 | 在原有母形上形成主次双轮廓，如分叉护手＋单段刃窗；仍是一把清楚的剑 | 第 3 把蓝宝石质修长主刃，尖端、肩部与护手关系按原图 |

### 普通剑如何简单但不寒酸

| 要做的事 | 具体做法 | 避免 |
|---|---|---|
| 先设计器形 | 剑尖、剑肩、护手、柄头至少有一处家族特征；另三处克制 | 圆柱握柄＋长方体刃＋横杆直接交付 |
| 用比例做工艺 | 剑刃有渐收，柄尾有收口；护手厚薄有节奏；握柄长度可信 | 所有部件等厚、尖端突然截断、握柄过细 |
| 用切面做信息 | 亮刃面／暗刃面／深色刃口三块关系清楚；用一次大斜面显示厚度 | 用噪点、铁锈和贴图填空，缺少实际形体 |
| 用三色做身份 | 每个家族主色约 65～75%、副色 20～30%、点缀 5～10%；低档也保留 | 普通档全灰；所有高档全蓝金 |
| 留一个干净焦点 | 比如扁圆柄头、杏叶护手、偏心铆钉或方形剑肩，四选一做主角 | 同时加宝石、缎带、齿轮、雕花来救造型 |
| 干净比破损更重要 | 完成的磨面、包边、缠柄可表达“日用好剑” | 以锈烂、裂口、缺刃来标注贫穷或低级 |

## 8. 一眼验收：保证差异，不靠加花

| 验收问题 | 通过标准 | 不通过时怎么改 |
|---|---|---|
| 普通档是否像完成品？ | 有渐收、斜面、护手体积和明确柄尾；三色关系完整 | 先修比例和刃面，不补雕花或光效 |
| 关闭 UI 后是否仍能认家族？ | 小图下至少能从轮廓＋主／副色识别家族 | 改护手母形与剑肩，不能只换宝石颜色 |
| 同家族四档是否有节奏？ | 从一件式护手到主题护手，再到主次结构；保留家族母形 | 删掉与主题无关的小件，把升级集中到一个大结构 |
| 同档八家是否重复？ | 普通也有直／叶／折／菱／曲刃差异，史诗有八种不同护手主形 | 改其中一把的器形与材质比例，避免蓝金兜底 |
| 史诗是否挤占传说？ | 没有复刻整段蓝宝石刃＋大金羽翼＋深蓝柄组合 | 保留自己的拱、角、镡、贝等主题，收回羽翼面积 |
| 小图能否看清？ | 建议用相同高度的约 96 px 预览比较；护手与柄头仍分离可读 | 合并碎片、加厚主要结构、减小花纹密度 |
| 正反面／侧面是否成立？ | 宝石有座、嵌芯有支撑、握柄连接完整，刃厚可解释 | 修结构连接；不靠高光遮盖悬空和断裂 |
| 是否误改玩法？ | 五档只更换外观与 UI 标识；同类别攻击数据一致 | 把外观尺寸与碰撞／射线／伤害参数解耦 |

建议首轮先画 **八家普通＋八家史诗，共 16 张端点稿**，检查风格差异与传说上限，再填中间两档；这是后续建议，本轮不调用生图工具、不改资产与代码。
