# 诺米像素小人：三视图与制作记录

整理日期：2026-11-10。根据本项目现存素材、生成脚本和 Git 提交整理；项目内角色名为「诺米（Nomi）」，本文对应用户所说的「糯米」。这是一份依据现存证据还原的记录，并非完整的原始对话或创作日志。

## 一、角色与三视图

项目保留了一张正面、侧面、背面排列的参考图，脚本将其标为 Mivo 生成的「藏青碎条斗篷」YSM 三视图。角色是大头 Q 版方块造型：白银色长发与呆毛、蓝色眼睛、黄色配饰，藏青色水手服和破碎下摆斗篷、白色裙边及深蓝靴子。三视图可用来核对发型、正面服饰、侧面厚度和背面斗篷。

原始参考：`art/nomi_ysm/ref/ref_ysm_navy.png`。下文的配图还包括早期方块版预览和后续体素版的参考对比、多角度预览。

## 二、制作过程

1. **准备参考图。** 以 Mivo 生成的正、侧、背图作为造型依据。仓库没有找到原始生成提示词、模型参数、对话或完整选稿过程，无法还原具体生图步骤与决策。
2. **制作方块版起手工程。** `art/nomi_ysm/build_nomi.py` 根据参考图程序化拼装 YSM 风格角色，逐格处理脸、眼睛、刘海、头发、衣服和斗篷。头顶采用阶梯形轮廓。输出 Blockbench 工程 `nomi.bbmodel`、Bedrock 几何 `nomi.geo.json`、贴图 `nomi.png` 和正侧背预览 `preview.png`，用于继续编辑和快速比对。
3. **从三视图转为体素版。** `art/nomi_voxel/carve.py` 识别参考图背景和人物轮廓，去掉地面阴影、填补浅色区域空洞，并采样正、侧、背各视图，输出轮廓/颜色中间数据。`voxelize.py` 自行读取同一张参考图，执行轮廓提取、采样与体素化：沿三视图轮廓约束形状，再为头、手臂、腿、身体、头发与斗篷等部位分别处理深度。
4. **修形与上色。** 只有一个侧视角，直接将视图轮廓求交会让手臂和腿过厚；脚本改为按部件控制深度，并处理圆角头、帽兜、翻领、外套和长发等层次。按面朝向取参考图颜色，分开脸部调色板、减少杂色并合并同色面。脸和刘海分层；侧面眼睛位置改用合适颜色，避免斜视角出现「四只眼」。
5. **绑定和接入游戏。** 生成的数据写入 `scripts/game/NomiVoxelData.lua`；`scripts/game/BlockCharacter.lua` 用每根骨骼对应的几何与节点驱动角色，`scripts/player.lua` 把体素诺米接为玩家外观。程序化动画覆盖腿臂、身体、头、长发、裙摆、外套和斗篷碎条；外套上下分层，运动时随速度摆动。
6. **调整体型与可见性。** 之后增加共用体素数据的 Q 版和修长版：修长版缩小头和头发、拉长腿并收窄身体，代码中通过 M 键切换。提交记录同时提到角色结构与可见性修复。
