# 移动端 UI 设计规范（像素冒险卷轴风）

日期：2026-11-13。分工：**美术/版式由 Claude 负责（本文 + `assets/ui/touch/`），程序实现全部交给 Astra**。
适用场景：`ruins_main`（徒步 + 骑龙同在一个场景）；`dragon_main` 的骑龙部分沿用同一套。

## 0. 硬规矩（先看）

1. **像素网格统一**：所有位图一律 **整数倍（2×）+ `NVG_IMAGE_NEAREST`** 绘制，禁止非整数缩放、禁止线性过滤、禁止旋转（会糊/糟）。逻辑 1 个美术像素 = 2dp。
2. **字体**：`Fonts/ArkPixel-12px-zh_hans.ttf`（已入库，OFL）。字号只用 **12 / 24**（12 的整数倍才清晰）。正文/提示 12，浮动大提示 24。
3. **配色走“墨青 + 铜金 + 羊皮纸”**（见 §6），不要再用 `{70,130,255}` 这类裸蓝紫 + 圆角矩形。UI 里不再出现 `borderRadius` 圆角+渐变的“现代 App 感”。
4. **徒步与骑龙是两套操作**：切换时右侧按钮群整体换一套（§3 / §4），不是在原有按钮上加几个。切换用 2~3 帧的阶梯式透明度变化（可带整数 2dp 位移），不做平滑缓动。**任何动画都不得对位图做非整数缩放**：“放大/脉冲”一律改为外围 1 美术像素(2dp)像素描边环的阶梯扩张 + 透明度两档变化。
5. 按键 UI 不得挡视野：所有按钮常态不透明度 0.78，按下 1.0；无触摸 3 秒后整体降到 0.45。
6. 屏幕设计基准：横屏 **844×390 dp**（`UI.Scale.DEFAULT`，系统逻辑分辨率）。必须读安全区（刘海/圆角/手势条），按钮距边缘 ≥ 安全区 + 20dp。竖屏不做专门适配，但不能崩（按钮跟随右/左下角锚定）。
7. 不要改 `assets/ui/touch/` 里的 PNG；缺图/要改图找我。

## 3. 徒步模式（时之法术）按钮

**左下：浮动摇杆**
- 触摸区：屏幕左 45% × 下 70%。首次按下处出现 `joy_base`，帽 `joy_thumb` 跟手（限制在半径 40dp 内，视觉位置整数化）。松手后摇杆淡出，原位置留一个 0.35 不透明度的“幽灵底座”提示区（固定在安全区内左下，中心约 (安全左+84, 屏高−84)）。
- 外推到 ≥ 90% 半径 = **奔跑**（等价 Shift）：底座换 `joy_base_run`。
- 输出等价于 WASD：上=W 下=S 左=A 右=D（模拟量，可用 `Move(dt, f, r, ...)` 的 f/r 直接送连续值，死区 0.15）。

**右下按钮群**（以屏幕右下角为原点 O=(屏宽−安全右−20, 屏高−安全下−20)；下表是**按钮中心**相对 O 的偏移，向左为负 x，向上为负 y）：

| 按钮 | 底座/图标 | 中心偏移 | 行为 |
|---|---|---|---|
| 碎时（主） | `btn40_main` + `shatter` | (−48, −48) | **按住蓄力，松开施放**（= 左键）。蓄力时外圈出现金色逐格充能弧（§6），按钮本体不动，外围加 1 美术像素的金色像素描边环阶梯扩张一格再收回 |
| 跳跃 | `btn32` + `jump_s` | (−48, −148) | 点按 = Space |
| 冻结 | `btn32` + `freeze_s` | (−148, −32) | 点按 = E |
| 回溯 | `btn32` + `rewind_s` | (−124, −124) | 点按 = Q |
| 上龙（情景） | `btn32_main` + `mount_s` | (−212, −72)，外加每 0.5s 一次外围像素环阶梯扩张脉冲（不缩放按钮） + 下方 12px 标签“上龙” | 仅当龙已苏醒且人在 3.6m 内出现；点按 = F |

右上角一排 3 个次级键（`btn32` + `_s`，64dp，间距 8dp，不透明度 0.6）：从右到左 **菜单(`menu`) 、远景(`farview` = Tab 切换)、快进(`clock` 按住 = T)**。菜单目前只放“释放/帮助说明”弹窗（`panel_paper` 面板，12px 墨色文字），内容用 §5 的移动端说明。

**右半屏空白处拖动 = 转视角**（见 §7）。

## 4. 骑龙模式按钮（与徒步完全不同的一套）

摇杆仍在左下，但语义变为骑乘舵：**上=前进(W)、下=停/刹车(S)、左右=转向(A/D)**，没有奔跑态；冲刺走右侧按钮。底座始终用 `joy_base`，推到顶端发一次轻微的 1 帧高亮。

右下按钮群分**地面**和**空中**两套（根据龙的 `loco.airborne` 切换，切换时旧按钮 2 帧阶梯降透明度、新按钮 3 帧阶梯升透明度并从偏下 4dp 落位（均不缩放））。偏移基准同 §3：

> 2026-11-13 变更：骑龙新增**普通吐息**（长按持续、松手立即停，地面空中均可），占据主按钮位（与徒步碎时同位置同大小）；原 B 键长前摇大招改名 `breathSpecial`，为点按触发的次级键。

**地面（已骑乘，未起飞）**

| 按钮 | 底座/图标 | 中心偏移 | 行为 |
|---|---|---|---|
| 吐息（主） | `btn40_main` + `breath` | (−48, −48) | **按住**持续吐息，松手立即停（`Down("breath")`） |
| 起飞 | `btn32` + `ascend_s` | (−48, −148) | = Space（起飞） |
| 下龙 | `btn32` + `dismount_s` | (−148, −32) | = F |
| 大招 | `btn32` + `breath_s` + 12px 标签“大招” | (−124, −124) | 点按 = B（长前摇大招，`Press("breathSpecial")`） |

**空中**

| 按钮 | 底座/图标 | 中心偏移 | 行为 |
|---|---|---|---|
| 吐息（主） | `btn40_main` + `breath` | (−48, −48) | 按住持续吐息 |
| 上升 | `btn32` + `ascend_s` | (−48, −148) | **按住**=Space 持续上升 |
| 下降 | `btn32` + `descend_s` | (−148, −32) | **按住**=C 持续下降 |
| 冲刺 | `btn32` + `dash_s` | (−124, −124) | **按住**=Shift；激活时换 `btn32_main` 底座 |

| 大招 | `btn32` + `breath_s` + 标签“大招” | (−196, −160) | 点按 = B |

**所有按住态必须释放**：打开菜单、失焦/切后台、TouchCancel、下龙、骑/下龙切换、地面↔空中套切换、触屏↔键鼠切换。

两套都要保证：同时按住摇杆 + 一个右侧按钮 + 拖视角（三指）互不抢事件。

## 6. 视觉细节

**调色板**（只用这些）
```
墨底     #162230   深墨   #0E121E   中蓝灰 #223444
铜       #AA6630   铜暗   #683A1C   金     #E0B253   金亮 #FFE596

冰蓝     #8FD0E8   提示灰蓝 #9DB3C2   警告红 #C8503C
```

**按钮状态**：常态 → 按下(`_down` 底座 + 图标下移 2dp) → 禁用(灰度 + 0.5 透明)。按下反馈没有缩放缓动。
**冷却遮罩**：圆按钮内做**逐格扫掠**（顺时针，12 点起，24 格量化，不要平滑），颜色 `rgba(14,18,30,0.62)`，被圆形裁剪（半径 = 底座半径 − 6dp，即只盖石面不盖铜边）；冷却剩余秒数用 12px 羊皮纸色居中（≥1s 才显示整数）。
**蓄力环**：碎时按钮外侧加一圈 2px(原生像素 → 4dp) 的金色弧，逐格 32 格充能，满格时整圈闪一下(2 帧)。
**情景按钮脉冲**（上龙等）：外围像素环 2 档（0.5s 切换），不缩放按钮本体，不要正弦平滑。
**所有阴影**：不要高斯阴影，需要时用 1×1 美术像素（2dp）深色(`#0E121E`)错位副本。

- 以最小改动接入：`RuinsScene.lua` 的 `Down/Press`（键盘 OR 虚拟输入）、`HandleSpells` 的左键蓄力、`DragonRide.lua` 的 `Down/Press`。**不改这些文件里与本任务无关的任何内容**（另一个会话正在改 RuinsScene/RuinsBuild/RuinsTrees/着色器）。
- 触屏下不要请求鼠标锁定，`pointer` 逻辑要对触屏旁路；视角灵敏度：横向 0.14°/dp，纵向 0.12°/dp（比 0.12 的鼠标略大，手指行程短），单指在右半屏非按钮区拖动。
- 触屏事件优先走 `TouchBegin/TouchMove/TouchEnd` 并按 `touchID` 分配所有权（摇杆、各按钮、视角各占一个 id），不要依赖鼠标模拟。UI 库的 `pointerEvents` 需 `none` 的地方保持 `none`，避免 HUD 吞掉玩法点击（原 HUD 是全 `pointerEvents="none"` 的展示层）。
