# 直刃剑三视图设计 Brief（2026-11-16）

## 当前稿的问题

首稿的细节密度过高，金色线条、护手中心宝石和剑首宝石形成重复的菱形视觉中心；放进体素遗迹环境后会显得过于精致。

## 下一轮目标

借鉴原神武器的轮廓层级和材质分区，保留大轮廓、少量高识别装饰与硬边平面，不复制精细贴花。三视图必须服务后续中低面数建模。

- 直刃保持一条长、干净、略收尖的主轮廓。
- 刃根只做一处明显的短肩部/ricasso 结构，不做全长纹样。
- 护手作为唯一横向识别层：厚实中央块 + 两片短斜翼，端部切面；不使用细长金线。
- 握柄使用单一圆角柱或方圆柱，两端各一个端环，深色包裹材质。
- 剑首只保留一个纵向六边形或梯形蓝宝石；取消护手中心宝石，避免双菱形叠加。
- 材质最多三类：浅色刃体、暗金结构、深色握柄；宝石作为点缀色/发光参数，不额外堆复杂材质。

## 建模预算

整剑目标 250–400 tris：刃 120–180、护手 50–80、握柄 24–48、剑首 40–70。每个部件尽量一个子网格和一个材质槽，保留硬边与少量大倒角。

## 三视图验收

1. 正/侧/背同尺度，连接边界一致。
2. 展示台常用距离下能一眼辨识四个部件。
3. 不出现双菱形或重复宝石中心。
4. 三色切换只需影响三大材质分区。
5. 不依赖贴图也能读出刃体、护手、握柄、剑首层次。

## 下一轮生成提示词核心

生成同一把直刃奇幻收藏品的严格正/侧/背三视图，低中面数、体素遗迹可用。只保留象牙浅蓝刃体、暗金护手/剑首、深炭握柄三大材质。刃体长直干净，刃根一处短肩部装饰；护手为厚实中央块加两片短斜翼；握柄为直圆角柱加两个端环；剑首仅一个纵向六边/梯形蓝宝石，护手中心无宝石。前侧背严格同尺度、同连接边界、无透视、无多余文字。总三角预算目标 250–400，装饰用大平面和硬边表达。

## 蒙德中世纪冒险风 v1

参考苍古自由之誓的蓝金关系、直剑轮廓和护手装饰集中原则，加入中世纪骑士装备的功能感：护手承担主要识别，握柄使用深色皮革，剑首改为小型圆形蓝色 cabochon，避免大菱形和重复宝石。保留中等精细度，但把纹样限制在护手中央盾形片和大平面倒角，便于后续贴图材质化。

## 长剑比例与轻微不对称 v1

上一版仍有匕首感，原因是刃身占比不足、护手和剑首过重。本版将刃身提高到整剑约 72–78%，握柄压到约 17–20%，并让护手承担斜向/螺旋形识别；正面和背面允许方向性差异，侧面保留厚度和挂接边界。产物：`art/parts3v/sword_straight_v1/straight_sword_long_asym_v1.png`。
