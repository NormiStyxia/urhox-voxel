# 武器建模「老路」规范（2026-11-22）

给四把新武器（遗迹铁剑 / 守门长剑 / 猎弓 / 银枝弓）返工用。**翼剑与荆棘花弓是唯一验收样板**，
本文件把它们实际使用的做法固化成可检查的条目。凡与本文件冲突的既有实现，一律以本文件为准。

## 0. 一句话区别

老路的武器 = **参考图逐点量出来的几何** + **材质分区权重** + **手写专用 shader**。
偷懒的武器 = 三角面糊纯色 + 把 2D 原画当贴图投影到 Base Color（守门长剑上一版就是这么干的）。

## 1. 只读样板（必须先读，不要凭记忆）

| 样板 | 几何生成器 | shader | 材质绑定 | 视觉模块 |
|---|---|---|---|---|
| 翼剑 | `art/weapon_gen/wingsword.py` + `trace_wingsword.py` | `assets/model/forge-blades/WingSword.shader`、`WingSwordCrystal.shader` | `WingSword.xml`、`WingSwordCrystal.xml` | `scripts/combat/WingSwordVisual.lua` |
| 荆棘花弓 | `art/weapon_gen/thornbow_blender.py` + `thornbow_export.py` | `ThornBow.shader`、`ThornCrystal.shader`、`ThornSand.shader` | `ThornBow.xml` 等 | `scripts/combat/ThornBowVisual.lua` |

必须注意到的三件事：

1. `wingsword.py` 的 `TRACE` 是从 2D 图**量出来**的控制点（`trace_wingsword.py`），不是手写常数。
2. 刃身是**多站点环体放样**（`ring_loft`），每个站点 12 边截面，冠高、脊线偏移、肩部倒角逐站变化。
3. shader 里没有任何 `sampler2D` 采样原画；材质全部由 `COLOR.r/g/b`、`COLOR.a`(shade)、`UV.x` 重建。

## 2. 数据契约（不要新发明，照抄这套语义）

### 2.1 剑（`{meta, tris}` JSON → `scripts/combat/models/<Name>.lua`）

每个三角：

- `p[3][3]` 顶点坐标（米，握把中心为原点，+Y 为剑尖，观察者在 −Z）
- `c=(r,g,b)` 材质通道权重，剩余 `1-r-g-b` 为握柄
  - `r` = 刃体钢 / `g` = 金属饰件（金、银、铁箍） / `b` = 宝石或芯 / 余 = 握柄与织物
- `shade` = 该面的明暗系数（逐面常数，等价于烘焙好的 AO/转折）
- `glow` = 自发光强度
- **每顶点 `uv = (submask, height01)`**：`submask ∈ {0, 0.35, 1.0}`（0 = 普通体，0.35 = 芯/内层，1 = 宝石发光件），`height01` = 该顶点在全剑高度上的 0..1 归一化位置

Lua 导出必须字节确定（同一份脚本连跑两次 SHA 相同），且 `pos/uv/col` 三串都要有，不允许只有 `pos+col`。

### 2.2 弓（`assets/model/forge-blades/<Name>.mesh.json`）

沿用 `README-thornbow.md` 的 `formatVersion=1, vertexStride=11`：
`pos(3) + normal(3) + 权重(3) + alpha + glow`，另需 **`uv(2)`** 扩展为 stride 13（`vertexStride=13`），
`uv.x` 语义同 2.1 的 submask，`uv.y` = 归一化高度。分区：`r` = 弓臂木质、`g` = 骨/叶/金属饰、`b` = 晶体+弦、余 = 缠绕握把。
parts 保持 `body / crystal / string` 三段（无晶体则 `crystal` 为空数组）。

## 3. 几何要求（这一条是「不偷懒」的核心）

| 项 | 剑 | 弓 |
|---|---|---|
| 三角面预算 | 1200–2200 | 1600–2800 |
| 主要形体 | 刃身 **≥8 个站点**，每站 **≥8 边**截面 | 弓臂 **≥14 个站点**，每站 **≥6 边**截面 |
| 截面变化 | 相邻站点冠高差 ≥2mm 且脊线横向偏移，禁止等厚棱柱 | 站点半径、扁平比逐站变化，禁止等径管 |
| 硬边 | 护手必须有 **≥2 层倒角环**（真实几何，不是颜色） | 弓梢端帽必须有真实厚度与脊 |
| 握把 | **≥5 个环** + 真斜向缠绕绳（几何，不是条纹贴图） | 缠绕 **≥4 圈真实螺旋**，绳要压在握把表面外 |
| 宝石 | 真切面（≥8 面），有独立 rim 与 peak | 晶芽真切面（≥8 面），落在枝干凹处 |
| 弦 | — | 实体细管，截面 ≥6 边，两端插入弓梢弦槽内部 |
| 闭合性 | 每个 part 水密、绕序朝外、0 退化面、无浮空碎片 | 同左 |
| 轮廓 | 不得比返工前差：剑正/背 IoU ≥0.96、侧 ≥0.93 | 正视 ≥0.96；侧视以「原画左右两列自身重合度」为上界，须 ≥ 该上界 −0.03 |

## 4. Shader 要求

每把武器一个**专用** shader（+ 对应 `.xml`，内容就是一行 `<surfaceshader name="...">`）：

```
assets/model/forge-blades/<Name>.shader
assets/model/forge-blades/<Name>.xml
```

必须实现：

- `METALLIC` / `ROUGHNESS` / `SPECULAR` **按通道分区给值**，不是全场一个常数
- 菲涅尔边缘光（`pow(1.0 - ndv, k)`），掠射角提亮
- 金属：环境反射（按反射向量 up 分量分层）+ 窄高光 `pow(rl, 60..120)`，金与钢分别调
- 木质 / 皮革 / 骨：程序化纹理（`sin` 组合的纤维或年轮），粗糙度 0.55–0.9，金属度 0
- 宝石：颜色归一化取色相 → 深/中/亮三档 + 厚度吸收 + 内部反射平面 + 菲涅尔，禁止纯白圣光
- 流光：**最多一条**主节奏，扫过幅度低，且在刻面边界断相
- 顶点色 sRGB → 线性转换必须做（参照 `VoxelSprite.shader` 的写法）

禁止：

- `sampler2D` 采样原画或任何贴图当 Base Color
- 纯色三角面平铺（只有 `ALBEDO = COLOR.rgb` 这种）
- 噪点填充代替形体
- 屏幕采样（`hint_screen_texture`）

## 5. 视觉模块

`scripts/combat/models/<Name>.lua`（数据）+ `scripts/combat/<Name>Visual.lua`（绑定）：
分帧上传、按 submask 拆分子网格（有不透明/半透两层时用 `SetNumGeometries`）、材质克隆与锻造换色入口、
失败返回 `nil` 让上层回退到体素占位。

## 7. 验收命令（每条都要给一行 pass/fail + 日志路径）

| 命令 | 要求 |
|---|---|
| `python3 art/weapon_gen/<weapon>_blender.py measure` | 三列地标量测 PASS |
| `... export` | 导出 JSON/Lua，含 uv 串 |
| `... topology` | 水密 / 绕序朝外 / 0 退化 / 单连通 |
| `... lua` | lupa 加载，`pos/uv/col` 与 JSON 全量一致 |
| `... compare` | IoU 达第 3 节阈值 |
| 确定性 | 连跑两次 JSON 与 Lua SHA-256 逐字节相同 |
| Blender 渲染 | `Blender -b --factory-startup -P <generator>` 成功出 `.blend` + 四视图 |
| 自检读图 | 必须实际打开渲染图确认，不得只看数字 |
| LSP | 改动的 Lua 文件 0 Error |

另需在报告里给出：三角面数、站点数、截面边数、不同朝向法线数、材质通道数、shader uniform 清单。

## 8. 边界

- 只改自己这把武器的文件；不要碰 `WeaponCatalog.lua`、`WeaponRig.lua`、`ForgeShowroom*.lua`、`ForgePanel.lua`
- 不要碰翼剑 / 荆棘花弓 / 法器 / 其他三把新武器的任何文件
- 不要 `git commit` / `push` / 构建；不要生成 `.meta`（集成阶段统一处理）
- 参考图不许当贴图、不许改参考图
