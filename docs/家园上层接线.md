# 住宅二层和屋顶接线

坐标以岛的局部原点为准，面向池岸的一面是 −Z。由首层负责人在创建住宅时调用一次。


```lua
local Upper = require('ruins.HomeHouseUpper')
Upper.Build(function(lo, hi, size) return brush(world, lo, hi, size) end, finish)
```

`finish(group, brush, options)` 接收已绘制的 Brush；在这里对旧柱等永久占用做裁切，调用 `brush:Finish(options)`，并把返回的体积注册给分组。每组一个体积，`options.masonry` 为 `homeWindows`。三组按以下状态注册。

| 组名 | 可见且有碰撞的状态 | 本地标高与作用 |
|---|---|---|
| `second` | 2、3 | 实体楼板 3.75 至 4.00 m，立面延续至 6.75 m |
| `secondRoof` | 2 | 从 6.75 m 起，完整长脊双坡过渡屋顶和烟囱 |
| `third` | 3 | 从 6.75 m 起，长屋顶、中央横山墙、两侧老虎窗、烟囱与东侧木轮；木轮可悬至楼板以下 |

状态 0、1 的首层及状态 1 临时屋顶由首层模块负责。切换状态须同时更新可见性、碰撞与网格占用；三层恢复时去掉 `secondRoof`。

## 地基、首层与阶段接口

主体外墙占本地 X −16 至 −1 m、Z 7 至 13 m，池岸在 −Z。右前门洞中线 X −4.25 m，净宽 2.25 m、净高 2.5 m。门廊和首层墙体属于同一持久体积，玩家可从 Y 0.75 m 的平台走入室内。首层正面有三扇石拱窗，两侧各一扇，背面两扇。

| 首层构件 | 生效阶段 |
|---|---|
| foundation 地基、平台及门阶 | 0 至 3 |
| ruin 残墙和散石 | 0 |
| ground-floor 首层及突出门廊 | 1 至 3 |
| one-storey-roof 首层长脊过渡瓦顶 | 1 |

调用 `HomeIsland.GetHouseStage()` 读取当前阶段，调用 `HomeIsland.SetHouseStage(n)` 切换。返回 `true` 表示成功或已处于目标阶段；返回 `false, reason` 时面板显示原因。首次进入为 0，同一会话内离岛和回岛保留阶段。七组房屋体积在建岛时创建，升降层复用实例，同时切换节点、碰撞过滤和窗灯。场景提供诺米足点、龙的支撑位置以及随朝向旋转的三个躯干碰撞球。站在将消失的楼板上或挡住即将出现的构件时，切换会被拒绝。

上层窗框、山墙斜撑和长檐口会以 options.nodeName=HomeHouseDetail-* 追加局部细节体积。它们沿用回调的 group 阶段范围，属于对应楼层，不应被解析成新的状态组。细节体积为 visual-only，碰撞继续由同组 0.125 m 主体体积提供。

## 灯光对位

所有窗均用槽位 156，朝外法线写在 `Upper.Windows` 中。表按窗逐项列出 `group,x,y,z,nx,nz,width,height`；位置取实际玻璃厚度的中心，单位米。把岛变换加在这些坐标上即可获得世界位置。

二层正面五跨中心 X 为 −14.5、−11.5、−8.5、−5.5、−2.5，玻璃中心 Z=7.3125，向 −Z；背面对应相同五跨。东西山墙各有两扇窗。三层正面中心 X=−8.5，两侧老虎窗在 X=−14 和 −3。二层窗归 `second`，阁楼窗归 `third`。实际高度、宽度与侧窗偏移以模块的共享表为准。

二层和阁楼各随分组返回一个代表灯位，位于正面中窗。二层灯口为 (−8.5, 5.25, 7)，阁楼灯口为 (−8.5, 8.5, 6.75)，均朝 −Z。HomeIsland 把 options.windowLamps 传入 H.RegisterWindowLamps，由灯光注册器处理阶段及灯数上限。窗台内沿使用 P.HOME_WINDOW_REVEAL，烧陶屋瓦使用 P.HOME_CLAY / P.HOME_CLAY_LIGHT。

窗光跟随 DayNight。白天的凹窗呈灰蓝色，黄昏到午夜逐渐透出琥珀色。远处的亮度来自嵌在窗框后的玻璃与内窗台。近处另有往下照的聚光灯，照距 1.05 米，从相机距离 19 米开始衰减，28 米退出。低档最多一盏，中、高档最多两盏，优先一层和当前最高层。废墟、白天和离岛时关闭住屋聚光灯，炉火独立。四阶段切换、画质切换、往返与卸载的回归用例在 `tests/ruins/home_house_lighting.lua`。
