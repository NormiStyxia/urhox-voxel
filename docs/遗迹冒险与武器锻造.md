# 遗迹冒险与武器锻造

## 当前可玩的第一圈

在遗迹击败一名敌人，结算时直接获得 3 强化矿和 2 淬炼砂。脱离敌人警戒、回到安全地面后，按 G 打开锻造库。新档可先用 1 矿把铁剑升到 Lv.2，装上锋芒剑印，用 2 砂稳炼到 II 阶。下一场战斗立即使用新数值。之后攒够 6 矿，可将这把铁剑熔成同等级的守门长剑，剑印继续生效。

| 武器 | 初始攻击 | 武技 |
| --- | --- | --- |
| 遗迹铁剑 / 守门长剑 / 翼剑 | 10 / 13 / 16 | 重击，沿用剑的动作和体力规则 |
| 猎弓 / 银枝弓 / 荆棘花弓 | 8 / 11 / 14 | 自动拉至满蓄力后射击 |
| 星砂时钟 | 6 | 满蓄力碎时，适合成片清理可破坏地形 |

三把弓共用射程、弹速、散布和蓄力曲线。每把弓使用配套箭矢，玩家只需换弓。法器对敌伤害和地形破坏范围分别计算；扩大挖掘范围只影响地形。新档持有普通剑、普通弓和法器。普通、珍贵两档目前沿用成品模型，以材质和发光强度区分档次。

## 打造、熔铸与时印

- 武器上限 Lv.5。每升一级消耗等于当前等级的强化矿，攻击增加初始值的 10%。法器每级还增加 8% 基础破坏半径。
- 打造普通、珍贵、传说档分别需 3、6、12 矿。可从当前装备打造同类下一档，也可补造较低档。单独打造保留旧武器，新武器从 Lv.1 开始。
- 熔铸需要二次确认。旧武器只能熔入同类下一档，整级继承。目标尚未打造时收取其打造费；目标已拥有且等级较低时，免费继承。传说武器和唯一法器受保护。
- 每类可装一枚时印，初始均可选择。换同类武器自动沿用已装时印。每枚时印单独记录精炼等级和失败次数，切换后保留。装配只核对武器类别。

| 类别 | 每阶加成（I / II / III 按倍率累加） |
| --- | --- |
| 剑印 | 锋芒加 8% 攻击、破军加 20% 破甲、震刃加 15% 削韧 |
| 矢印 | 白羽加 8% 攻击、凿甲加 20% 破甲、镇石加 15% 削韧 |
| 法印 | 裂地加 12% 地形破坏半径、蚀岩加 15% 体素破坏强度、余震加 25% 碎时削韧 |

普通精炼每次消耗 1 砂。I 升 II 的每次成功率依次为 80%、100%；II 升 III 依次为 50%、75%、100%。失败时保留已有等级，面板显示下一次概率。未到保底时可选 2 砂稳炼，到保底时 1 砂必成。

## 操作与存档

| 场景 | 操作 |
| --- | --- |
| 徒步探索或持剑、弓 | E 冻结，R 回溯，Q 释放当前武技。三类武技共用 4 秒冷却 |
| 移动 | 默认奔跑（7.2 m/s，不耗体力）；Ctrl 切换步行 / 奔跑；按住 Shift 冲刺（10 m/s），消耗体力，耗尽后回到奔跑，回复到 30% 才能再冲刺。手机：摇杆轻推步行、推到底奔跑，按住「冲」冲刺 |
| 切换武器 | 轻点 Tab 循环，长按 Tab 打开轮盘；1 / 2 / 3 分别直选剑、弓、法器 |
| 锻造与观察 | 安全地面按 G 打开锻造库，Z 切换远景 |
| 触屏 | 点击切换按钮呼出轮盘；按冻结、回溯、武技图标操作；脱战后点锻造图标 |

锻造操作即时结算。改色属于草稿，面板因受击或警戒关闭时可以恢复。撤销改色会保留已经打造的武器、材料和保底进度。

v1 / v2 本地存档载入后迁移到 v3，保留剑的配色、已选的剑弓类别和两把旧传说武器。每次先写临时文件，完成后再替换正式存档。若替换中断，下次可从上次保存恢复。Web 端沿用引擎内存文件系统，刷新会清空进度；跨会话经营需要接入持久化存档。

## 家园、龙与地图的后续规格（待开发）

第一轮家园体验以一处废弃驻地为目标。玩家从裂隙带回怪物材料，在驻地用回溯修复锻造炉。武器和家园建设共享掉落来源，让玩家在下一把武器与修复一处设施之间做选择。人形龙在炉边加工或迎接玩家，龙形负责跨越高差和远途探索。

派遣从已探索的区域选一处狩猎点，出发时显示预计归来时间与普通材料收益。回家领取后再派遣。离线加工按实际投入的原料结算，同一批奖励只能领取一次。首领图纸、首次开路和关键遗物留给手动探索。派遣时长、离线收益上限待实测，接入前需验证退出重进和重复领取。

大地图先做家园与裂隙两个区域，通过落点切场。裂隙首区建议从 160–200 米量级试做，用崖顶、半山平台与谷底形成可以反复辨认的高差。飞行主通道先按 20 米以上净宽搭白盒，用实际龙体、翼展、转弯半径和跟随相机试飞，再确定尺寸。洞室入口放在能降落的平台旁。区内按地形块组织，后续根据 Web 与手机的帧耗和内存决定加载距离。分块边界需要回测高速飞行、落脚碰撞、切回已破坏地形与谜题状态。
