# 遗迹冒险与武器锻造

## 当前可玩的第一圈

在遗迹击败一名敌人，结算时直接获得 3 强化矿和 2 淬炼砂。脱离敌人警戒、回到安全地面后，按 G 打开锻造库。新档可先用 1 矿把铁剑升到 Lv.2，装上锋芒剑印，用 2 砂稳炼到 II 阶。下一场战斗立即使用新数值。之后攒够 6 矿，可将这把铁剑熔成同等级的守门长剑，剑印继续生效。

| 武器 | 初始攻击 | 武技 |
| --- | --- | --- |
| 遗迹铁剑 / 守门长剑 / 翼剑 | 10 / 13 / 16 | Q 重击，沿用剑的动作，消耗体力 |
| 猎弓 / 银枝弓 / 荆棘花弓 | 8 / 11 / 14 | 自动拉至满蓄力后射击 |
| 星砂时钟 | 6 | 满蓄力碎时，适合成片清理可破坏地形 |

三把弓的射程、弹速、拉弓时间和散布完全相同，只有伤害不同。每把弓使用配套箭矢，玩家只需换弓。法器对敌伤害和地形破坏范围分别计算；扩大挖掘范围只影响地形。新档持有普通剑、普通弓和法器。普通、珍贵两档目前沿用成品模型，以材质和发光强度区分档次。

## 打造、熔铸与时印

- 武器上限 Lv.5。每升一级消耗等于当前等级的强化矿，攻击增加初始值的 10%。法器每级还增加 8% 基础破坏半径。
- 打造普通、珍贵、传说档分别需 3、6、12 矿。可从当前装备打造同类下一档，也可补造较低档。单独打造保留旧武器，新武器从 Lv.1 开始。
- 熔铸需要二次确认。旧武器只能熔入同类下一档，整级继承。目标尚未打造时收取其打造费；目标已拥有且等级较低时，免费继承。传说武器和唯一法器受保护。
- 每类可装一枚时印，初始均可选择。换同类武器自动沿用已装时印。每枚时印单独记录精炼等级和失败次数，切换后保留。装配只核对武器类别。

| 类别 | 每阶加成（I / II / III 按倍率累加） |
| --- | --- |
| 剑印 | 锋芒加 8% 攻击、长锋加 10% 攻击范围、震刃加 15% 削韧 |
| 矢印 | 白羽加 8% 攻击、凿甲加 20% 破甲、镇石加 15% 削韧 |
| 法印 | 裂地加 12% 地形破坏半径、余震加 25% 碎时削韧 |

普通精炼每次消耗 1 砂。I 升 II 的每次成功率依次为 80%、100%；II 升 III 依次为 50%、75%、100%。失败时保留已有等级，面板显示下一次概率。未到保底时可选 2 砂稳炼，到保底时 1 砂必成。

## 副词条与被动

武器的全部数值只剩六个：攻击、攻击范围、削韧（失衡）、破甲、拉弓移速、碎时破坏半径。每把武器有一条副词条（只改其中一个数值）和一句被动（一句话、一个数，在攻击结算时直接乘进伤害或削韧）。

| 武器 | 副词条 | 被动 |
| --- | --- | --- |
| 遗迹铁剑 | 攻击范围 +6% | 稳固：连击第三段削韧 +20% |
| 守门长剑 | 攻击范围 +12% | 守门：对失衡的敌人伤害 +15% |
| 翼剑 | 削韧 +10% | 逐风：冲刺结束后 1 秒内的首击伤害 +25% |
| 猎弓 | 拉弓移速 +10% | 游猎：对未察觉的敌人伤害 +15% |
| 银枝弓 | 破甲 +10% | 银枝：满蓄力箭削韧 +25% |
| 荆棘花弓 | 拉弓移速 +10% | 荆棘：满蓄力箭伤害 +20% |
| 星砂时钟 | 攻击 +10% | 星砂：碎时命中的敌人伤害 +20% |

护甲与弱点只对弓箭生效；剑和时之法术不拆部位。小怪只有一个受击区，没有护甲和弱点。

## 操作与存档

| 场景 | 操作 |
| --- | --- |
| 徒步探索或持剑、弓 | E 冻结，R 回溯，Q 释放当前武技。三类武技共用 4 秒冷却 |
| 移动 | 默认奔跑（7.2 m/s，不耗体力）；Ctrl 切换步行 / 奔跑；按住 Shift 冲刺（10 m/s），消耗体力，耗尽后回到奔跑，回复到 30% 才能再冲刺。手机：摇杆轻推步行、推到底奔跑，按住「冲」冲刺 |
| 切换武器 | 轻点 Tab 循环，长按 Tab 打开轮盘；1 / 2 / 3 分别直选剑、弓、法器 |
| 锻造与观察 | 安全地面按 G 打开锻造库，Z 切换远景 |
| 触屏 | 点击切换按钮呼出轮盘；按冻结、回溯、武技图标操作；脱战后点锻造图标 |

锻造操作即时结算。改色属于草稿，面板因受击或警戒关闭时可以恢复。撤销改色会保留已经打造的武器、材料和保底进度。

v1 / v2 本地存档载入后迁移到 v3，保留剑的配色、已选的剑弓类别和两把旧传说武器。v3 旧档载入时补上空的材料库存与领取记录。每次先写临时文件，完成后再替换正式存档。若替换中断，下次可从上次保存恢复。Web 端优先使用宿主的持久文件系统。当前 Maker Web 播放器在支持 OPFS 的浏览器里能跨刷新保留本地进度。文件仅存于内存时，已登录玩家在成功读取 TapTap 云档后同步库存和装备。文件系统与云档都无法持久化时，进度仅保留在本次运行中。

## 遗迹材料与行囊背包

普通探索的击杀依然结算强化矿、淬炼砂与轮转时印。以下五种专属素材会留在地上，靠近后按 F 或轻触物品提示拾取。

| 来源 | 材料 | 每次产出 |
| --- | --- | --- |
| 木灵 | 木灵凝脂 | 1 |
| 织巢虫 | 琥珀巢丝 | 1 |
| 岩甲巨兽 | 岩甲晶片 | 1 |
| 遗迹构装体 | 遗迹导能件 | 1 |
| 时蚀灵体 | 时蚀砂 | 1 |
| 采集树 | 木材 | 2 |
| 采石点 | 石料 | 2 |
| 晶簇 | 晶矿 | 1 |

默认入口的训练木桩可选五种对手，每种对手的专属素材每个存档首次可领一份。训练依然不给强化矿、淬炼砂或石印。木桩与物品同时在手边时，F 优先处理最近的可拾取或采集物。龙庭东北的晶簇和西北绑赭色布带的小树可以从训练场步行到达。采完会留下断晶岩座或带年轮的树桩，点位和领取数量一起存档。晶矿、时蚀砂分别拥有独立物品 ID，现有锻造配方照常读取强化矿和淬炼砂。

落地并脱离警戒后按 B 查看行囊。触屏从菜单进入背包。材料、武器与石印可翻页，选中卡片显示详情。武器与石印装备沿用现有安全条件与时印槽位。

运行配置见 [MaterialCatalog.lua](../scripts/combat/MaterialCatalog.lua)，采集、地面掉物与遮挡判断见 [RuinsResources.lua](../scripts/ruins/RuinsResources.lua)。

## 家园小岛与旅行地图

按 M 打开正俯视卷轴，糯米头像标出当前区域。点击岛屿启程，也可以按左右键选岛、Enter 确认，M 或 Esc 收起。触屏徒步模式点「地图」。时之遗迹与家园小岛从开局开放，传送需要下龙、落地并脱离战斗。

家园北侧木屋前的石炉与铁砧沿用锻造库，靠近后按 G 或触屏锻造键。水潭东岸设有浅阶，南侧水渠穿过岛岸形成瀑布。圆形石坪在东侧，遗迹巨龙苏醒后会随传送到石坪。返回遗迹使用上次安全落点，往返共享装备、材料及遗迹谜题状态。

卷轴图与头像分别由 Mivo Nano Banana 生成，再按最近邻和有限色板整理。家园由脚本分帧生成到同一体素世界，交互、碰撞、设施和模型用同一套米制坐标。离线几何对照见 [家园岛全景](../art/home_island/geometry-review.png)。

## 家园经营、派遣与裂隙的后续规格（待开发）

第一轮家园体验以一处废弃驻地为目标。玩家从裂隙带回怪物材料，在驻地用回溯修复锻造炉。武器和家园建设共享掉落来源，让玩家在下一把武器与修复一处设施之间做选择。人形龙在炉边加工或迎接玩家，龙形负责跨越高差和远途探索。

派遣从已探索的区域选一处狩猎点，出发时显示预计归来时间与普通材料收益。回家领取后再派遣。离线加工按实际投入的原料结算，同一批奖励只能领取一次。首领图纸、首次开路和关键遗物留给手动探索。派遣时长、离线收益上限待实测，接入前需验证退出重进和重复领取。

后续可在现有两个区域之外，通过旅行地图增加裂隙。裂隙首区建议从 160–200 米量级试做，用崖顶、半山平台与谷底形成可以反复辨认的高差。飞行主通道先按 20 米以上净宽搭白盒，用实际龙体、翼展、转弯半径和跟随相机试飞，再确定尺寸。洞室入口放在能降落的平台旁。区内按地形块组织，后续根据 Web 与手机的帧耗和内存决定加载距离。分块边界需要回测高速飞行、落脚碰撞、切回已破坏地形与谜题状态。
