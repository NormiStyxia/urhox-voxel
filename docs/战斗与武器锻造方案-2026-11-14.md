# 战斗与武器锻造方案（剑 + 弓，可拼装体素武器）

日期：2026-11-14。策划/方案：Claude；代码实现：gpt-6-astra（maker GPT）协同 worker。
本文是 worker 们共同的**唯一设计依据与接口契约**。有冲突先改本文再改代码；代码不得悄悄偏离。

## 0. 一句话

解谜态用时间法术（碎时/冻结/回溯，手上亮像素法阵光）；**战斗态**换一套：剑（近战）+ 弓（远程），武器是**小颗粒体素**，由玩家在锻造库里用“部件”拼装；不攻击时武器背在背后，脱战后武器隐藏、手光重新亮起。场景里加三种敌对生物。

## 1. 范围（v1 竖切片，不要超出）

| 项 | v1 内容 |
|---|---|
| 武器 | 1 把剑（4 个槽位）、1 张弓（3 个槽位） |
| 部件 | 每槽 2~3 个可选件，共 ~20 个部件，全部默认解锁（不做材料/掉落/经济） |
| 战斗操作 | 剑：3 段连击、蓄力重击、闪避；弓：拉弓蓄力三档、松手射击、边拉边慢走；切换武器；收/拔刃 |
| 敌人 | 石甲兽（小 Boss，1 只）、碎石哨灵（远程小怪）、苔壳虫（近战小怪） |
| 玩家 | 血量、受击硬直、倒下后回安全点复活 |
| 锻造库 | 脱战时从菜单或锻造台打开；换部件、换 3 路颜色、看数值对比；保存/恢复默认 |
| 不做 | 武器耐久、属性元素系统、掉落、多人、第三把武器、存档云同步 |

## 2. 状态机：三种“武器可见度” + 谁在手里

```
探索态 EXPLORE（脱战）    手：像素法阵光（现有手光）亮；武器：隐藏；可用：时间法术 + 解谜
   │  触发进战：①敌人对玩家警戒(aggro)，由敌人持续心跳 OnEnemyAggro ②玩家点“拔刃/收刃”按钮（PC 为 C 键）③受击。**探索态的攻击键/左键/1 仍是碎时，不会进战**
   ▼
战斗待机 COMBAT_IDLE      手：光熄灭；武器：背在背后(back)；时间法术按钮被战斗按钮替换
   │  按攻击/闪避              ▲ 攻击结束 2.5s 无新输入 → 回到背后(收刃动作 0.3s)
   ▼                          │
战斗出手 COMBAT_ACTIVE    武器：在手（剑在右手，弓在左手）
   │
   ▼  脱战：6s 内无敌人 aggro 且未受击，或点“收刃”
探索态：武器淡出隐藏（8 帧阶梯透明或体素逐层消散），手光 0.4s 渐亮
```

规则：
- **视觉即状态**：手光亮 = 可以解谜；武器出现 = 战斗中。不另加状态图标。
- 战斗态**禁用**碎时/冻结/回溯（按钮整组换成战斗组），防止战斗里乱碎遗迹。脱战 1s 后恢复。
- 骑龙态独立，不进入战斗态；上龙前强制脱战（立刻收武器）。
- 过渡中的输入：拔刃/收刃动作期间可被闪避取消。

## 3. 武器体素与挂点

- 小颗粒：体素边长 **s = 0.03m**（对照：人物 0.022、龙身 0.08、墙 0.0625、地形 0.125），剑全长约 1.0m ≈ 33 格，弓高约 1.1m ≈ 37 格。每件武器**合并成单个 VoxelVolume**（不 Finalize、无物理体、无碰撞，参考 `DragonRig.lua`/`TimeObject.lua` 创建方式：`world:CreateVolume` → `SetVoxelMaterial` → `RebuildGeometry`）。上限：单把 ≤ 4000 体素。
- 挂点（Node）：
  - `back_sword`：`body` 骨下，斜背在背后（约 -35°，剑尖朝上左），`back_bow`：`body` 骨下横背；
  - `hand_right`：复用 `NomiController.castSocket`（`arm_right` 下的掌心点）作为剑柄握点；
  - `hand_left`：`arm_left` 下对称点，作为弓握把。
- 姿态：握点对齐部件 socket `grip`；挥剑动画由 `BlockCharacter` 现有 `armed/aiming` 手臂姿态叠加，**v1 不新建动画系统**，用程序化摆臂 + 武器节点自身的旋转/位移做打击感（剑沿弧线挥，拉弓左臂前伸右臂后拉）。
- 调色板：新开槽位 **160–199**（遗迹 100–159、龙 40–57/65–77 已占）。剑 160–175，弓 176–191，192–199 预留（锻造预览/特效）。实现前先确认引擎调色板上限与现有占用，别越界。每把武器 3 个颜色通道：**主色 / 副色 / 点缀色（可带自发光）**，改色=改这几个调色板项，不重建体素。
- 精度要求：边缘不要锯齿成块——刃口 1 格宽，刃脊有一格高光色；护手/剑首要有 2 格的明暗层次，不允许整件一个纯色块。

## 4. 部件系统（数据驱动）

### 4.1 数据格式（`scripts/combat/WeaponParts.lua`，worker 1 负责）

```lua
-- 每个部件：
{
  id = "blade_straight",           -- 全局唯一
  weapon = "sword",                -- sword | bow
  slot = "blade",                  -- 槽位名
  name = "直刃", desc = "均衡",
  -- 体素：按层(y)存字符矩阵，字符=颜色通道/材质，'.'为空；坐标轴约定见 4.3
  voxels = { ...ascii layers... },
  palette = { P="primary", S="secondary", A="accent", D="dark" },
  sockets = { root = {0,0,0}, top = {0,20,0} },   -- 与相邻部件对接的点（体素坐标）
  stats = { attack=+0, speed=+0, reach=+0, poise=+0 },  -- 对最终数值的加成
}
```

### 4.2 槽位与选项

**剑**（槽位自下而上拼接：剑首 → 握柄 → 护手 → 剑刃）

| 槽位 | 选项 | 数值倾向 |
|---|---|---|
| 剑刃 blade | 直刃（均衡）/ 阔刃（攻击+ 速度−）/ 细剑（速度+ 攻击−，穿刺更长） | attack, speed, reach |
| 护手 guard | 十字（均衡）/ 翼形（失衡值+，更稳）/ 无护手窄身（速度+） | poise, speed |
| 握柄 grip | 缠革（均衡）/ 长柄（reach+，速度−） | reach |
| 剑首 pommel | 圆首（均衡）/ 晶首（轻微蓄力加速）/ 配重（攻击+ 速度−） | attack, speed |

**弓**（槽位：弓臂 / 握把 / 箭簇）

| 槽位 | 选项 | 数值倾向 |
|---|---|---|
| 弓臂 limbs | 短弓（拉弓快、射程近）/ 长弓（射程远、拉满慢、伤害+）/ 反曲弓（均衡） | draw speed, range, attack |
| 握把 grip | 皮握把（均衡）/ 稳定握把（移动拉弓更快、散布小） | spread, move |
| 箭簇 tip | 铁簇（均衡）/ 骨簇（轻、速度快伤害低）/ 晶簇（命中时附带小范围晶爆，击破部位加成） | attack, poise |

颜色：每个部件在 voxels 里用字符 `P/S/A/D` 指明通道；锻造库提供 3 路 × 6 套预设色板（时砂金、冰蓝、遗迹灰、铜红、苔绿、暮紫），可单独选每一路。

### 4.3 组装（`WeaponBuilder.lua`）

1. 输入：`{ weapon="sword", parts={blade="blade_straight", guard=..., grip=..., pommel=...}, colors={primary=..,secondary=..,accent=..} }`。
2. 坐标约定：+Y 为“从握点指向剑尖/弓上端”，+Z 为刃面法线（薄方向），+X 为刃宽方向；原点在**握点 grip 的中心**，这样挂到手上无需额外偏移。
3. 对接：下一槽部件的 `root` 对齐上一槽的 `top`（整数体素对齐，不插值）。重叠格取优先级高者（刃 > 护手 > 握柄 > 剑首）。
4. 合并成稀疏体素表，求包围盒，建一个 VoxelVolume。**只在锻造变更/首次装备时重建**，战斗中不重建。
5. 同时导出：
   - `stats`：基础值 + 各部件加成（见 §6.1 的基础数值），夹紧到合理范围；
   - `hit`：剑 → 沿 +Y 的胶囊（半径 0.12m，长度 = 握点到刃尖实际长度）；弓 → 箭发射点（`limbs` 上沿中点）+ 方向；
   - `bounds`：给锻造预览用。
6. 缓存：相同 `parts+colors` 不重复构建；切换部件时只替换变化的槽位再合并。

### 4.4 存储（`WeaponStore.lua`）

装备配置存本地 JSON（`File` 沙箱，参考 `engine-docs/recipes/file-storage.md`，`cjson`）：`{ version=1, sword={parts=..., colors=...}, bow={...}, active="sword" }`。Web 刷新会丢失（引擎已知限制）——锻造库界面上用一行 12px 文字说明，不做云同步。读取失败/部件 id 失效 → 回退默认配置，不报错。

## 5. 战斗系统

### 5.1 通用
- 玩家 HP 100（像素心形条，见 §8）。受击：硬直 0.25s + 击退 0.6m + 0.8s 无敌帧；归零 → 倒下 → 1.2s 后在最近安全点（`NomiController.safePos`）以满血复活，战斗态清空。
- **打击感**：命中时顿帧 0.05s（只暂停攻击者与目标动画，不改 timescale）、体素碎屑 6~10 粒（复用/扩展现有特效 `fx_`，新增 kind="hit"）、屏幕轻微抖动（相机 offset，幅度 ≤ 0.03m）。
- 判定都用**解析几何**（胶囊/球），不依赖物理刚体，不依赖体素碰撞；伤害结算入口统一：

```lua
-- scripts/combat/Hit.lua
Hit.Apply(target, {
  dmg = 12, poise = 8,        -- 伤害 / 失衡值
  part = "foreleg_l",         -- 可选：命中的敌方部位 id
  kind = "sword"|"arrow"|"crystal",
  pos = Vector3, dir = Vector3,
  source = "player"|enemyId,
})
-- target:ApplyHit(info) -> { hit=true, killed=false, partBroken="..." }
```

### 5.2 剑
> 时间轴以 §13 动画片段为准（普攻 0.46/0.42/0.62s，重击释放 0.62s，闪避 0.45s）；下表时序仅为设计意图，判定/取消/无敌窗口一律读片段 `events`。
| 动作 | 输入（触屏 / PC） | 时间轴 | 规则 |
|---|---|---|---|
| 普攻 1/2/3 | 攻击键点按 / 左键 | 前摇 0.10s → 判定 0.12s → 后摇 0.18s（第 3 段后摇 0.30s） | 判定窗口内每个敌人每段最多受一次；后摇前 0.12s 内再按进入下一段；第 3 段为下劈，击退更大 |
| 重击 | 攻击键**长按 ≥0.45s** 松手 / 右键 | 蓄力最多 1.0s，蓄满有闪光；前摇 0.22 → 判定 0.14 → 后摇 0.55 | 伤害 ×2.2、失衡 ×2.5；蓄力中移速 ×0.4；可被闪避取消 |
| 闪避 | 闪避键 / Shift（战斗态） | 0.45s 位移 3.2m，前 0.25s 无敌，冷却 0.6s | 朝摇杆方向，无输入朝背后；不可落入虚空边缘（用 Terrain.HasGround 截断终点） |

基础数值（再由部件修正）：攻击 10，速度 1.0（影响前后摇倍速，范围 0.7~1.4），reach 1.0（判定胶囊长度倍率，0.8~1.4），poise 6。

### 5.3 弓
| 动作 | 输入 | 规则 |
|---|---|---|
| 拉弓 | 攻击键**按住** / 左键按住 | 0→1 蓄力 0.7s（受弓臂影响）；三档：<0.3 弱 / 0.3~0.8 中 / ≥0.8 满；拉弓中移速 ×0.5；左手持弓，右手拉弦 |
| 射击 | 松手 | 沿**相机准星射线**方向射出（命中点修正，起点为弓箭发射点）；弱 18m/s / 中 30 / 满 44，重力下坠 6m/s²；满蓄力穿透 1 个小怪 |
| 命中 | — | 箭=线段 vs 敌人球体/部位球逐帧扫掠 + 体素/地形射线（遇墙消失并留 0.8s 箭插入）；弱点（头/核心）×1.6 |
| 数量 | — | 无限箭；同屏箭 ≤ 12 个，对象池复用 |

基础：攻击 8（满蓄力 ×1.8），draw 0.7s，range 36m。

### 5.4 切换与收刃
- 切换武器按钮：0.4s 动作，旧武器收到背后（若在手）→ 新武器显示为背后待机；只有当前武器上背，另一把隐藏。
- 收刃键：战斗态→探索态，手光重新点亮，法术可用。

### 5.5 敌人（不进物理世界，kinematic 节点 + 解析判定）

共同要求：
- 移动用射线贴地 + `Terrain.HasGround(x,z)` 判断边缘，**绝不走出岛缘/掉进虚空**；AI 位置计算每帧限 5 个敌人以内。
- 状态：`IDLE → PATROL → ALERT(0.4s 抬头) → CHASE → TELEGRAPH(前摇可读) → ATTACK → RECOVER → STAGGER → DEAD`。
- 前摇必须“可读”：身体压低/发光色变化 + 地面预警圈（像素圈，阶梯扩张），**不允许无前摇的伤害**。
- 死亡：体素碎散（球形分裂、飘散淡出），不留尸体；掉落先不做。
- 体素造型：程序化拼装（参考龙的 SDF/分部件做法，更简单即可），每个敌人 ≤ 3000 体素，可分骨节节点（头/躯干/四肢），颜色走 §3 同样的调色板扩展槽 **200–239**（敌人专用）。

| 敌人 | 定位 | 行为 | 部位/弱点 |
|---|---|---|---|
| **苔壳虫**（小怪，一次 2~4 只） | 教近战和闪避 | 绕圈接近→0.6s 前摇弓背→扑咬 1.8m；扑后 0.8s 硬直是输出窗口 | 单体，HP 30，背壳硬（正面 -30%），肚皮弱点 |
| **碎石哨灵**（远程小怪，1~2 只） | 教弓和走位 | 悬浮，保持 8~12m 距离，0.9s 聚能后发射慢速石弹（12m/s，可闪避/可被剑打散）；被近身会后撤 | HP 24，核心（前胸晶）为弱点 |
| **石甲兽**（小 Boss，1 只） | 战斗核心体验 | 见下 | 部位见下 |

**石甲兽**（遗迹守卫兽，四足，体长约 3.2m，体素 ~2800）：
- 部位：`head`、`foreleg_l`、`foreleg_r`、`back_armor`（背甲）、`core`（背甲下的晶核，背甲破后暴露）。每个部位有“甲值”，被打满则**破甲**：前腿破甲→冲撞更容易摔倒；背甲破甲→暴露核心，弱点倍率开启。
- 招式（全部有前摇和预警）：
  1. **冲撞**：低头刨地 0.9s（预警直线条）→ 直线冲 9m（撞到石柱/墙 → 眩晕 2.5s，是最大输出窗口）；
  2. **横扫**：抬前腿 0.7s（预警扇形）→ 前方 120° 扇形 3.2m；
  3. **跺地**：后撤 → 跳起 → 落地圈形冲击 4m（可跳过或闪避）。
- 阶段：HP < 50% 时背甲裂开，冲撞变为连续两次、跺地加快；不做复杂阶段转换动画（粒子 + 咆哮 + 一次地面圈即可）。
- 数值：HP 600，poise 100（失衡 → 倒地 3s，倒地期间所有伤害 ×1.5）。

**布置**（场景：浮空岛，遗迹环 + 中央岛）：
- 苔壳虫：中央岛草地 2 组，每组 3 只，距玩家出生点和桥头至少 15m；
- 碎石哨灵：外环南路、桥头两侧，各 1 只；
- 石甲兽：中央岛的北侧开阔处（避开解谜关键路径与龙），有一圈“遗迹石圈”作为 Boss 场地，场地内自然散布 2~3 根可被冲撞的石柱。
- 刷新规则：脱战且玩家离开 40m 外 → 重置；击败后不再刷新（v1 不做重生）。位置由 worker 3 用 `Terrain.IsSafeGround` 逐点校验，不凭记忆写坐标。

### 5.6 解谜 / 战斗分离的接口
- 战斗态下 `TimeSpells` 的施放被拒绝（提示“战斗中无法使用时间之力”，12px，信息条出现 1.2s）。
- 战斗中的碎屑/箭不触发 `TimeObject` 的破坏逻辑；剑不能碎石（v1），避免两套系统互相污染。

## 6. 锻造库面板（ForgePanel）

### 6.1 交互与布局（横屏 844×390 基准，沿用像素冒险卷轴风）
```
┌──────────────────────────────────────────────────────────┐
│ [剑][弓]                           锻造库            [×]  │  ← plaque_ink 顶栏
├───────────────┬────────────────────────┬─────────────────┤
│ 部位列表       │     预览（慢速旋转）      │  数值对比       │
│  刃  ▸ 直刃    │        ⚔ 体素预览        │ 攻击 ▮▮▮▮▯ +2  │
│  护手 ▸ 十字   │   拖动转，双击回正        │ 速度 ▮▮▮▯▯ -1  │
│  握柄 ▸ 缠革   │                         │ 范围 ▮▮▮▮▯     │
│  剑首 ▸ 圆首   │                         │ 失衡 ▮▮▯▯▯     │
├───────────────┴────────────────────────┴─────────────────┤
│ 选中部位的选项卡：[直刃][阔刃][细剑]   颜色：主● 副● 点缀●  │
│                        [恢复默认]            [装备并关闭]   │
└──────────────────────────────────────────────────────────┘
```
- 全部可点击目标 ≥ 56dp；部件选项卡为 `panel_paper` 小卡（图标/12px 名称/一行 12px 描述）。
- 点击部件立即重建预览（≤ 1 帧内完成，不卡顿，必要时分帧）；数值条为 0..5 格像素条，改动项闪一下并显示 ± 差值。
- 仅**脱战**可开；打开时暂停战斗输入（不暂停世界）；关闭时若武器配置变化，重建并重新挂到背后/隐藏。
- 预览：参考 `engine-docs/recipes/scene-to-nanovg.md`（3D 场景预览），用小的独立场景/视口渲染武器体素；**若在 Web 实测预览不可用，降级为 2D 部件拆解图（每部件图标 + 总览剪影）**，功能不降级。

## 13. 人物战斗动画（攻击 / 受击 / 闪避 / 拔收 / 死亡）

### 13.1 现状与做法
- `BlockCharacter:Update(dt, s)` 每帧用 `SetBone(name, pitch, yaw, roll)`（度，`Quaternion(pitch,yaw,roll)`）**绝对赋值**所有骨骼。约定：`pitch` 正值=骨骼下端往后摆（手臂**负 pitch=向前/上举**，现有持械前举 -80）；`roll` 正值=下端甩向 +X（右臂外张取正，左臂取负）。可用骨骼：`root`(位置)、`body`、`leg_right/left`、`arm_right/left`、`head`、`hair_*`、`hood`、`coat_upper/lower`、`cloak_strip_*`。
- 做法：**不改 BlockCharacter**。新增覆盖层 `CombatAnim`：在 `nomi:Update()` 之后调用 `anim:Apply(nomi)`，对被片段控制的骨骼做 `Quaternion` slerp 混合（片段权重 0→1→0，淡入淡出各 0.06~0.12s），未被控制的骨骼保持原有行走/待机/披风飘动。
- 动作用**关键姿态 + 缓动曲线**表达，不做逐帧：每个片段 4~8 个关键姿态；用 ease-in（蓄势慢）+ ease-out-expo/突加速（出手快）+ 过冲回弹（收招）表达重量；整段允许“**取帧率降低**”（≈24fps 量化时间）做出像素风“有节奏的顿挫”，且在判定窗口内强制每帧采样不丢帧。

### 13.2 片段数据格式（`scripts/combat/AnimClips.lua`）
```lua
{
  id = "sword_light_1", dur = 0.46, weaponType = "sword",   -- weaponType=武器种类；weapon 轨道见下
  phases = { anticipation={0,0.10}, active={0.10,0.22}, recovery={0.22,0.46} },
  -- 关键姿态：t 为归一化时间 0..1，欧拉角度 {pitch,yaw,roll}；ease 指向该关键帧的缓动
  keys = {
    body      = { {0,{0,0,0}}, {0.22,{-6,+28,0},"inQuad"}, {0.48,{+14,-35,0},"outExpo"}, {1,{0,0,0},"outBack"} },
    arm_right = { ... }, arm_left = { ... }, head = { ... }, leg_right = { ... }, leg_left = { ... },
  },
  root  = { {0,0}, {0.5,-0.04}, {1,0} },          -- root 竖向偏移(米)
  weapon = { {t, offset={x,y,z}, euler={p,y,r}} }, -- 手持武器相对手握点的附加位姿，给 WeaponRig:SetSwing
  motion = { {t0=0.10,t1=0.26, forward=0.9} },    -- 位移（米，沿人物朝向），由战斗模块折算为 cc 速度
  events = { {t=0.22,"hit_on"}, {t=0.48,"hit_off"}, {t=0.55,"cancel_open"}, {t=0.9,"cancel_close"} },
  speedStat = "speed",                           -- 播放速度乘以武器 stats.speed
}
```
**时间轴以片段为唯一来源**：W2 的判定窗口、取消窗口、输入缓冲全部由片段 `events` 驱动，不在战斗代码里再写一套数字。**符号方向以 Web 实际画面为准**：数值是初值，worker 须先做 1 个片段验证正负号再批量做，其余按同一约定。

### 13.4 武器随动
- 战斗模块每帧取 `anim:GetWeaponPose()`（`offset, euler`）调用 `rig:SetSwing(offset, euler)`，武器节点在手 socket 下叠加该位姿；武器自身拖尾用 6~8 个“残影”半透明体素片段（取过去 8 帧的手 socket 位置，球形/线段插值，极低成本），颜色用武器点缀色。
- 背后待机：武器随 `body` 骨摇摆，跑步时有 1~2° 延迟抖动（次级运动）。

### 13.5 敌人受击反馈（W3，轻量）
- 命中点“白闪”：目标被命中体素/部位材质 0.08s 内提亮（改发光强度，不换材质对象）；
- 受击微移：目标节点沿击方向 0.05m 位移 + 2 帧回弹（**不做缩放**）；
- 部位破甲：该部位关节节点抖动 3 帧、碎屑 8~12 粒、颜色换裂纹色；
- 倒地/眩晕：整体倾倒的角度关键帧，另加冒“石屑”粒子。


## 15. 调研修订（R2《手机操作与 HUD》，2026-11-14）— 优先级高于 §7/§8 同项内容

## 16. 调研修订（R3《武器锻造与敌人》，2026-11-14）— 优先级高于 §4/§5.5/§6 同项内容

来源：`docs/research/R3-武器锻造与敌人.md`。

### 武器与锻造
1. **属性拆分**：`poise`（全身失衡值）与新增 `armorBreak`（部位破甲倍率，默认 1.0）分开；晶首 = 蓄力修正（拉弓/重击蓄满时间 −8%，攻击 −0.5）；晶簇 = 命中小范围晶爆（半径 0.8m，伤害 = 箭伤 ×0.25），`armorBreak` +0.25，**代价：箭速 −10%、射程 −8%**；稳定握把 = 移动拉弓速度 ×0.6（原 ×0.5）、散布 −25%，**代价：拉弓速度 −8%**。不允许任何部件在所有四项上同时占优——部件表每个选项必须同时有正负值（或明确代价）。
2. **预设与复原**：每把武器提供三套推荐组合（**均衡 / 快攻 / 破甲**）和**单槽复原**；保留“恢复默认”；增加撤销一步。

5. **版式**：宽屏三栏（部位列表 / 预览 / 数值），小屏（<720dp 宽）自动折叠数值到预览下方可展开；预览固定握点与尺度，提供显式“回正”按钮与 3 色板；所有触点 ≥56dp 逻辑尺寸。
6. **安全开放**：锻造库**仅在安全区且无敌人警戒时开放**；已打开时若任何敌人进入警戒/玩家受击，**立即关闭并保留草稿**（`ForgePanel.Close(keepDraft)`，下次打开恢复草稿）；不暂停世界。“预览一帧内重建”改为**实测目标**：重建分帧（每帧 ≤2ms 预算，超出则分批），避免卡顿。
7. **刀光**：短阶梯带（≤8 段）+ 少量方形粒（≤8 粒）；3cm 体素只是建模尺度，战斗辨识靠整体**剪影**，部件设计须保证剪影差异（刃宽、护手形状、弓臂曲线）。

### 敌人
8. **石甲兽**：保持三招；**背甲破坏 → 立即暴露核心**；**HP<50% 只进入狂暴**（加速、双冲、更短收招），**不自动开甲**（避免半血自动开甲冲淡定点破甲的价值）；若某关需要保底开甲，须作为明确的辅助机制另列，不属 v1。

11. **遭遇构成**：每个遭遇点先 **2 虫 + 1 哨灵**；Boss 独立；所有冲撞/击退/后撤按**敌人体半径**做全路径地面检查（身体半径内任意采样点无地面则截断），防止大体型中心有地而身体悬空。

## 19. 战斗表现优化（R5《战斗表现与 Juice》，2026-11-14）— 在 §14–§18 基础上叠加；冲突时数值以 §14/§18 为准，表现语义以本节为准

### 19.1 统一命中事件（W2 负责，所有表现共享）
一次伤害结算只产生**一个**表现事件，声音/火花/镜头/HUD/敌人反应都订阅它，避免重复触发：
```lua
HitEvent = {
  swingId = n,                      -- 同一次挥击/箭编号，群攻按它合并（顿帧取最大、相机包络只触发一次）
  weapon = "sword"|"bow"|"crystal"|"stone",   -- 来源
  tier = "light"|"heavy"|"third"|"arrow_weak"|"arrow_mid"|"arrow_full",
  material = "soft"|"armor"|"core"|"stone",   -- 命中的部位材质（由敌人 hurtShapes 的 material 字段给出）
  part = "head"|..., pos = Vector3(接触点), dir = Vector3(斩向/弹道方向，单位), normal = Vector3?,
  broke = bool(破甲), staggered = bool, killed = bool, weak = bool,
}
```
- 空挥只触发 `sword_whoosh`，不产生 HitEvent。命中声音必须以**实际结算**为触发点（不能在 hit_on 无条件播放）。
- 硬甲、弱点、破甲、软体四类反馈：区别首先靠**形状与声音**，其次才是颜色。

### 19.2 镜头（W2；镜头先保构图再加震，震动/FOV 冲击各自可关）

## 20. 动作生动化（用户反馈“动作非常潦草”，2026-11-14）— 在 §13/§18/§19 之上叠加；冲突时以本节为准

### 20.1 诊断（Web R3 画面 + 代码）
- 摆幅太保守：重击出手帧里剑只是细线，手臂几乎不动；相机 5m/FOV55，角色在屏幕上很小，**必须把动作做“大”（动画风格化夸张）**。

- 闪避无镜头反应、人物姿态不明显：见 20.5。
- 背后武器只是挂在 body 骨上，不是“浮现—悬挂—飞到手”：见 20.2。

### 20.2 背后武器（原神式）— W1 `WeaponRig`
状态机（SetPose 兼容保留 hidden/back/hand，内部细化）：
1. **hidden → materialize（0.30s）**：体素按层从下到上 6 步阶梯淡入 + 8 粒点缀色碎光在挂点周围向内收拢（用 §19.4 共享粒子预算，≤8 粒）；结束时一次 0.08s 小闪。
2. **hang（悬挂）**：武器**悬浮**在背后，不贴体：局部偏移（x0, y+1.05m 相对 root, z −0.30m），剑斜 35°（剑尖朝上偏左，约 −35° 绕 Z、+15° 绕 X）、弓竖挂略偏 8°；轻微漂浮 ±0.02m @0.6Hz；带弹簧延迟跟随身体转向/移动（落后 0.08s，最大偏离 0.12m）；点缀色边缘微光（emissive 槽，亮度随时间 0.9~1.0 呼吸）。

4. **stow（0.18s）**：反向飞回挂点；到点时轻微回弹（0.02m）+ `blade_sheath` 音。
5. **dissolve（0.30s）**：脱战时反向 materialize（从上到下 6 步消散 + 碎光向外），随后 hidden。
弓同理，但挂点为横挂于背后（弓背朝外，弦朝身体）；弓飞到**左手**，剑到右手。**不要改 SetPose/GetHit/SetSwing 对外语义**；新增 `rig:SetFlyProgress`（只读诊断）可选。

### 20.4 弓（对照 Minecraft 弓）— W1 `WeaponParts/Builder/Rig` + W4 姿态
- **规范**：握把在手心；**弓背（凸面）朝目标（+Z），弦在射手一侧（−Z）**；弓竖直（+Y 向上），箭沿 +Z 搭在握把右侧；拉弓时弦中点沿 −Z 被拉向射手面部，弓臂向射手一侧弯（视觉用 3 档弦位置：p=0 / 0.5 / 1 对应弦中点 z = 0 / −0.18m / −0.35m）。箭上弦：p>0.05 显示一支箭（体素：杆+羽+簇，随簇部件换颜色）。
- **W1 先审计**：在 F7/测试里输出弓的俯视 ASCII（x-z 平面）确认凸面朝向，修正 Builder/Rig 的 Quaternion(90,0,0) 基准或体素数据，使“弦朝射手、弓背朝目标”成立；加离线测试（弦中点 z < 握点 z，弓背 z > 握点 z）。
- **姿态（W4）**：MC 式——躯干朝向目标；左臂前伸指向目标方向（俯仰跟随相机 pitch，上下 ±35°夹紧）；右手拉弦到嘴角/下颌高度，右肘位置用瞄准 IK；p 越大右手越靠近面部；头略低。
- **镜头（W2）**：拉弓 p 从 0→1，FOV 渐收 −5°（0.5s 内），灵敏度 ×0.65；松手 0.1s 复位；准星轻微收缩；满蓄一次小抖动。

### 20.5 闪避：人物 + 镜头 — W4 姿态 + W2 镜头
- 姿态加大（取代 §18 姿态表数值，时间不变）：root 最低 −0.24m；躯干前倾 30°、侧滑侧倾 12°；持剑臂**向后拖**（pitch +55°），另一臂向前平衡；腿大跨步（前后腿差 55°）；头反向补偿保持看目标；**脚下尘线**（沿滑向 0.4~0.7m 的 3~4 个地面方粒）。
- 镜头（默认开，可 F3 关）：接受滑步瞬间**镜头目标滞后**——相机焦点相对角色向后保留 0.25–0.35m 偏移，用二阶弹簧 0.18s 追上（过冲 3%）；镜头距离 +0.25m（0.08s 拉远，0.25s 回收）；**FOV +3°**（0.05s 进入，0.20s 回落）；水平偏移不变，不滚转、不抖动，准星保持稳定；0.22s 后接攻击则镜头停止拉远并带 0.15m 前推（“进身”），无攻击则正常回收。
- 攻击镜头：出手前 0.06s 轻微后拉 0.08m（蓄势），接触点带 §19.2 包络，重击 FOV +2°；第三段落地 0.03m 下压。
