# 遗迹交互与骑龙表现（2026-11-13）

基于 a98b2d6，保留 Web 的鼠标拖动／锁定降级逻辑。只调整现有场景、时间技能与骑龙适配，不修改引擎库或人物模型。

## 玩家可见的变化

- 瞄准时之物件：独立的亮边与金色准星，命中位置出现 I–XII 罗马数字时钟。完整、碎裂、冻结的选择反馈都跟随同一个物件，移开后淡出；复原常态仍无逐体素描边。
- 长按左键／1 蓄力 1.4 秒，破坏半径按平滑曲线从 0.9m 到 3.2m；显示进度和范围圈，松开一次释放。失焦、调试面板或上龙取消蓄力。时间物件保留整件碎裂规则，范围影响附近可碎物件和碎片细分。
- 手部旋转时钟法阵、命中扩散环与原光束叠加。共 4 个命中环循环复用，非无限创建节点。
- 外围墙体改为 32 片局部平直体积旋转拼接，保留门洞、坍塌和柱墩；不再沿世界网格逼近圆形。墙精度仍 0.125m。
- 树干保留 0.0625m 方形体素硬面，主干、树根和枝条连续收细，树皮增加疤痕和微凹凸；中央庭院地砖加入石板磨耗、窄裂纹与颗粒。

## 骑龙和吐息

- 角色在龙姿态更新之后重新贴鞍座，消除一帧错位。保留 W/S 前进刹车、A/D 转向、Shift 空中冲刺、Space 起飞上升、C 下降、L 降落、G 滑翔。
- F 下龙先检查：空中／起降阶段提示先落稳；落地后在两侧及后方寻找有地面、无墙、头顶有空间且不在龙体内的位置。
- 遗迹外部角色控制器增加龙躯干、颈、头、尾根和四肢的运动学避让；推开之前检查场景碰撞，避免把人推入墙里。不是全身刚体模拟。
- 龙移动和转向增加主体球体扫掠，碰墙停止位移／速度；地面移动检查台阶高度与落差。仍保留原动画、步态及飞行惯性。
- 骑乘保留准星，B 地面吐息向准星偏转（头部左右 ±35°、俯仰 ±40°）；空中给出降落提示，不强行套用地面吐息姿态。
- 吐息沿嘴部方向查询首个真实碰撞表面，光束截断到命中位置。墙面也有定向冲击环和命中光；新发射粒子的寿命随距离缩短。
- 破坏以 0.12 秒间隔处理，只伤害当前命中的普通可破坏体积，强度 3（古石硬度 4 仍保护）。时间物件走自身碎裂／冻结接口，同次吐息每物件只处理一次。
- 向上表面落点产生材质冰层，逐渐扩大，最多 6 片；最后一次命中后 13 秒开始融化、18 秒消失。世界高度限制防止染到上下楼层。冰层是视觉覆盖，不新增滑倒规则或薄片碰撞。

## 验证与 Web 接手

离线使用 Lua 5.4：语法、真实生成器的旋转墙接缝／门洞采样、树网格硬法线／绕序／预算、回溯体积生命周期、蓄力松手／取消、龙身推开／撞墙／安全下龙、伤害限频／冰层上限和消退。

现有骑龙输入、冲刺、风摆、飞行姿态数值测试继续跑；旧测试替身补齐当前控制器构造已要求的 size、vS 与 rig 字段，未改变生产飞行动力学以迎合测试。

Web 仍需画面与实际物理验收：白天／黄昏的平直墙面、罗马数字可读性、完整和冻结物件选中、满蓄释放、近墙旋转／降落／下龙、对墙／碎石／坡地吐息、冰层融化。离线测试不代表 SurfaceShader 已编译或 Web 画面已通过。禁止用已知不兼容的本地 Metal Runtime 代替 Web 验证。

## 追加：骑乘长按普通吐息

用户追加要求：同一个破坏操作，徒步时蓄力碎时，骑龙时长按持续普通吐息。地面、飞行、滑翔均可喷射，松手立即停；现有 B 键大招保留地面长前摇施放。

实现：dragon/DragonStream.lua + DragonStream.shader。射程 18m，普通碎石伤害强度 1.8，较窄命中范围；使用 18 顶点交叉霜流、96 个粒子上限和低频小冲击环，不生成大招晶林。命中仍走 RuinsDragon 的限频破坏与冰层处理，回溯物件走自身状态接口。普通吐息以颈／头／下颚姿态叠加，保留飞行动作和移动输入。

移动端接线约定（已发给「像素风冒险卷轴移动端UI优化」会话）：

- RuinsDragon.New 自动建立 M.stream；RuinsDragon:Update 自动推进，无需 Scene 重复调用。
- Scene 提供 M.readStreamInput()，返回 held, allowed。PC 左键／1；移动端 TouchInput.Down("breath")。普通 breath 不再映射 KEY_B 的 Press，大招单独映射 breathSpecial。
- 在上下龙、失焦、菜单、触摸取消、输入切换时停止；M.stream:Stop(true) 表示需要先松手再按。M.stream.active 可供 UI 显示喷射状态。
- 普通吐息按钮与步行碎时主按钮保持相同位置和尺寸，地面／空中都是持续 held 语义。
- tests/ruins/stream.lua 检查持续按住、立即松手停止、地面／空中状态保留、首命中限距、取消后重新按下、大招互斥与几何预算。
