# 锻造库改版方案（2026-11-15）

## 为什么改
- 像素字 + 像素面板在手机上读不清，整套 UI 不必都是像素风。
- 右上预览（独立 Scene + RenderTexture）在 Web / Windows 都没真正出过 3D，作废。
- 新方向：**右侧干净的深蓝玻璃面板（前端归 Claude）+ 左侧天空独立小展示间里慢转、可拖拽的 3D 体素武器（引擎代码归 Astra）**。像素图标保留。

## 分工
| 内容 | 负责 |
|---|---|
| `scripts/ui/ForgePanel.lua` 整个重写（版式、主题、字体、交互、淡入淡出、文字/数值） | Claude |
| `scripts/combat/ForgeShowroom.lua`（新）展示间 3D 与相机 | Astra（astra-weapons） |
| `RuinsScene.lua` 里与视口/相机/输入相关的少量接线 | 仅在展示间需要时，由 Astra 最小改动并同步 W2 |

## 展示间接口（Claude 的面板只调用这些）
模块：`require('combat.ForgeShowroom')`，全部方法点号调用，失败不抛错。

```
Showroom.Enter(scene, opts) -> boolean
    scene = 主场景；opts = { focusX = 0.30 }   -- 武器出现在屏幕横向 30% 处（左侧）
    建展示间、切换 renderer 视口到展示间相机；失败返回 false 并回滚（面板退回 2D 侧视）
Showroom.Exit()                -- 销毁全部节点，恢复进入前的视口/相机；可重复调用，幂等
Showroom.SetWeapon(single)     -- single = {weapon='sword'|'bow', parts={...}, colors={...}}（同 Builder.Compile 输入）
                               -- 内部用 Builder.BeginPreview/StepPreview 增量构建，每帧 ≤2ms
Showroom.Update(dt)            -- 每帧：构建步进、自转、拖拽惯性
Showroom.DragBegin() / Showroom.DragBy(dxPixels) / Showroom.DragEnd(velocityPixelsPerSec)
Showroom.Home()                -- 平滑回正并恢复自转
Showroom.IsReady() -> boolean  -- 武器网格已构建并正在显示
Showroom.State() -> 'off'|'building'|'ready'|'failed'
Showroom.SetFocus(fractionX, fractionY)  -- 窗口尺寸/布局变化时改投影偏移
```

## 展示间要求
1. 位置：主岛上空很高处的独立小房间（远离龙与云层；注意浮点精度，建议 y≈800–1500，Astra 自行确认不与云/龙/岛的包围盒重叠）。
2. 隔离：自己的 Zone（环境光、雾关闭）+ 自己的灯；主场景太阳光不能照进展示间，展示间灯也不能照到主场景（用 light mask / zone mask；`Light.lightMask`、`Drawable.viewMask` 或视口分层任选其一，写进文件头注释）。背景暗蓝无光照 backdrop（NoTextureUnlit）+ 一个很小的圆台，不要云/天空盒穿帮。
3. 灯光：主光偏左上暖白，轮廓光偏右后冷蓝，环境光低；体素材质沿用 `NomiVoxel.xml` 顶点色。
4. 相机：透视（FOV≈30–35），武器全部可见（弓长条、剑长条都要整只入画），用 `Camera.projectionOffset` 或视口把武器放在屏幕左 55% 区域中心偏左（`focusX`）。
5. 自转：约 12°/s 绕竖直轴；拖拽时停转，松手后带惯性衰减，约 1.5s 后恢复自转；`Home()` 回到 25° 并恢复自转。
6. 武器模型：用 `WeaponBuilder` 的 CustomGeometry 预览路径（`BeginPreview/StepPreview/DisposePreview`，已在离线测试覆盖）。**不得**再用第二个 VoxelPhysicsWorld、RenderTexture、第二个 Scene。换武器/换部件时旧网格 Dispose，新网格出来前保留旧模型避免闪空。
7. 战斗/其它系统：展示间存在期间主场景照常运行也可以，但不得让 CombatCamera、龙镜头、`renderer:SetViewport` 的其它调用把视口抢回去（Astra 检查 `RuinsScene.lua` 里设置视口的位置，必要时加 `if Showroom.Active() then return end`）。`Exit()` 后必须恢复原视口且原相机状态不被污染。
8. 异常：`Enter` 任一步失败 → 回滚所有节点与视口，返回 false。`Update` 里任何异常 pcall 掉并把 `State()` 置 `'failed'`，不要打断每帧逻辑。
9. 性能：展示间期间的额外开销 ≤1 个 draw 级别；构建增量化；离开后零残留（节点数、Geometry 数回到进入前）。

## 面板如何使用
- `Open` → 面板先做 0.2s 黑场淡入 → 峰值时调用 `Showroom.Enter`；成功则面板淡出黑场，左侧透出 3D 展示间；失败则用左侧 2D 侧视大图兜底（体素单面投影，面板自己画）。
- 面板每次配置变化调用 `Showroom.SetWeapon`；每帧调用 `Showroom.Update(dt)`；左半屏拖拽转调 `DragBegin/By/End`；双击调 `Home()`。
- `Close` → 黑场淡入 → `Showroom.Exit()` → 淡出。ForceClose/`Close(true)` 立即 Exit，不做动画。

## 面板版式（横屏 844×390 基准，逻辑坐标已除以整数缩放）
- 右列宽约 330，贴右安全边，圆角 14、深蓝玻璃（#0E1624 约 92% 不透明 + 细金线 #C9A860 / 冰蓝高光），左 55% 全透明留给展示间。
- 右列自上而下：标题「锻造库」+ 关闭 ✕；剑/弓分段切换；「推荐方案 ▾」（均衡/迅捷/破甲、单槽复原、恢复默认）；部位页签（刃/护手/握柄/柄头 或 弓臂/握把/弓梢）；选项卡（体素侧视缩略 + 名称，3 个）；主/副/点缀三个色点，点开展开色板；三条数值：`当前 → 候选` 与 ±差（失衡/破甲收进「更多」）；底部固定 [撤销] [装备]。
- 字体 MiSans，正文 15–16，标题 22–24，数值 17–18；按钮高 ≥44。右列可滚动，底部按钮固定。
- 保留像素图标（`剑_s`/`弓_s` 等）作为页签小图标，其余不再用像素九宫格。
- 左下角淡字提示：「拖动旋转 · 双击回正」。

## 不变的约束
- `ForgePanel` 公开接口：`Open / Close(keepDraft) / ForceClose / IsOpen / PreviewMode`；回调 `{rig,config,canOpen,onOpen,onApply,onEquip,onClose,say}` 语义不变；草稿保留、撤销一步、Apply 逻辑原样迁移。
- `PreviewMode()` 返回 `'3d'`（展示间 ready）/`'fallback'`/`nil`。
- 面板打开期间输入仍由 `ForgePanel.IsOpen()` 阻断。
