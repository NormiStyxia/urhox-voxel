# 遗迹建筑细化与 Web 验收

2026-11-12。基于 main 的 2d38844（包含 Web 鼠标捕获修复）继续。

## 精度与造型

| 部件 | 当前体素/采样边长 | 说明 |
|---|---|---|
| 地形、龙庭、台基、横梁、肋拱、渡槽 | 25 cm（本轮未全局细化） | 保持布局与大轮廓 |
| 外墙、角楼、柱廊、北殿后墙、巨像 | 12.5 cm | 外墙 32 段；柱身各自紧包围盒 |
| 倒柱、北殿前柱 | 6.25 cm | 凹槽、柱鼓接缝、柱础退台、断口 |
| 树干、枝、根 | 6.25 cm 可视采样 | 方截面、轴对齐硬法线，整树合并外表面；隐藏碰撞仍为 25 cm |

墙面沿圆周排列约 1m × 0.5m 的错缝砌石，增加墙脚退台、压顶和局部扶壁。拱券由浅石块、窄金内缘和中央符文组成。苔痕主要集中在墙脚和石缝，残墙顶露出石芯与缺角。树冠仍使用原叶片卡，树的位置和随机冠形序列保留。

没有修改诺米、龙、谜题逻辑、相机、输入控制和场景布局。装饰树干精度不增加物理体数量。门楼轮廓使用外墙 12.5cm 网格；厘米级石缝是材质细节，不是全墙使用厘米级体素。

## 实现位置

- scripts/ruins/RuinsBuild.lua：分级网格、建筑造型；外墙/角楼按竖列缓存地面高度。
- scripts/ruins/VoxelBrush.lua：Finish 的可选 masonry 材质类型。
- scripts/ruins/RuinsScene.lua：按体素边长与砌石类型缓存材质。
- assets/Shaders/BLGL/RuinsVoxel.shader：显式启用砌石层；石缝与颗粒随像素足迹淡出，减少远景闪烁。
- scripts/ruins/RuinsTrees.lua、assets/Shaders/BLGL/RuinsBark.shader：方格枝干、共面合并、连续世界投影树皮纹。

## Web 验收边界与接手检查

本轮不运行有已知 Metal 崩溃的本地 Runtime。通过 Maker 官方提交构建流程发布 Web 预览，构建结果以工具回执为准。以上几何检查不证明 Shader 编译、碰撞表现或整套玩法已在 Web 验收。

Web 接手重点看：
1. 南门近景：拱券、门框和墙脚是否可读，门洞与原谜题封门乱石相互独立。
2. 沿墙行走：错缝石材跨体积连续，远处石缝不过密、不闪烁；正 X 方向圆周接缝附近是否显眼。
3. 北殿近景：柱础、凹槽、断面与巨像，确认人物仍能通过原通路。
4. 金叶树近景：枝根为有台阶的方格轮廓，无圆管、黑面、漏面，树冠位置不变。
5. 查看 RuinsBuild: ... FAILED、RuinsTrees: shader failed、RuinsVoxel.shader failed 日志；检查加载耗时、Web 帧率及原谜题交互。

如果后续回调精度，优先调 RuinsBuild.DETAIL（建筑）和 RuinsTrees 的 BARK_CELL（树干）；不要全局把地形改成 6.25cm，体素体积会按立方增长。
