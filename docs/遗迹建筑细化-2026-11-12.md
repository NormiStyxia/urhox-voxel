# 遗迹建筑细化与 Web 验收

2026-11-12。基于 main 的 2d38844（包含 Web 鼠标捕获修复）继续。

## 精度与造型

| 部件 | 当前体素/采样边长 | 说明 |
|---|---|---|
| 地形、龙庭、台基、横梁、肋拱、渡槽 | 25 cm（本轮未全局细化） | 保持布局与大轮廓 |
| 外墙、角楼、柱廊、北殿后墙、巨像 | 12.5 cm | 外墙 32 段；柱身各自紧包围盒 |
| 倒柱、北殿前柱 | 6.25 cm | 凹槽、柱鼓接缝、柱础退台、断口 |
| 树干、枝、根 | 6.25 cm 可视采样 | 方截面、轴对齐硬法线，整树合并外表面；隐藏碰撞仍为 25 cm |

墙面沿圆周排列约 1.5m × 0.75m 的错缝砌石（反馈修订后，仅材质浅缝），增加墙脚退台、压顶和局部扶壁。拱券由浅石块、窄金内缘和中央符文组成。苔痕主要集中在墙脚和石缝，残墙顶露出石芯与缺角。树冠仍使用原叶片卡，树的位置和随机冠形序列保留。

没有修改诺米、龙、谜题逻辑、相机、输入控制和场景布局。装饰树干精度不增加物理体数量。门楼轮廓使用外墙 12.5cm 网格；厘米级石缝是材质细节，不是全墙使用厘米级体素。

## 实现位置

- scripts/ruins/RuinsBuild.lua：分级网格、建筑造型；外墙/角楼按竖列缓存地面高度。
- scripts/ruins/VoxelBrush.lua：Finish 的可选 masonry 材质类型。
- scripts/ruins/RuinsScene.lua：按体素边长与砌石类型缓存材质。
- assets/Shaders/BLGL/RuinsVoxel.shader：显式启用砌石层；石缝与颗粒随像素足迹淡出，减少远景闪烁。
- scripts/ruins/RuinsTrees.lua、assets/Shaders/BLGL/RuinsBark.shader：方格枝干、共面合并、连续世界投影树皮纹。

## Web 验收边界与接手检查

本轮不运行有已知 Metal 崩溃的本地 Runtime。通过 Maker 官方提交构建流程发布 Web 预览，构建结果以工具回执为准。以上几何检查不证明 Shader 编译、碰撞表现或整套玩法已在 Web 验收。

Web 接手重点看：
1. 南门近景：拱券、门框和墙脚是否可读，门洞与原谜题封门乱石相互独立。
2. 沿墙行走：错缝石材跨体积连续，远处石缝不过密、不闪烁；正 X 方向圆周接缝附近是否显眼。
3. 北殿近景：柱础、凹槽、断面与巨像，确认人物仍能通过原通路。
4. 金叶树近景：枝根为有台阶的方格轮廓，无圆管、黑面、漏面，树冠位置不变。
5. 查看 RuinsBuild: ... FAILED、RuinsTrees: shader failed、RuinsVoxel.shader failed 日志；检查加载耗时、Web 帧率及原谜题交互。

如果后续回调精度，优先调 RuinsBuild.DETAIL（建筑）和 RuinsTrees 的 BARK_CELL（树干）；不要全局把地形改成 6.25cm，体素体积会按立方增长。


## 同日反馈修订：凸条、回溯重影与材质

用户实机截图反馈外墙过密、柱子像白膜、土坡模糊，并反馈回溯后残留另一状态及逐格发光。本次修订基于 b70da8c，保留 Web 侧新的拖动/焦点控制。

- 外墙：撤销体素几何中的半格深刻缝。圆弧采样会把这种刻缝变成密集竖向凸条；现在保留墙脚/扶壁/门框轮廓，以 1.5m × 0.75m 材质浅缝表达砌石，降低缝与亮边对比。
- 回溯：TimeObject、谜题临时采样体积、空 Brush 统一使用 world:RemoveVolume，而不是组件 Dispose。引擎接口文档明确 RemoveVolume 同时销毁节点、组件与 solver body。完整体重建先移除旧体，复原接口有状态保护；复原第一帧即清掉冻结/回溯/闪光状态。
- 普通时间物件：去掉沿每个体素棱边的常驻金线/蓝线，未复原物件仅在瞄准时有轻微轮廓提示。复原后不再有这层提示，原有局部符文的调色板自发光降至 12%；主动施放冻结、回溯仍保留技能特效。
- 柱子：两个白石槽位改成偏暖的旧石色，粗糙度分别 0.84/0.88；加入中尺度矿脉、细孔和毫米级法线起伏。共享这些石材的桥、石雕会保持相同材质语言。
- 土坡/岩壁：补充世界空间三向投影的岩屑、土粒、非规则岩块边界与微表面凹凸，避免陡面只剩纵向低频糊色；近景细节按像素足迹淡出。不更改地形轮廓、碰撞或草的位置。

验证：Lua 5.4 语法、既有 detail_geometry.lua 均通过。新增 tests/ruins/time_object_lifecycle.lua：模拟世界持有节点/物理体，完整执行三轮碎裂、冻结、解冻、两类回溯及重复复原，64 个体积创建并完整移除、每轮复原只保留一个完整体。旧代码在同一检查中触发组件 Dispose 的错误断言。这是 API 生命周期回归测试，不是原生引擎残影的截图复现。

Web 构建与画面验收分开记录；Shader 在 Web 的实际编译、近景材质与通关表现仍需网页端确认。浏览器扩展未连接时，不用构建成功或旧运行日志冒充画面通过。
